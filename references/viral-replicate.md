# 爆款复刻（Viral Replicate）规范

> 适用：客户带一个爆款参考视频/链接进来，想"复刻/仿这个/照这个做/换个品做同款"。
> 定位：爆款复刻**不是第 7 类视频类型**，是**一个"带参考进来"的入口**——它跨类型，先拆解参考属于哪类 + 为什么爆，再决定复刻什么。
> 触发信号："复刻""仿这个""同款视频""这个爆了我想做个一样的""换个品做同款"。

---

## 一、版权四层面（一条都不能踩）

大多数人一提版权就想到"被告"，但电商短视频的实际风险，**平台查重比法律侵权来得更快更狠**。四层是独立风险：

### 1. 著作权层面（法律线，最宽松）

著作权保护**"表达"，不保护"思想/方法/结构"**：

| 可以放心复刻（不受保护） | 不能照搬（受保护） |
|---|---|
| 视频的框架/套路（前3秒钩子→痛点→方案→CTA 结构） | 具体画面：每一帧的构图、运镜、光影 |
| 创意手法、方法论（"第一人称自拍种草""开箱测评"） | 具体文案/台词原文（逐字逐句） |
| 纯事实（产品参数、价格、功能） | 出镜人的具体形象（肖像） |
| 通用口头禅/桥段（"姐妹们我挖到宝了"） | 原创 BGM 和配乐 |

一句话记死：**复刻"骨架"合法，照搬"血肉"侵权。** 骨架=结构、套路、节奏、方法论；血肉=画面、文案原句、人物、音乐。

### 2. 平台查重层面（现实线，比法律严）

这是算法判定，不是法律判定——法律不侵权，画面/文案太像照样被限流：

- **抖音**：原创度检测，搬运/抄袭限流、降权；判定维度含画面相似度、文案相似度、BGM 相同度。
- **小红书**：对"搬运"处罚最严，笔记被判搬运直接限流。
- **视频号**：原创声明机制，搬运取消原创权益、拿不到推荐。

**结论：SKILL 的安全线要高于法律线**——不是"不侵权就行"，是"避开平台查重算法"。

### 3. 肖像权层面（人物出镜额外风险）

用别人的真人脸，不管有没有复刻动作，只要那张脸出现在你的商业视频里，就涉及肖像权和商业使用授权。复刻时不得直接复用他人真人脸；Seedance/H3 路径的人物资产走黑白铅笔素描 / 黑白线稿流程，人物参考图只定义姿态、构图、服装或发型结构，不做真人身份复刻；可灵路径仅可使用用户已授权的真人照片/视频作 I2V 身份锚定。视频是否使用真实人物风格按用户单独确认。

### 4. 音乐版权层面（最容易被忽略）

BGM 是最隐蔽的坑：爆款配乐常是热门曲目，直接搬原 BGM 会被版权系统识别下架。本 SKILL 的生成阶段默认禁 BGM，因此爆款 BGM 只能用于分析节奏点、剪辑密度与情绪曲线；不得在视频生成 PROMPT 中写原曲、同风格替代曲或任何配乐指令。用户若在发布阶段另行明确要音乐，才可在生产/发布说明中列“平台曲库授权音乐待人工选择”，仍不得复用爆款原曲。

## 二、复刻的正确姿势：结构复刻 + 表达重构

落地要改四样东西：

- **画面**：换场景、换角度、换构图。即使同品，也不能用原爆款的每一帧构图。
- **文案**：改写成自己的话，不是"换几个词"——和 SKILL 已有的"段子改编铁律"一致：基于结构逻辑改编成原创，严禁照搬原句。
- **人物**：不同品必换人；同品用同一模特，也要换服装/场景/镜头，否则平台判"重复内容"。
- **音乐**：不进入生成 PROMPT；仅把爆款 BGM 拆为节奏点、剪辑密度与情绪曲线。若用户明确要发布后配乐，只在运营说明标“平台曲库授权音乐待人工选择”，不指定或复用原曲。

---

## 三、爆款拆解六维（复刻第一步，最容易被漏）

不拆就复刻 = 照着画瓢，表面抄了、内核（为什么让人看完/转发/下单）丢了。拆解表：

| 维度 | 拆什么 | 产出 |
|---|---|---|
| **钩子** | 前 3 秒靠什么留人？（悬念/冲突/利益/反差） | 钩子类型 + 为什么有效 |
| **脚本结构** | 开头→发展→高潮→结尾怎么走 | 结构骨架（可复刻部分） |
| **节奏** | 剪辑节奏（切多快）+ 镜头内运动速度（慢动作/正常） | 节奏曲线（接 SKILL 已有节奏维度） |
| **卖点** | 卖点怎么带出来？参数轰炸还是场景代入 | 卖点呈现逻辑（可迁移部分） |
| **情绪** | 情绪怎么推？好奇→认同→下单 | 情绪弧线 |
| **CTA** | 结尾怎么收？怎么让人行动 | CTA 手法 |

拆出来的结果分两类：**"骨架"（结构/节奏/情绪弧线/卖点逻辑，可复刻）** 和 **"血肉"（具体画面/文案/人物/音乐，要改）**。

---

## 四、复刻度三档（场景/人物改不改，是这一档的选择）

| 复刻度 | 场景 | 人物 | 运镜/节奏 | 文案 | 适用 + 风险 |
|---|---|---|---|---|---|
| **高复刻（像素级）** | 尽量贴近 | 尽量还原 | 逐镜复刻 | 改产品名/细节 | 同品同款；查重风险最高，几乎必踩线，**不推荐** |
| **中复刻（结构复刻）** | 可换 | 可换 | 复刻结构不逐镜 | 按结构重写 | 不同品同款；**推荐，安全且有效** |
| **低复刻（灵感借鉴）** | 全原创 | 全原创 | 只借一个点 | 全原创 | 最安全，但复刻感弱 |

核心判断：**高复刻在平台上基本是死路**（查重 + 侵权双重风险），默认引导客户走**中复刻**——结构照搬、表达原创。和"段子改编"边界一致。

---

## 五、同品 vs 不同品（两套逻辑，必须分开问）

**同品同款**：难点在"差异化"。
- 复刻自己的旧爆款：法律风险低（自己的版权），但平台查重照样命中——重点是换场景/换钩子/换剪辑做出新意。
- 复刻**别人**的同品爆款：风险最高（直接竞品，最易被投诉搬运），必须明确提醒。

**不同品同款**：难点在"卖点迁移"。
- 最容易翻车的是生搬硬套——把台词里的产品名换成新产品的名字。
- 正确做法：**迁移"爆款怎么把卖点讲清楚的逻辑"，不迁移"台词本身"**。新产品卖点不同，表达要重新设计。

---

## 六、探测问项（Phase 3 用，一次问全，不留占位符）

客户进入爆款复刻后，Phase 3 对尚未明确的字段必问：优先用当前环境的结构化提问工具，没有时用编号文本；已回答的字段不重复问。

1. **同品还是不同品**：「复刻的是同一个产品，还是换个产品套同款？」→ 决定走差异化逻辑还是卖点迁移逻辑。
2. **复刻度**：「场景/人物/文案要多大程度贴近原爆款？」→ 高/中/低三档，默认引导中复刻。
3. **场景改不改**：「场景用相似场景还是全新场景？」
4. **人物改不改**：「人物用单人还是多人？出镜人要换吗？」（Seedance / H3 人物资产用黑白素描；可灵直接走用户授权真人照片/视频 I2V 参考、免素描；视频风格另行确认）
5. **目标平台**：「发哪个平台？」→ 判断爆款套路在该平台还成立吗、是否已被用烂（接"发行区域"机制）。

---

## 七、素材采集清单（客户需提供的参考素材）

| 素材 | 用途 |
|---|---|
| 爆款视频本体 / 链接 | 画面、运镜、节奏参考 |
| 爆款文案 / 字幕 | 台词、话术参考 |
| 爆款 BGM（如有） | 仅拆解节奏点、剪辑密度与情绪曲线；不写入生成 PROMPT，不复用原曲或指定同风格替代曲 |
| 爆款数据（点赞/转发/评论） | 判断"爆"具体爆在哪一段 |
| 客户自己的产品图/素材 | 新产品要用的（不同品同款必需） |

---

## 八、与既有铁律的关系（一致性）

- **段子改编铁律**：素材库段子可原文存放，交付剧本必须原创改编。→ 爆款复刻同理：参考视频可原文存放，交付剧本必须结构复刻 + 表达原创。
- **采集阶段铁律**：探测阶段把必要信息问全，不留占位符。→ 复刻的探测项（同品/不同品、复刻度、场景、人物、平台）一次问全。
- **合规规则标来源铁律**：版权四层面的平台查重描述（抖音/小红书/视频号）属【导演经验】，写进 SKILL 时标来源，不冒充官方铁律。
