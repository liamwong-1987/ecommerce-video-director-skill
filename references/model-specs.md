# 三模型能力对比与 PROMPT 格式总览

## 能力对比

| 维度 | Seedance 2.0 | Seedance 2.5 | MiniMax H3 |
|------|-------------|-------------|-----------|
| 单次时长 | 4-15s | **30s**（超长 180s） | 4-15s |
| 参考图片 | 9 张 | **30 张** | 9 张 |
| 参考视频 | 3 段 | 10 段 | 3 段（各 2-15s） |
| 参考音频 | 3 段 | 10 段 | 3 段（各 2-15s） |
| 素材上限 | 约 12 个 | **50 个** | 12 个 |
| 分辨率 | 720p-1080p | 720p-1080p | **最高 2K**（2560×1440） |
| 音频 | 后配 | 后配 | **原生 32kHz 立体声**（音画联合生成） |
| 时间戳控制 | 无 | **有** | 无 |
| 首尾帧模式 | 无 | 无 | **有**（I2VA/L2VA/FL2VA） |
| Prompt 上限 | - | - | 7000 字符 |
| 宽高比 | 16:9/9:16/1:1 | 16:9/9:16/1:1 | 21:9/16:9/4:3/1:1/3:4/9:16 |

## PROMPT 格式（三模型完全不同，必须区分）

| 模型 | 语言 | 格式 |
|------|------|------|
| Seedance 2.0/2.5 | **中文** | 六板块 + @图片N 引用 |
| MiniMax H3 关键帧模式 | **英文** | 对齐指令 + 3 字段 |
| MiniMax H3 全能参考模式 | **英文** | 6 区段 |

## 2.0 超 15s 时长衔接方案（尾帧高清重绘）

Seedance 2.0 单段 4-15s，做 30s+ 用「多段 + 尾帧高清重绘衔接」（默认方案）：

1. 拆段：按脚本停顿拆成 ≤15s 每段，每段独立六板块提示词（见 `seedance-prompt.md`）。
2. 生成段1 → 截取最后一帧。
3. **尾帧高清重绘**：用「同构图高清重绘」提示词把尾帧重绘为高清图（画面/构图/主体不变，仅提分辨率）。
4. 校验重绘图与尾帧一致；漂移则回退直接截图当首帧。
5. 高清图作段2 首帧参考，段2 提示词写「从首帧无缝继续」。循环至末段后拼接。

> 选 2.0 且时长 >15s 时，SKILL Phase 6 会触发此流程。

## 选择逻辑

1. **要 30s+ 长视频 / 多素材 / 时间戳控制** → Seedance 2.5
2. **要原生立体声 / 首尾帧 / 2K / 性价比** → MiniMax H3
3. **沿用已有 2.0 工作流 / 稳定成熟** → Seedance 2.0

**注意**：同一脚本按模型转不同格式，不要混用。详细规范见 `seedance-prompt.md` 和 `h3-prompt.md`。
