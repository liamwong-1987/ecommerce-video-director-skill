# 五模型能力对比与 PROMPT 格式总览

## 通用前置：可灵 Kling 优势与其它模型对比（每次问客户选模型前必讲）

在问客户任何「选哪个模型」的问句之前，必须先讲下面这段——客户必须基于完整信息拍板，**Agent 不得替客户做模型信息输入**（不替客户列优势、不替客户选）。无论客户答「否（不真人）」还是「已有偏好模型」，都要先讲，不能等客户说「有可灵」才提。

| 维度 | 可灵 Kling | Seedance 2.0/2.5/Mini | MiniMax H3 | 数字人方案 |
|------|-----------|----------------------|------------|-----------|
| 真人样貌一致性 | 最强，多镜头同一人不变脸 | 平台屏蔽真实人脸，做不了真人 | 一般，多镜头易变脸 | 虚拟人，非真人 |
| 口型同步 | 支持（口播/探店/解说必备） | 不支持写实真人 | 不支持写实真人 | 视方案 |
| 中文场景理解 | 优秀 | 一般 | 一般 | 一般 |
| 适用场景 | 真实模特/主播口播/探店/真人脸 | 商品/虚拟/非真人 | 商品/虚拟/非真人 | 非真人替代 |
| 是否需客户具备生成能力 | 是（账号/API/MCP） | 否 | 否 | 视方案 |

**结论一句话**：真人出镜场景，可灵 Kling 是唯一能稳定做出写实真人的模型，其它模型在此场景硬伤明显；但可灵需客户具备生成能力，否则按 SKILL Phase 0 第三问换方案走。非真人场景，5 个模型按成本/时长/效果由客户选。

## PROMPT 格式（五模型完全不同，必须区分）

| 模型 | 语言 | 格式 |
|------|------|------|
| Seedance 2.0/2.5 | **中文** | 六板块 + @图片N 引用 |
| Seedance 2.0 Mini | **中文** | 一句话公式（主体+运动，背景+运动，镜头+运动）+ @引用 + 时间戳 |
| MiniMax H3 关键帧模式 | **英文** | 对齐指令 + 3 字段 |
| MiniMax H3 全能参考模式 | **英文** | 6 区段 |
| **可灵 Kling** | **中文场景 + 英文技术参数（混合）** | 时间轴 / 分镜标签，I2V 身份锚定，口型同步 |

> **⚠️ Mini 的关键坑**：不要套用 2.0/2.5 的六板块格式。Mini 用简洁一句话公式，塞六板块标题会干扰生成、浪费次数。详见 `seedance-mini-prompt.md`。
>
> **⚠️ 可灵的关键坑**：不要套用六板块，也不要套 Mini 一句话或 H3 英文字段。可灵用「分镜标签时间轴 + 中文场景英文参数混合」，且**真人口播必须走 I2V 身份锚定 + 口型同步**。详见 `kling-prompt.md`。

## 2.0 / Mini / 可灵 超 15s 时长衔接方案

- **Seedance 2.0**：用「多段 + 尾帧高清重绘衔接」（默认方案）——截取尾帧 → 重绘高清 → 校验 → 当首帧。详见 `seedance-prompt.md` 第十节。
- **Mini**：优先用「视频延长」直接续写（`将@视频1延长Xs`），不做尾帧重绘。详见 `seedance-mini-prompt.md` 第六节。
- **可灵**：用「视频续写」从上一片段尾帧无缝继续，**每 2–3 段用原始参考（图/视频）重新锚定身份**防漂移；音频不跨片段连续，统一配乐放后期。详见 `kling-prompt.md` 第六节。

## 选择逻辑

1. **要 30s+ 长视频 / 多素材 / 时间戳控制** → Seedance 2.5
2. **要原生立体声 / 首尾帧 / 2K / 性价比** → MiniMax H3
3. **沿用已有 2.0 工作流 / 稳定成熟** → Seedance 2.0
4. **成本优先 / 批量快速生成 / 电商营销 A/B 测试** → Seedance 2.0 Mini
5. **真实模特 / 主播口播 / 探店 / 真人脸出镜** → **建议可灵 Kling**（Seedance 平台层屏蔽写实真人面部，做不了真人；可灵 I2V + 视频提取特征真人一致性最强，且原生口型同步）。**但须客户先确认具备可灵生成能力（账号/API/MCP），否则改走换方案（数字人 / 客户自有真人模型）。模型最终以客户确认为准，Agent 不擅自路由。**

> **模型决策时序（重要 · 对应 SKILL Phase 0）**：模型选择不是 Phase 9 的事，必须在 Phase 0（资产/分镜/PROMPT 之前）由客户拍板完成。真人出镜场景尤其要先确认客户是否具备可灵 Kling 生成能力——不具备就不走可灵，改数字人或客户自有真人模型，绝不硬用 Seedance 做写实真人（平台屏蔽必失败）。模型一旦锁定，Phase 8 资产、Phase 7 分镜、Phase 10 PROMPT 全程按该模型走，中途换模型须回 Phase 0 重做。Agent 只推荐 + 讲清各模型差异，不替客户路由。

**注意**：同一脚本按模型转不同格式，不要混用。详细规范见 `seedance-prompt.md`、`seedance-mini-prompt.md`、`h3-prompt.md` 和 `kling-prompt.md`。
