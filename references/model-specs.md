# 五模型能力对比与 PROMPT 格式总览

## 通用前置：可灵 Kling 优势与其它模型对比（每次问客户选模型前必讲）

在问客户任何「选哪个模型」的问句之前，必须先讲下面这段——客户必须基于完整信息拍板，**Agent 不得替客户做模型信息输入**（不替客户列优势、不替客户选）。无论客户答「否（不真人）」还是「已有偏好模型」，都要先讲，不能等客户说「有可灵」才提。

| 维度 | 可灵 Kling | Seedance 2.0/2.5/Mini | MiniMax H3 |
|------|-----------|----------------------|------------|
| 真人样貌一致性 | I2V + 视频提取人物特征，还原度最高【你实测】 | 能做写实真人，还原度较低【你实测】 | Omni-Reference 全向参考锁定跨镜头角色一致性【官方】 |
| 口型同步 | 优秀 | 优秀 | 优秀 |
| 中文场景理解 | 优秀 | 优秀 | 优秀 |
| 适用场景 | 真实模特/主播口播/探店/真人脸（还原度最高） | 商品/虚拟/真人（还原度较低） | 商品/虚拟/真人（还原度较低） |
| 人物资产过审 | 直接出真实人物参考图 | 人物资产图用黑白素描生成（过人脸审核），视频仍真实风格 | 人物资产图用黑白素描生成（过人脸审核），视频仍真实风格 |

> 本技能不接数字人方案；也不向客户开放「风格化」选择——黑白素描仅作为人物资产图过审手段（自动应用），绝不作为视频风格。

**结论一句话**：真人出镜场景，推荐可灵 Kling（还原度最高最稳）；客户也可选 Seedance / H3 做真人（能做但还原度较低）。本技能对客户没有任何生成能力门槛——Agent 必先讲清前置对比表让客户基于完整信息自选，不替客户拍板、不预设门槛。非真人场景，5 个模型按成本/时长/效果由客户选。**黑白素描仅用于人物资产图过审，绝不作为视频风格——视频人物必须是真实风格。**

## PROMPT 格式（五模型完全不同，必须区分）

| 模型 | 语言 | 格式 |
|------|------|------|
| Seedance 2.0/2.5 | **中文** | 六板块 + @图片N 引用 |
| Seedance 2.0 Mini | **中文** | 一句话公式（主体+运动，背景+运动，镜头+运动）+ @引用 + 时间戳 |
| MiniMax H3 关键帧模式 | **英文** | 对齐指令 + 3 字段 |
| MiniMax H3 全能参考模式 | **英文** | 6 区段 |
| **可灵 Kling** | **中文场景 + 英文技术参数（混合）** | 时间轴 / 分镜标签，I2V 身份锚定，口型同步 |

> **⚠️ Mini 的关键坑**：不要套用 2.0/2.5 的六板块格式。Mini 用简洁一句话公式，塞六板块标题会干扰生成、浪费次数。详见 `seedance-mini-prompt.md`。
>
> **⚠️ 可灵的关键坑**：不要套用六板块，也不要套 Mini 一句话或 H3 英文字段。可灵用「分镜标签时间轴 + 中文场景英文参数混合」，且**真人口播必须走 I2V 身份锚定 + 口型同步**。详见 `kling-prompt.md`。

## 超 15s 时长衔接方案（何时做、怎么做，由 Phase 7 分镜「尾帧衔接」列决定）

> **触发判定**：是否走衔接流程，由 Phase 7 分镜表「尾帧衔接」列决定，**不按视频类型、不按模型豁免**：标记「否」（跳切段）直接新景别独立生成；标记「是」（连续段）强制走下方「尾帧高清还原 + 校验-重试闭环」，所有模型一致执行。

- **Seedance 2.0/2.5（连续段）**：强制「尾帧高清还原」——截取尾帧 → 保真高清重绘（内容/构图/主体/服装/光源/色调完全不变，仅提清）→ 校验-重试（至少 2 次、至多 3 次，直到一致）→ 当首帧。**绝不用低清尾帧直接当首帧、绝不跳过还原、重试耗尽前不回退**。详见 `seedance-prompt.md` 第十节。
- **Mini（连续段）**：走「视频延长」链式续写（`将@视频1延长Xs`），本身是平台内高清续写；**不允许在衔接处用低清尾帧糊弄**。跳切段直接新景别独立生成。详见 `seedance-mini-prompt.md` 第六节。
- **可灵（连续段）**：走「视频续写」从上一片段尾帧无缝继续，**每 2–3 段用原始参考（图/视频）重新锚定身份**防漂移；原生高清，**不允许在衔接处用低清尾帧糊弄**。跳切段直接新景别独立生成。详见 `kling-prompt.md` 第六节。
- **MiniMax H3（连续段）**：用首尾帧 FL2VA 对齐 / Regenerate-2K，保真还原到高清后当首帧；校验-重试闭环同 Seedance。详见 `h3-prompt.md`。

## 节奏控制能力对比（Phase 3 节奏调研 → Phase 7 运动速度列 → Phase 10 落地）

> 核心区分：**剪辑节奏**（镜头切换快慢，分镜的镜头时长/切点密度）与**镜头内运动速度**（单镜头里动作快慢、升格慢动作、正常速度）是两个概念，不要混为一谈。下表只讲「镜头内运动速度」能力。

| 节奏维度 | Seedance 2.0 | Seedance 2.0 Mini | Seedance 2.5 | MiniMax H3 | 可灵 Kling（V3/O3） |
|---|---|---|---|---|---|
| 慢动作/升格 | 提示词级（`慢镜头`+速度锚点） | 同 2.0 | 时间锚点精确变速（停帧+分段变速+动效画板） | 间接（高帧率后后期放慢，`slow zoom` 运镜术语造慢速感） | 原生（`slow motion` 提示词 + 60fps） |
| 快动作/缩时 | 提示词级（`快剪辑`/`快动作`） | 同 2.0 | 速度系数 +1.2x 等 | 提示词级（`fast-paced`+分段描述） | 原生（`fast camera`+60fps） |
| 变速精度 | 基础分段 | 同 2.0 | **最强**（停帧=速度0 + 分段变速 + 速率曲线可视化） | 分段过程描述（按时间戳分节） | 间接（Multi-Shot 每镜头固定速度，单镜头内不支持变速） |
| 关键帧控制 | 首尾帧输入 | 首尾帧（靠图生视频造首帧） | 首尾帧 + 三帧混合 | 首尾帧（FL2VA） | 首帧/尾帧 + 元素参考（O3） |
| 镜头切转衔接 | 导演模式多镜头 | 多镜头（官方评测切换不够自然） | 30s 原生多镜头 | 单片段多镜头 | Multi-Shot 一次最多 6 镜头 |
| 提示词节奏控制 | 节奏语义解析器 | 同 2.0 | 时间戳语法精确到秒 | 分段过程描述 + 音频绑定节奏 | Cause-and-Effect 因果链 |

**关键结论**：
- **镜头内精确变速（停帧/分段变速/升格）最强 → Seedance 2.5**（唯一支持停帧 + 动效画板速率曲线）。
- **多镜头衔接最接近专业剪辑 → 可灵 V3/O3**（Multi-Shot 一次最多 6 镜头自动切换）。
- **可灵劣势**：单个镜头内不支持速度变化（Multi-Shot 每镜头固定速度）。
- **H3 慢动作是间接实现**：无直接开关，靠 `slow zoom` 运镜术语 + 高帧率后期放慢。
- **国外视频普遍不喜欢快节奏，但不代表不问**——节奏调研对所有区域必做，不按区域跳过。

## 选择逻辑

1. **要 30s+ 长视频 / 多素材 / 时间戳控制 / 镜头内精确变速（停帧+分段变速+升格慢动作）** → Seedance 2.5
2. **要原生立体声 / 首尾帧 / 2K / 性价比** → MiniMax H3
3. **沿用已有 2.0 工作流 / 稳定成熟** → Seedance 2.0
4. **成本优先 / 批量快速生成 / 电商营销 A/B 测试** → Seedance 2.0 Mini
5. **真实模特 / 主播口播 / 探店 / 真人脸出镜** → **推荐可灵 Kling**（还原度最高；客户也可选 Seedance/H3 做真人，只要接受较低还原度；可灵 I2V + 视频提取特征真人一致性最强，且原生口型同步）。**本技能对客户不设能力门槛**——Agent 讲清前置对比表让客户基于信息自选，不替他拍板。模型最终以客户确认为准，Agent 不擅自路由。

> **模型决策时序（重要 · 对应 SKILL Phase 0）**：模型选择不是 Phase 9 的事，必须在 Phase 0（资产/分镜/PROMPT 之前）由客户拍板完成。真人场景三模型都能做，推荐可灵是因为还原度最高；客户也可选 Seedance/H3 做真人（还原度较低但能做）。本技能对客户没有任何生成能力门槛——客户的 API / 账号 / 付费是客户私事，skill 不预设、不评估。Agent 只讲清各模型差异让客户自选。人物资产图统一用黑白素描过审、视频还原真实风格。模型一旦锁定，Phase 8 资产、Phase 7 分镜、Phase 10 PROMPT 全程按该模型走，中途换模型须回 Phase 0 重做。

**注意**：同一脚本按模型转不同格式，不要混用。详细规范见 `seedance-prompt.md`、`seedance-mini-prompt.md`、`h3-prompt.md` 和 `kling-prompt.md`。
