## 通用前置：可灵 Kling 优势与其它模型对比（需要选模型时讲）

当用户尚未选择模型或需要比较时，先概括与本次镜头有关的差异，再让客户拍板；不要强迫用户阅读与当前任务无关的完整表。用户已经明确模型时直接记录偏好，在 Phase 7.5 按镜头能力提示必要风险，不重复提问。

| 维度 | 可灵 Kling | Seedance 2.0/2.5/Mini | MiniMax H3 |
|------|-----------|----------------------|------------|
| 真人样貌一致性 | I2V + 视频提取人物特征，还原度最高【你实测】 | 能做写实真人，还原度较低【你实测】 | Omni-Reference 全向参考锁定跨镜头角色一致性【官方】 |
| 口型同步 | 优秀 | 优秀 | 优秀 |
| 中文场景理解 | 优秀 | 优秀 | 优秀 |
| 适用场景 | 真实模特/主播口播/探店/真人脸（还原度最高） | 商品/虚拟/真人（还原度较低） | 商品/虚拟/真人（还原度较低） |
| 人物资产形式 | **可灵走授权真人 I2V 参考、免素描** | 人物资产统一黑白铅笔素描 / 黑白线稿 | 人物资产统一黑白铅笔素描 / 黑白线稿 |

> 本技能不接数字人方案；正式人物资产（非可灵路径）固定为黑白铅笔素描 / 黑白线稿，不输出真人照片或彩色肖像。Seedance/H3 可直接用已确认素描生成真人感视频；**可灵路径免产素描**——选定可灵即直接以用户授权的真人照片/视频作 I2V 身份锚定。若用户另行提供并授权真人照片/视频，也可作为生成阶段输入，但不能反向改变正式人物资产图。

**结论一句话**：真人出镜视频场景，推荐可灵 Kling（视频还原度最高最稳）；客户也可选 Seedance / H3 做真人视频。**可灵路径免产黑白素描**，直接走授权真人 I2V 参考；Seedance/H3 路径仍须交付黑白铅笔素描 / 黑白线稿，不输出真人照片或彩色肖像。视频风格由用户单独确认，不能反向改变人物资产。

## 产品一致性能力边界与镜头路由（先读）

> 任何纯 AI 视频模型都不能对真实 SKU 的 Logo、包装文字、固定版式、型号和价格作效果担保。PROMPT 仍应保留“产品外观、比例、位置与参考图 100% 一致”的强约束，让模型理解最高优先级；最终效果按镜头路由验收，模型选择不能替代真实产品资产。

| 一致性目标 | 镜头类型 | 可用模型/方法 | 正确验收 | 禁止做法 |
|---|---|---|---|---|
| L1：只保证像同类产品 | P0/P1 叙事氛围镜 | 仍需真实产品参考；只用于远景/背景/氛围 | 远景中的品类观感、主色和氛围成立 | 用相似产品替代真实产品 |
| L2：保证产品长相接近 | P2 产品动作镜 | 必须使用真实产品参考，优先可灵 O3；其他模型需逐镜测试 | 轮廓、比例、材质、主色、主要色块/图形 | 用长 PROMPT 强求文字/Logo 精准 |
| L3：保证真实包装信息 | P3 信息镜/结尾 Packshot | 必须使用真实产品图、实拍视频、微动、跟踪合成 | Logo、文字、版式、型号与真实资产一致 | 交给任何视频模型重新绘制包装 |

**模型分工建议：**
- Seedance 2.0/2.5：叙事、人物、氛围、口播、节奏；产品镜仅在 P2 测试通过时使用。
- Seedance Mini：低成本草稿、氛围和非关键 P0/P1 镜；不作为包装保真主力。
- MiniMax H3：视觉氛围、首尾帧、无口播产品环境镜；P3 仍需真实资产前景。
- 可灵 O3：真人身份与参考驱动 P2 产品动作镜优先；P3 不重画包装。
- 真实资产/合成：唯一可以承担 L3 SKU 保真的生产线。

## PROMPT 格式（5 条模型路线完全不同，必须区分）

| 模型 | 语言 | 格式 |
|------|------|------|
| Seedance 2.0/2.5 | **中文** | 六板块 + @图片N 引用 |
| Seedance 2.0 Mini | **中文** | 一句话公式（主体+运动，背景+运动，镜头+运动）+ @引用 + 时间戳 |
| MiniMax H3 关键帧模式 | **英文** | 对齐指令 + 3 字段 |
| MiniMax H3 全能参考模式 | **英文** | 6 区段 |
| **可灵 Kling** | **中文场景 + 英文技术参数（混合）** | 时间轴 / 分镜标签，I2V 身份锚定，口型同步 |

> **⚠️ Mini 的关键坑**：不要套用 2.0/2.5 的六板块格式。Mini 用简洁一句话公式，塞六板块标题会干扰生成、浪费次数。详见 `seedance-mini-prompt.md`。
>
> **⚠️ 可灵的关键坑**：不要套用六板块，也不要套 Mini 一句话或 H3 英文字段。可灵用「分镜标签时间轴 + 中文场景英文参数混合」，且**真人口播必须走 I2V 身份锚定 + 口型同步**。详见 `kling-prompt.md`。

## 超 15s 时长衔接方案（何时做、怎么做，由 Phase 7 分镜「尾帧衔接」列决定）

> **触发判定**：是否走衔接流程，由 Phase 7 分镜表「尾帧衔接」列决定，**不按视频类型、不按模型豁免**：标记「否」（跳切段）直接新景别独立生成；标记「是」（连续段）强制走下方「尾帧高清还原 + 校验-重试闭环」，所有模型一致执行。

- **Seedance 2.0/2.5（连续段）**：强制「尾帧高清还原」——截取尾帧 → 保真高清重绘（内容/构图/主体/服装/光源/色调完全不变，仅提清）→ 校验；通过即停止，不通过才重试，累计最多 3 次 → 当首帧。**绝不用低清尾帧直接当首帧、绝不跳过还原、重试耗尽前不回退**。详见 `seedance-prompt.md` 第十节。
- **Mini（连续段）**：走「视频延长」链式续写（`将@视频1延长Xs`），本身是平台内高清续写；**不允许在衔接处用低清尾帧糊弄**。跳切段直接新景别独立生成。详见 `seedance-mini-prompt.md` 第六节。
- **可灵（连续段）**：走「视频续写」从上一片段尾帧无缝继续，**每 2–3 段用原始参考（图/视频）重新锚定身份**防漂移；原生高清，**不允许在衔接处用低清尾帧糊弄**。跳切段直接新景别独立生成。详见 `kling-prompt.md` 第六节。
- **MiniMax H3（连续段）**：用首尾帧 FL2VA 对齐 / Regenerate-2K，保真还原到高清后当首帧；校验-重试闭环同 Seedance。详见 `h3-prompt.md`。

## 节奏控制能力对比（Phase 3 节奏调研 → Phase 7 运动速度列 → Phase 10 落地）

> 核心区分：**剪辑节奏**（镜头切换快慢，分镜的镜头时长/切点密度）与**镜头内运动速度**（单镜头里动作快慢、升格慢动作、正常速度）是两个概念，不要混为一谈。下表只讲「镜头内运动速度」能力。

| 节奏维度 | Seedance 2.0 | Seedance 2.0 Mini | Seedance 2.5 | MiniMax H3 | 可灵 Kling（V3/O3） |
|---|---|---|---|---|---|
| 慢动作/升格 | 提示词级（`慢镜头`+速度锚点） | 同 2.0 | 时间锚点精确变速（停帧+分段变速+动效画板） | 间接（高帧率后后期放慢，`slow zoom` 运镜术语造慢速感） | 原生（`slow motion` 提示词 + 60fps） |
| 快动作/缩时 | 提示词级（`快剪辑`/`快动作`） | 同 2.0 | 速度系数 +1.2x 等 | 提示词级（`fast-paced`+分段描述） | 原生（`fast camera`+60fps） |
| 变速精度 | 基础分段 | 同 2.0 | **最强**（停帧=速度0 + 分段变速 + 速率曲线可视化） | 分段过程描述（按时间戳分节） | 间接（Multi-Shot 每镜头固定速度，单镜头内不支持变速） |
| 关键帧控制 | 首尾帧输入 | 首尾帧（靠图生视频造首帧） | 首尾帧 + 三帧混合 | 首尾帧（FL2VA） | 首帧/尾帧 + 元素参考（O3） |
| 镜头切转衔接 | 导演模式多镜头 | 多镜头（官方评测切换不够自然） | 30s 原生多镜头 | 单片段多镜头 | Multi-Shot 一次最多 6 镜头 |
| 提示词节奏控制 | 节奏语义解析器 | 同 2.0 | 时间戳语法精确到秒 | 分段过程描述 + 音频绑定节奏 | Cause-and-Effect 因果链 |

**关键结论**：
- **镜头内精确变速（停帧/分段变速/升格）最强 → Seedance 2.5**（唯一支持停帧 + 动效画板速率曲线）。
- **多镜头衔接最接近专业剪辑 → 可灵 V3/O3**（Multi-Shot 一次最多 6 镜头自动切换）。
- **可灵劣势**：单个镜头内不支持速度变化（Multi-Shot 每镜头固定速度）。
- **H3 慢动作是间接实现**：无直接开关，靠 `slow zoom` 运镜术语 + 高帧率后期放慢。
- **国外视频普遍不喜欢快节奏，但不代表不问**——节奏调研对所有区域必做，不按区域跳过。

## 选择逻辑

1. **要 30s+ 长视频 / 多素材 / 时间戳控制 / 镜头内精确变速（停帧+分段变速+升格慢动作）** → Seedance 2.5
2. **要原生立体声 / 首尾帧 / 2K / 性价比** → MiniMax H3
3. **沿用已有 2.0 工作流 / 稳定成熟** → Seedance 2.0
4. **成本优先 / 批量快速生成 / 电商营销 A/B 测试** → Seedance 2.0 Mini
5. **真实模特 / 主播口播 / 探店 / 真人脸出镜** → **推荐可灵 Kling**（还原度最高；客户也可选 Seedance/H3 做真人，只要接受较低还原度；可灵 I2V + 视频提取特征真人一致性最强，且原生口型同步）。**本技能对客户不设能力门槛**——Agent 讲清前置对比表让客户基于信息自选，不替他拍板。模型最终以客户确认为准，Agent 不擅自路由。

> **模型决策时序（对应 Phase 0 / 7.5）**：Phase 0 记录用户可用模型与偏好，Phase 7.5 再为每个镜头锁定模型/工具；同一视频允许逐镜多模型路由。仅改某一镜模型时，更新该镜路由、资产限制和 PROMPT 即可；只有模型变化影响产品事实、人物路线、全片时长或场景基线时，才回对应上游阶段，不默认整案重做。**可灵路径人物资产走授权真人 I2V 参考、免素描**；Seedance/H3 路径正式人物资产始终交付黑白素描，生成阶段可用素描，或使用用户另行授权的真人素材。

**注意**：同一脚本按模型转不同格式，不要混用。详细规范见 `seedance-prompt.md`、`seedance-mini-prompt.md`、`h3-prompt.md` 和 `kling-prompt.md`。

## 导演思维公式（两步，定死框架：以后所有视频按这个做）

小逻的精髓是「导演思维」——模型无关的镜头/表演/节奏决策方法。本 SKILL 把它提炼成**两步公式**：第 1 步用导演思维定镜头（模型无关），第 2 步按 Phase 7.5 每镜路由的模型/工具翻译成对应生产指令（各模型官方语法，或 P3 的真实资产微动/合成指令）。以后做任何视频都走这两步，不跳步。

### 第 1 步【导演决策】（模型无关，小逻导演思维）

每个镜头先定 4 件事：

1. **景别与功能**：这个镜头什么景别、承载什么？大远景/全景立空间，中景做人物关系，近景做反应，特写锁细节。
2. **运镜意图**（不是具体词，是意图）：特写要「稳」、中近景要「轻手持+惯性」、全景要「呼吸感/纪实」。
3. **表演**：禁情绪词，用六维可见动作 + 动作中间态 + 电商表演范式（见下方）。
4. **节奏**：镜头时长（快节奏 1-2s / 慢节奏 3-5s）、切点、宏观换挡（15-30s 一次明显换挡）。

### 第 2 步【模型翻译】（按 Phase 7.5 每镜路由，把导演意图复刻成对应生产指令）

1. **运镜意图 → 官方词**：查「运镜意图对照表」（下方）换成该模型官方运镜词。
2. **表演 → 按模型能力写六维**：可灵微表情降级 / Seedance 降级 / Mini 砍到 1-2 个 / H3 英文落地（见「各模型能力边界」）。
3. **结构 → 套模型 PROMPT 格式**：Seedance 六板块 / 可灵分镜标签时间轴 / Mini 一句话公式 / H3 英文字段（见各模型文件）。

### 六维物理表演（禁抽象情绪词，用可见生理细节）

视频 PROMPT 描述人物情绪，**严禁「难过 / 愤怒 / 委屈 / 失望 / 崩溃 / 麻木 / 紧张 / 开心」等抽象情绪词**，改用六维可见生理细节（普通镜头 ≥3 维，关键近景/特写 ≥5 维）：

1. **微表情与视线**：瞳孔骤缩/缓慢扩张、睫毛颤动、视线失焦或重聚、咬肌收紧、嘴角肌理位移、眼睑抖动。
2. **肢体与体态**：重心前压或后移、双肩随呼吸起伏、指尖拧抓衣角、指节泛白、手腕紧绷、脚步半停。
3. **动作中间态**：欲言又止、抬手悬空、转身一滞、半步悬停、触碰前微顿、物件即将落下的未完成状态。
4. **生理应激**：喉结滚动、鼻翼微翕、额角筋络微凸、胸腔节律改变、吞咽停顿、呼吸短促。
5. **光影呼吸**：呼吸和体态变化带动皮肤/衣领/面部轮廓/眼窝阴影细微位移（`ambient light drift`）。
6. **物理交互与重力反馈**：肢体与道具/服装/地面交互遵守碰撞体积；急停时头发衣摆留惯性；搬重物时肌肉收紧+重心下压。

### 电商表演范式（4 个，借小逻「范式方法」，把抽象情绪翻译成连贯可见动作）

> 方法来自小逻「六维物理表演」的表演范式——每个范式是一段**连贯动作流**，不是关键词堆砌；写 PROMPT 时把范式「融进动作描述」，不得把范式名直接当画面写。以下 4 个覆盖电商带货高频情绪，替代「满足 / 惊喜 / 信任 / 种草」这类抽象词：

1. **种草回甘**（吃/喝类产品的品尝体验）：视线从手中产品移到镜头，眼睑放松，嘴角缓慢上扬；咽下后喉结轻微滚动，颈部放松；肩膀随一次长呼气下沉；侧光随抬颌在喉线与锁骨之间缓慢移动；手指在罐身上无意识地摩挲，留下轻微转动。
2. **惊喜感**（开箱/发现卖点）：眼睛缓缓睁大，眉毛上挑；身体不自觉地前倾半寸，拿着产品的手在半空一顿；随后唇角向两侧拉开，露出克制的笑；呼吸在停顿一拍后变浅；正面光随身体前倾在面部移动，眼神光更亮。
3. **信任背书**（达人/老板出镜推荐）：目光直视镜头，眨眼频率放缓；语速放慢，说话时下巴微微收拢；右手从身侧抬起，掌心摊开朝向镜头，停在中途；肩背挺直，重心稳定；光线在面部保持稳定，只有说话时嘴角与咬肌有轻微位移。
4. **满足体验**（使用后的享受感）：眼睛轻闭一秒后睁开，视线放松；肩线缓慢下沉，胸腔随一次深呼气回落；头微微后仰，嘴角带出放松的笑；后颈与椅背/靠垫之间留下真实挤压；环境光在面部停留，明暗缓慢过渡。

### 全局禁用抽象审美词（写任何 PROMPT 一律替换）

| 禁用 | 换成 |
|---|---|
| 高级感 / 氛围感 / 大片感 / 质感拉满 / 电影级光影 / 杰作 / 电影感 | 可见物理细节（材质/光影/构图/明暗具体化） |
| masterpiece / best quality / cinematic lighting / movie poster | 同上 |

### 运镜意图对照表（导演意图 → 各模型官方词，第 2 步查这张表）

> 官网核实（2026-08）：可灵官方运镜词 = 中文「航拍/特写/跟拍/环绕/缓慢推进/超大远景/长焦/景深」+ 少数英文 `pan/zoom/dolly/close-up/tracking shot`；Seedance 官方运镜词 = 「推/拉/摇/移/环绕/升降/跟随/倾斜/旋转/固定」+ 官方词典「固定镜头/镜头静止不动、手持拍摄/镜头晃动、镜头跟随、镜头环绕、镜头拉近拉远、镜头特写」。**没有** `locked-off tripod shot`/`subtle cinematic handheld` 这套词（那是小逻自造英文标签，勿套）。

### 各模型 PROMPT 翻译公式（导演意图 → 模型 PROMPT，第 2 步执行）

> 以下公式把导演决策的 4 件事（景别/运镜/表演/节奏）翻译成各模型官方 PROMPT 语法。**严禁跳过第 1 步直接写 PROMPT**——先定导演意图，再按公式翻译。

> **PROMPT 的正确关系**：官方公式规定模型可识别的语法、字段、时间轴、素材引用和能力边界；它们是**翻译规则，不是内容替代品**。先用确认剧本、分镜、台词、资产、路由和时长决定“这条镜头实际要什么”，再翻译成目标模型官方格式。任何为了套公式而删台词、改产品事实、增加无关动作或混用其他模型字段的写法都不合格；最终统一按 `prompt-delivery-contract.md` 验收。

#### Seedance 2.0 / 2.5 翻译公式

```
导演意图 → Seedance PROMPT：
  景别 → 写入「镜头描述」板块每镜开头
  运镜 → 查「运镜意图对照表」Seedance 列，嵌入每镜描述
  表演 → 六维物理动作写入画面描述（禁情绪词），电商范式「融进动作」
  节奏 → 快节奏 1-2s/镜密集跳切，慢节奏 3-5s+/镜少切
  格式 → 强制六板块骨架（角色+参考图/背景/镜头/声音/风格/禁止项）
  声音 → 环境音/动作音效+对白三子项全写，禁止空白；不写 BGM（默认不生成背景音乐）
  @引用 → 每个 @带"仅"字限定用途
  尾巴 → 避坑后缀（无抖动、无失焦、运镜流畅……）
```

#### Seedance 2.0 Mini 翻译公式

```
导演意图 → Mini PROMPT：
  景别 → 省略景别术语，用画面描述暗示（"手持产品靠近镜头"=特写感）
  运镜 → 查「运镜意图对照表」Mini 列，嵌入一句话
  表演 → 砍到 1-2 个核心物理细节（Mini 一句话公式写不了复杂表演）
  节奏 → 时间戳分镜，快节奏 1-2s/分、慢节奏 3-5s+/分
  格式 → 一句话公式：主体+运动，背景+运动，镜头+运动
  时间戳 → **正文必须含连续的 0-Xs 分段**，覆盖 Phase 7.5 计划的完整叙事段长；缺时间戳或未覆盖计划段长即不合格。常见 15s 只是版本快照，以用户当前 UI/API 为准。**例外：P2/P3 产品镜不套“写满最大时长”要求，按 Phase 7.5 独立短镜（1-3 秒）并走产品参考重注入或真实资产微动/合成。**
  禁止 → 严禁套用六板块！严禁套六板块标题！
  @引用 → @图片1 作为产品主视觉 / @图片1 为首帧
```

#### 可灵 Kling 翻译公式

```
导演意图 → 可灵 PROMPT：
  景别 → 中文写景别（中近景/特写/全景），英文写镜头参数（85mm f/1.4）
  运镜 → 查「运镜意图对照表」可灵列，中文+少量英文
  表演 → 体态/动作中间态/物理反馈重点写；微表情/生理应激面部少写（可灵脸"锁得住动不了"）
  节奏 → 快节奏分镜标 1-2s/格、慢节奏 3-5s+/格
  格式 → 分镜标签时间轴 [0s-5s 画面]：[动作+镜头+光线+声音]
  语言 → 中文场景+英文技术参数混合
  真人 → **选可灵即免素描**，直接走 I2V/O3 授权真人照片/视频参考 + 口型同步；参考可用已确认黑白素描（Seedance/H3），或用户另行提供并授权的真人照片/视频（可灵主路径）
  禁止 → 严禁套用六板块！严禁套 Mini 一句话！严禁套 H3 英文字段！
```

#### MiniMax H3 翻译公式

```
导演意图 → H3 PROMPT：
  景别 → 英文写景别（Close-up/Medium Shot/Wide Shot）
  运镜 → 查「运镜意图对照表」H3 列，英文术语
  表演 → 英文落地：在 detailed_description 内写微表情/体态/动作
  节奏 → 快节奏分段描述按时间戳分节
  格式 → 关键帧模式=3 字段（对齐指令+integrated_multimodal_description+overall_soundscape+non_diegetic_music）；**non_diegetic_music 为配乐，本 SKILL 默认不生成 BGM，禁 BGM 时该字段填 N/A 或不输出**
         全能参考模式=6 区段（subject_definitions/summary/retention_analysis/detailed_description/…）
  口播路由 → 凡含口播/对白，强制 Ref2VA（即便单图，keyframe completion 锚定首帧），对白落 detailed_description；关键帧模式无对白字段，禁用于口播视频
  慢动作 → 间接实现（slow zoom 运镜术语+高帧率后期放慢，无直接开关）
  禁止 → 严禁套用六板块！严禁套可灵分镜标签！
```

### 各模型表演 / 运镜能力边界（落地要点，详见各模型文件）

| 模型 | 六维表演能写多少 | 分级运镜 |
|---|---|---|
| **可灵 Kling** | **身份一致强、微表情弱**（I2V 锁脸，但脸「锁得住动不了」）——六维里依赖脸的部分（微表情/生理应激面部）少写，重点写体态/动作中间态/物理反馈 | 中文运镜词 + pan/zoom/dolly/close-up |
| **Seedance 2.0/2.5** | **真人还原低，微表情同样不稳**——重点写体态/动作中间态（不依赖脸），微表情少写 | 官方运镜词 + 避坑后缀 |
| **Seedance Mini** | **砍到 1-2 个核心物理细节**（一句话公式写不了复杂表演） | 一句话嵌 1 个运镜词 |
| **H3** | **英文落地**：在 `detailed_description` 内写体态/动作中间态为主，微表情仅限动作型面部中间态（嘴角随说话微动等），禁情绪渲染型微表情 | 英文运镜术语清单 |
