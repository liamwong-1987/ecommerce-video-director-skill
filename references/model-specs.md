# 四模型能力对比与 PROMPT 格式总览

## 能力对比

| 维度 | Seedance 2.0 | Seedance 2.0 Mini | Seedance 2.5 | MiniMax H3 |
|------|-------------|-------------------|-------------|-----------|
| 单次时长 | 4-15s | 4-15s | **30s**（超长 180s） | 4-15s |
| 参考图片 | 9 张 | 9 张 | **30 张** | 9 张 |
| 参考视频 | 3 段 | 3 段 | 10 段 | 3 段（各 2-15s） |
| 参考音频 | 3 段 | 3 段 | 10 段 | 3 段（各 2-15s） |
| 素材上限 | 约 12 个 | 约 12 个 | **50 个** | 12 个 |
| 分辨率 | 720p-1080p | 2K | 720p-1080p | **最高 2K**（2560×1440） |
| 音频 | 后配 | 后配 | 后配 | **原生 32kHz 立体声**（音画联合生成） |
| 时间戳控制 | 无 | **有**（9s+ 推荐） | **有** | 无 |
| 首尾帧模式 | 无 | 无（靠图生视频造首帧） | 无 | **有**（I2VA/L2VA/FL2VA） |
| 成本 | 标准 | **减半**（≈0.5元/s，flex 离线再省 50%） | 标准 | 标准 |
| 速度 | 标准 | **更快** | 标准 | 标准 |
| 画质 | 标准 | 略低于标准版（电商/营销够用） | 标准 | 标准 |
| Prompt 上限 | - | - | - | 7000 字符 |
| 宽高比 | 16:9/9:16/1:1 | 16:9/9:16/adaptive | 16:9/9:16/1:1 | 21:9/16:9/4:3/1:1/3:4/9:16 |

## PROMPT 格式（四模型完全不同，必须区分）

| 模型 | 语言 | 格式 |
|------|------|------|
| Seedance 2.0/2.5 | **中文** | 六板块 + @图片N 引用 |
| Seedance 2.0 Mini | **中文** | 一句话公式（主体+运动，背景+运动，镜头+运动）+ @引用 + 时间戳 |
| MiniMax H3 关键帧模式 | **英文** | 对齐指令 + 3 字段 |
| MiniMax H3 全能参考模式 | **英文** | 6 区段 |

> **⚠️ Mini 的关键坑**：不要套用 2.0/2.5 的六板块格式。Mini 用简洁一句话公式，塞六板块标题会干扰生成、浪费次数。详见 `seedance-mini-prompt.md`。

## 2.0 / Mini 超 15s 时长衔接方案

Seedance 2.0 和 Mini 单段 4-15s，做 30s+ 时分段衔接：

**2.0**：用「多段 + 尾帧高清重绘衔接」（默认方案）——截取尾帧 → 重绘高清 → 校验 → 当首帧。详见 `seedance-prompt.md` 第十节。

**Mini**：优先用「视频延长」直接续写（`将@视频1延长Xs`），不做尾帧重绘——Mini 本身画质略低，重绘收益有限。详见 `seedance-mini-prompt.md` 第六节。

## 选择逻辑

1. **要 30s+ 长视频 / 多素材 / 时间戳控制** → Seedance 2.5
2. **要原生立体声 / 首尾帧 / 2K / 性价比** → MiniMax H3
3. **沿用已有 2.0 工作流 / 稳定成熟** → Seedance 2.0
4. **成本优先 / 批量快速生成 / 电商营销 A/B 测试** → Seedance 2.0 Mini

**注意**：同一脚本按模型转不同格式，不要混用。详细规范见 `seedance-prompt.md`、`seedance-mini-prompt.md` 和 `h3-prompt.md`。
