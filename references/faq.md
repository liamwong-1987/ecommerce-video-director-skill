# 常见问题与避坑速查（FAQ）

> 本文件把散落在各 reference 里的避坑提示与高频问题收拢成一张速查表，按「问题 → 答案 → 详细出处」组织。详细规范仍以对应文件为准。

## 一、模型选择类

**Q：Seedance 能做真人视频吗？**
能做写实真人，只是人物还原度较低（可灵约 95 分、Seedance 约 75 分），不是"不能做"。真人出镜推荐可灵（还原度最高）。出处：`model-specs.md` 通用前置对比表。

**Q：人物资产为什么必须是黑白素描？**
因为本 SKILL 的人物资产交付规范就是黑白铅笔素描 / 黑白线稿，便于统一资产视觉并避免生成真人照片。人物参考图只定义姿态、构图、服装或发型结构，不用于锁脸或真人身份复刻。视频 PROMPT 是否使用真实人物风格，必须按用户要求单独确认，不能反向改人物资产。出处：`asset-workflow.md`。

**Q：Seedance 2.0 Mini 能套 2.0/2.5 的六板块格式吗？**
不能。Mini 用一句话公式（主体+运动，背景+运动，镜头+运动），塞六板块标题会干扰生成、浪费次数。出处：`seedance-mini-prompt.md`。

**Q：可灵能套 Seedance 六板块 / Mini 一句话 / H3 英文字段吗？**
不能。可灵用「分镜标签时间轴 + 中文场景英文参数」，且真人口播必须走 I2V 身份锚定 + 口型同步。出处：`kling-prompt.md`。

**Q：客户输入模糊、跳过问题、急着要结果怎么办？**
走快速通道，但只能对可默认项使用默认值；不可默认的阻塞项必须先补齐。进剧本前一次性报客户确认，不逐问。

**不可默认的阻塞项**：真实产品素材是否已经提供、目标平台与发行区域、视频时长、是否真人出镜、是否纯提示词/生成模式、产品是否涉及受监管品类、包装文字和 Logo 原文是否齐全、客户素材/肖像/商标是否有使用授权。产品默认按真实包装保真做，不把“要不要真实”当成问题。

**可默认但必须标注的字段**：画幅（默认 9:16）、语言（按平台/区域）、镜头节奏、BGM 偏好、是否批量。

**必须先补齐、不能拿概念方案顶替的字段**：高清产品 PNG、完整包装文字、真实价格/优惠、品牌规范、平台账号信息。产品真实素材或包装原文缺失时，暂停正式电商视频流程，不能生成相似产品或把概念图当正式产品。

**优先级**：用户明确指定的平台/风格 > 用户明确指定的视频类型/场景包 > 区域默认 > 全局默认。

**Q：能直接出视频吗？**
当前纯提示词模式只交付提示词包 + 资产 SPEC，不内置生视频 API 对接。生成模式是架构侧接入 API 后的扩展工作流。无论哪种模式，电商产品都必须使用真实产品素材，不能用相似产品或概念包装顶替。出处：`SKILL.md`「能力模式」。

**Q：数字人方案接吗？**
不接。本技能只接 5 个视频生成模型（Seedance 2.0 / 2.0 Mini / 2.5、MiniMax H3、可灵 Kling）。出处：`SKILL.md` Phase 0。

## 二、分镜图与产品文字类

**Q：所有视频都必须出分镜图吗？**
必须。产品视频、人物口播、剧情、品牌片、纯氛围、动画/3D、无产品视频全部必须出整张 3×3 宫格分镜图。分镜图由 AI 单次直出整张，不允许拼合；分镜图不合格就整张重跑；用户未确认分镜图与逐格台账前，不得进入视频 PROMPT 或视频生成。

**Q：产品包装上的字要不要写进 PROMPT？**
必须。只要资产图、分镜图或视频镜头要求看见包装文字、Logo、型号、配料表、酒精度或固定版式，就必须把客户确认的包装原文逐字写进对应 PROMPT。没有确认原文不能猜写，只能标记待补；逐字写入是约束模型和验收的依据，但 P3 仍必须用真实产品资产、微动或合成兜底。

## 三、节奏类

**Q：快节奏视频 = 画面里人物动作飞快吗？**
不是。剪辑节奏（镜头切换快慢）与镜头内运动速度（动作快慢/升格慢动作）是两个概念。手表 TVC 可以 2 秒一切（剪辑快），但静物细节展示用升格慢动作表达。出处：`SKILL.md` Phase 3、`model-specs.md`「节奏控制能力对比」。

**Q：哪个模型做慢动作/升格最好？**
Seedance 2.5（时间锚点精确变速 + 停帧 + 动效画板速率曲线）最强；可灵原生支持（`slow motion` + 60fps）；Seedance 2.0/Mini 提示词级；H3 是间接实现（高帧率后后期放慢，无直接开关）。出处：`model-specs.md`。

**Q：可灵能在一个镜头里前半段慢速后半段快速吗？**
不能。可灵 Multi-Shot 每个镜头是固定速度，单镜头内不支持变速。要同一镜头内变速，需拆多个镜头或用 Seedance 2.5 时间锚点。出处：`kling-prompt.md`「节奏/速度控制」。

## 三、合规类（高频踩坑）

**Q：提示词能写"最 / 第一 / 100%"吗？**
不能。极限词禁用，改写"行业领先 / 头部"。出处：`SKILL.md` Phase 5 规则 A。

**Q：能写微信号 / 二维码 / 外链吗？**
不能。引流导流是硬红线，小红书《交易导流违规管理细则》与抖音公约都封。出处：`SKILL.md` Phase 5 规则 F。

**Q：招商 / 加盟 / 代理 / 投资能写吗？**
实测触发"内容可能包含敏感信息"报错（硬敏感）。改"开店 / 合作 / 品牌宣传"等中性词。出处：`SKILL.md` Phase 5 规则 G。

**Q：能写"后期配音 / 加 BGM / 剪映处理"吗？**
不能。音频由模型原生生成，禁止"后期叠加 / 后期添加"指示。出处：`SKILL.md` Phase 5 规则 I。

**Q：AI 生成内容要标注吗？**
要。小红书标"AI创作"，TikTok 标 AI 生成/编辑，抖音按平台 AI 规范显著标识，YouTube 用"披露 altered or synthetic content"工具。出处：`SKILL.md` Phase 5 规则 J。

## 四、写提示词类（高频浪费次数的坑）

**Q：为什么提示词要写"这几秒发生什么"而不是"画面长什么样"？**
因为你要的是一段视频不是一张照片，模型要时间变化，不是静止一帧。出处：`seedance-prompt.md` 第十二节。

**Q：参考图上传了但效果不对？**
每个 @引用必须标注用途，且用"仅"字限定（`@图片1 仅定义角色的面部和绿色外套`），否则背景/路人/多余颜色会被带进来。出处：`seedance-prompt.md` 第二节。

**Q：一拍能叠三个运镜动作吗？**
不能。每个节拍只选一个运镜动作，叠加会打架。出处：`seedance-prompt.md` 第六节。

**Q：可灵写"无文字"为什么反而生成文字？**
否定会召唤——不写"无 X"，直接描述存在的东西（"无文字"→"画面纯净无叠加元素"或干脆不提）。出处：`kling-prompt.md` 避坑清单。

**Q：长片段做到一半脸变了？**
每 2–3 段用原始参考图/视频重新锚定身份；单段按模型单次最大时长写（可灵 15s，不拆 5 秒），超 15s 续写时重新锚定。出处：`kling-prompt.md` 避坑清单。

**Q：口播台词对不上嘴型？**
台词 <10 词 + 锁定镜头 + 减少头部转动和手部动作。出处：`kling-prompt.md` 第四节。

## 五、衔接类

**Q：视频超过 15s 怎么拼？**
按 Phase 7 分镜「尾帧衔接」列判定：跳切段直接新景别独立生成；连续段强制「尾帧高清还原 + 校验-重试闭环」（至少 2 次、至多 3 次，直到一致），绝不用低清尾帧直接当首帧。出处：`SKILL.md` Phase 11、`model-specs.md`「超 15s 时长衔接方案」。

**Q：尾帧高清还原能跳过吗？**
不能。这是强制步骤，不存在"画质够就跳过""漂移就回退截图当首帧"的退路；3 次仍不一致上报用户，不静默降级。出处：`SKILL.md` Phase 11。
