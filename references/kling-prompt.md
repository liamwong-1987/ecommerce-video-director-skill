# 可灵 Kling 提示词规范（第 5 个视频模型）

> 适用：真人口播 / 探店 / 真实模特出镜 / 情绪肖像。可灵真人还原度最高，Seedance 能做写实真人但还原度较低，这是两者的核心差距（可灵明显更高）。
> 本文件的版本名、帧率、时长和素材数量是编写时快照；执行时以用户当前可灵 UI/API 与账号能力为准。**可灵路径免产黑白素描**，选定可灵即直接以授权真人照片/视频作 I2V 身份锚定；Seedance/H3 路径正式人物资产仍为黑白素描，素描本身可以生成真人感视频，用户另行提供且授权的真人照片/视频也可作为生成输入。

## 0. 路由铁律（先读）

| 镜头职责 | 可灵的适配性 | 正确用法 |
|-----------|-----------|-----------|
| 真实模特 / 主播口播 / 探店 / 真人脸出镜 | 强 | O3/I2V 锁人物身份，模型负责人物和叙事 |
| P2 产品动作镜 | 较强 | O3 多图参考；每镜独立 1-3 秒，重新注入 `P-HERO`/真实产品参考，受控动作 |
| P3 SKU 保真镜 | 不承担包装重画 | 真实 `P-PACKSHOT`/实拍/合成保留产品，模型只做微动与环境 |
| 非真人 / 动画 / 虚拟形象 | 可用 | 按 Phase 7.5 的镜头职责与预算路由 |

> **原因**：可灵 I2V + 多参考让真人多镜头身份还原较强，也适合参考驱动的产品动作镜；但它和其他生成模型一样，不能保证真实包装的文字、Logo、固定版式。客户确认的是“每条生产线的模型”，而不是让某一个模型替全片承担不擅长的 SKU 保真职责。

### P2 产品动作镜模板

```text
[0s-2s 画面]：@图片1 仅定义同一真实产品的外观。冰箱冷白光内，细高哑光白色铝罐保持正面朝向镜头，被手缓慢取出。
镜头：特写，缓慢推近，close-up, slow dolly in。
约束：只允许轻微位移，罐体旋转不超过 15 度，手部遮挡不超过罐身 30%；产品外观、比例、朝向、位置与参考图 100% 一致，保持轮廓、主色、主要色带和主要图形；不要求生成可读小字或精确 Logo。“100%一致”是模型强约束，实际仍按 P2 标准验收。
```

### P3 SKU 保真镜模板

```text
[0s-2s 画面]：@图片1 仅定义真实 SKU 正面包装，保持其 Logo、文字、色块和版式原样作为前景主体。背景为冰箱冷白光与浅景深，罐身有轻微冷凝水反光。
镜头：固定特写，slow dolly in。
约束：只允许镜头缓慢推进、光影与冷凝水变化；不旋转、不重绘、不替换包装信息。
```

## 1. 模型版本（选哪个）

| 版本 | 官方名 | 分辨率 | 时长 | 定位 |
|------|--------|--------|------|------|
| **V3** | Video 3.0 | 最高 4K（60fps） | 最长 15s | 提示词优先，从零生成电影级镜头；Multi-Shot 一次最多 6 镜头自动切换；原生音频 + 口型同步（5 语言）；结束帧控制；**不支持 V2V 编辑** |
| **O3** | Video 3.0 Omni | 最高 4K | 15s | 参考驱动：多图参考（无参考视频时参考图+主体 ≤ 7 张，有参考视频时 ≤ 4 张）+ 视频参考 + V2V 编辑（风格迁移/背景替换/角色替换）；多角色共指（3+ 角色）；原生音频 + 口型同步 |
| **3.0 Mini** | — | 待平台确认 | 待平台确认 | 低价版（约 0.80 元/秒，对标 Seedance 2.0 Mini）；详细参数待平台确认 |

> 电商真人口播 / 探店优先 **O3**（多图 Omni 参考锁脸 + 口型同步 + 原生音频最稳，且支持 V2V 编辑）。从零生成多镜头叙事用 **V3**；成本敏感批量用 **3.0 Mini**。

## 2. PROMPT 格式（时间轴 / 分镜标签，非六板块）

可灵用「分镜标签语法」，和 Seedance 六板块、Mini 一句话公式、H3 英文字段**完全不同，不可套用任何一个**。

**默认混合语言**：**中文写场景 / 动作 / 情感 / 声音 / 约束，英文写摄影机型号 / 镜头参数 / 运动术语 / 色彩风格**（一句话：中文场景 + 英文技术参数）。

**单段时长（铁律）**：一个 PROMPT 覆盖可灵**单次最大时长 15s**，时间轴在 15s 内细分；**不拆成 5 秒一段单独生成**。只有超过 15s（30s）才走第六节「时长衔接」续写。

### 真实视频风格总锁（真人/真人感镜头必写）

可灵的官方时间轴和 I2V 公式负责让模型理解镜头、参考和音画关系；每条 PROMPT 的具体内容必须仍以确认剧本、分镜、资产和镜头职责为准，不能机械套模板。

```text
视频视觉风格：真实摄影/实拍质感，写实真人，真实皮肤纹理、真实服装材质、自然环境光和可信物理接触，镜头运动符合真实拍摄惯性。
```

（Seedance/H3 路径）黑白素描只用于人物资产图审核与身份锚定，不能成为最终视频风格；**可灵路径直接用授权真人参考，不产出素描**。人物镜头不能默认生成插画、动漫、黑白素描、3D 人物、CGI 人物、数字人或塑料皮肤；`13 动画/3D 演示`是已确认的非真人产品路线，单独按路由执行。

### 台词绑定硬规则

- 凡写“说话/口播/介绍/回答/对镜讲解/张嘴表达”，对应时间轴必须紧邻写入：`[角色ID]用[语言]说：“[确认剧本原话]”`。
- 台词只能从确认剧本复制；不得改成“自然口播”“介绍产品”等概括语。
- 一句话控制在 1.5-2.5 秒、短分句优先。超时只按自然停顿拆到相邻时间轴，原话不得删改；影响节奏时回剧本层确认。
- 画外音写“画外音用[语言]说：‘[原话]’，画面内角色双唇保持闭合”。
- 无台词镜必须写“无对白，仅[环境音/动作音]”；不得留下人物是否发声的歧义；默认不含背景音乐。


```
[0s-5s 画面]：
@人物参考图仅定义女主播身份与服装；女主播以真实摄影质感站在咖啡店门口，手持产品看向镜头。
女主播用中文说：“[确认剧本中的第一句原话]”。
镜头：中近景，固定镜头，85mm f/1.4 浅景深。
光线：午后暖阳光从右侧打入，脸部自然明暗过渡。
声音：清晰中文口播与台词同步，咖啡店环境音，结尾一声杯子轻碰。

[5s-10s 画面]：
女主播举起产品靠近镜头，展示包装细节。
女主播继续用中文说：“[确认剧本中的第二句原话]”。
镜头：特写，缓慢推近，100mm f/2.8 微距。
光线：柔和正面补光，产品表面反光清晰。

[10s-15s 画面]：
女主播收势微笑，画面定格在产品与笑脸同框。
女主播用中文说：“[确认剧本中的收尾原话]”。
镜头：中景，固定镜头，最后 1 秒轻微变焦。
视频视觉风格：真实摄影/实拍质感，真实皮肤纹理、自然光影与真实服装材质。
约束：保持女主播面部结构不变，产品外观与参考图一致，画面纯净无叠加元素。
```

### 分镜标签
- 单镜头：一个 PROMPT 写满 15s，`[0s-15s 画面]：...`
- 多镜头（V3/O3）：一个 15s PROMPT 内用时间轴细分，`[0s-5s 画面]：...` / `[5s-10s 画面]：...` / `[10s-15s 画面]：...`，每段一个镜头一个节拍，续接点写清（同场景 / 光线 / 角色特征）。

### 节奏/速度控制（V3/O3 原生 60fps）

可灵 3.0 系列原生 60fps，支持用提示词控制**镜头内运动速度**（区别于 Multi-Shot 的「剪辑节奏」——镜头切换快慢）：

- **慢动作（升格）**：提示词写 `slow motion` / `slow-motion`，配合官方建议的 "deliberate, steady movement"（刻意、平稳的动作）。60fps 输出确保放慢后无 judder 伪影。
- **快动作**：`fast camera, high energy` / `quick cut`；60fps 保证快速动作流畅。
- **能力边界（诚实标注）**：Multi-Shot 每个镜头是固定速度/时长，**单个镜头内不支持速度变化**（不能前半段慢速、后半段快速）。要「同一镜头内变速」，需拆成多个镜头分别控制，或用 Seedance 2.5 的时间锚点变速。

> 节奏调研结论见 `model-specs.md`「节奏控制能力对比」；Phase 7 分镜「运动速度」列在此落地为慢动作/快动作关键词。

## 3. I2V/O3 人物参考（真人镜头必用）

真人口播 / 探店必须走 I2V/O3 参考驱动。**可灵路径免产素描**，直接以用户授权的真人照片/视频作 I2V 身份锚定；也可把已确认黑白素描（Seedance/H3 路径资产）还原为真人感视频：

1. **已确认黑白素描（Seedance/H3 路径资产）**：使用 Phase 8 已确认的正式人物资产，PROMPT 写清仅参考人物结构、发型、体型与服装，并要求成片转换为真实摄影风格。
2. **授权真人素材（可灵主路径）**：选定可灵时直接以此作 I2V 身份锚定——上传清晰正脸/半身照片或当前界面允许时长的真人视频作身份参考，适合固定主播/模特反复出镜。
3. **服装 / 产品参考**：用参考图锁定服装颜色、产品外观（「产品身份不变」）。

> **可灵路径免产素描**：Phase 8 正式人物资产（非可灵路径）仍是 **1 张 1×3 黑白素描三视图**，编号 `图N`；可灵路径下授权真人照片/视频直接作主身份参考，不要求先产素描。授权真人照片/视频不替代、不改写 Seedance/H3 路径的正式人物资产交付。

## 4. 口型同步 + 原生音频（口播核心）

可灵 3.0 系列（V3/O3）支持「图片 + TTS / 音频 → 说话口型」，且音视频一体生成（口型与语音联合求解）。

**对话写法**：
- 台词放引号、标说话者：`角色 A 保持静止，锁定中近景，说："[台词]"`
- 对话时：锁定镜头、减少头部转动、减少手部动作
- 一句话 ≈ 1.5-2.5s；中文口型效果好，英文次之
- 对话 >10 词容易口型错位 → **口播台词控制在短分句**

**音频（画内真实音，默认不含背景音乐）**：环境音层（空间感）+ 动作音效层（时间感）。声音要具体到「什么物体 + 什么动作 + 什么材质 = 什么声音」；不写情绪音乐层/配乐（BGM）。

```
声音：雨打钢架的密集声，远处交通底噪，结尾一声轻柔杯子碰触。
音效：开罐时的气体释放声、液体倒入杯中的细密水声。
```

## 5. 避坑清单（必看）

| 坑 | 现象 | 处理 |
|----|------|------|
| **否定会召唤** | 写「无 X」反而生成 X | 不写「无 X」，直接描述存在的东西（如「无文字」→ 换「画面纯净无叠加元素」，或干脆不提） |
| 对话口型错位 | 嘴型对不上 | 台词 <10 词 + 锁定镜头 + 减少头部转动 |
| 长片段身份漂移 | 脸随时间漂移 | **每 2–3 段用原始参考图 / 视频重新锚定身份**；单段按最大 15s 写，超 15s 续写时重新锚定 |
| 手部不稳定 | 手变形 | 减少复杂手部动作；手放口袋 / 桌面 / 身后 |
| 面部微表情弱 | 近景脸僵 | 用身体 / 姿势传情绪；近景减少大动作 |
| 文字 / logo 漂移 | 字糊 | P3 使用真实包装 PNG/实拍/受控合成；不要让生成模型重画 |
| 多主体互相干扰 | 脸串味 | 选 1 个主角，其余读成形状 / 轮廓 |

## 5.5 六维表演与官方运镜词（可灵身份一致强、微表情弱）

可灵 I2V 锁脸能力最强（同一个人不变脸），但**微表情是弱项**（脸「锁得住动不了」）——六维表演里依赖脸的部分少写，重点写不依赖脸的体态/动作中间态/物理反馈（详见 `model-specs.md`「导演思维公式」→「各模型能力边界」）：

- 情绪禁抽象词，用可见生理细节：重心前压、双肩起伏、指尖收紧、脚步半停、呼吸带动的光影位移（`ambient light drift`）等。
- 动作优先「中间态」：抬手悬空、转身一滞、欲言又止，不写已完成的静态结果。
- **微表情少写**（可灵面部微表情弱）：不写「瞳孔骤缩、睫毛颤动」这类依赖脸的细节，用身体/姿势传情绪。
- **手部细节谨慎**（可灵手不稳定）：手放口袋/桌面/身后，少复杂手部动作。

**运镜意图 → 官方词**（对照 `model-specs.md`「运镜意图对照表」，中文为主 + 少数英文，勿套小逻英文标签）：

| 导演运镜意图 | 可灵官方词 |
|---|---|
| 特写要「稳」 | 固定镜头 + 特写（close-up） |
| 中近景要「轻手持+惯性」 | 缓慢推近 / 镜头跟随 |
| 全景要「呼吸感/纪实」 | 航拍 / 环绕 / 缓慢推进 |

## 6. 时长衔接（>15s 用「视频续写」）

可灵单段最长 15s。需要 30s+ 时，**仅当分镜（Phase 7）标记「尾帧衔接 = 是」的连续段**走**视频续写**（从上一片段最后一帧续接，原生高清，**不允许在衔接处用低清尾帧糊弄**）；跳切段（分镜标「否」）直接新景别独立生成，不取尾帧。**不是 Seedance 的尾帧重绘**：

1. 按自然停顿拆 15s 内每段，每段独立写提示词（可灵时间轴格式）
2. 生成段1 → 导出
3. 用段1 尾帧作为段2 的首帧参考，PROMPT 写「从这张帧无缝继续」
4. **每 2–3 段用原始参考（图 / 视频）重新锚定身份**，防漂移
5. 音频不跨片段连续 → 在生产说明中列为受控剪辑层统一复杂音效（默认不含配乐）；不要把“后期添加”写进视频模型 PROMPT 正文

## 7. 去哪生成

可灵提示词产出后，去可灵平台生成（网页 klingai.com 粘贴，或接入 API / MCP 自动出片——按你的接入方式）。原生音频在生成时一并产出，无需后期配音。
