# 可灵 Kling 提示词规范（第 5 个视频模型）

> 适用：真人口播 / 探店 / 真实模特出镜 / 情绪肖像。可灵真人还原度最高，Seedance 能做写实真人但还原度较低，这是两者的核心差距（可灵明显更高）。

## 0. 路由铁律（先读）

| 用户要的是 | 用哪个模型 |
|-----------|-----------|
| 真实模特 / 主播口播 / 探店 / 真人脸出镜 | **可灵**（Seedance 能做写实真人但还原度较低，高一致性真人建议可灵；人物资产可黑白素描过审） |
| 非真人 / 产品 / 动画 / 虚拟形象 | Seedance / Mini / H3（按原逻辑选） |

> **原因**：Seedance 能做写实真人但还原度较低，高一致性真人（口播/探店要求脸不变）建议走可灵，不要套 Seedance。

## 1. 模型版本（选哪个）

| 版本 | 分辨率 | 时长 | 何时用 |
|------|--------|------|--------|
| v2.5-turbo | 720p-1080p | 5/10/15s | **口播 / 探店 / 真实模特默认**：Omni 多图 + 口型同步 + 原生音频 |
| v3 | 1080p | 5/10s | 多镜头叙事、旗舰画质（每 shot ≤5s，最多 6 shot） |

> 电商真人口播 / 探店优先 **v2.5-turbo**（口型同步 + 原生音频最稳）。

## 2. PROMPT 格式（时间轴 / 分镜标签，非六板块）

可灵用「分镜标签语法」，和 Seedance 六板块、Mini 一句话公式、H3 英文字段**完全不同，不可套用任何一个**。

**默认混合语言**：**中文写场景 / 动作 / 情感 / 声音 / 约束，英文写摄影机型号 / 镜头参数 / 运动术语 / 色彩风格**（一句话：中文场景 + 英文技术参数）。

```
[0s-5s 画面]：
一个穿米色风衣的女主播站在咖啡店门口，手持产品对镜头说话。
镜头：中近景，locked-off 锁定，85mm f/1.4 浅景深。
光线：午后暖阳光从右侧打入，脸部明暗分明。
声音：咖啡店环境音，结尾一声杯子轻碰。
约束：保持女主播面部结构不变，无文字，无水印。
```

### 分镜标签
- 单镜头：`[0s-5s 画面]：...`
- 多镜头（v3）：`[0s-3s 画面]：...` / `[3s-7s 画面]：...`，每段一个镜头一个节拍，续接点写清（同场景 / 光线 / 角色特征）。

## 3. I2V 身份锚定（可灵最强能力，必用）

真人口播 / 探店必须走 I2V（图生视频），用参考图 / 视频锁身份：

1. **单图锁脸**（基础）：给 1 张清晰正脸 / 半身图，PROMPT 写「保持面部结构不变」。
2. **多图 Omni（推荐，最稳）**：上传 **3–8 秒真人视频**提取人物特征，比单图锚定稳定得多 → 适合固定主播 / 模特反复出镜。
3. **服装 / 产品参考**：用参考图锁定服装颜色、产品外观（「产品身份不变」）。

> Phase 8 资产：真人口播须产出 **1 张清晰正脸锚点图**（或 3–8s 真人视频），编号 `图N`，供可灵 I2V 锁身份。

## 4. 口型同步 + 原生音频（口播核心）

可灵 v2.5+ 支持「图片 + TTS / 音频 → 说话口型」，且音视频一体生成（口型与语音联合求解）。

**对话写法**：
- 台词放引号、标说话者：`角色 A 保持静止，锁定中近景，说："[台词]"`
- 对话时：锁定镜头、减少头部转动、减少手部动作
- 一句话 ≈ 1.5-2.5s；**中文口型最强**，英文次之
- 对话 >10 词容易口型错位 → **口播台词控制在短分句**

**音频三层**：环境音层（空间感）+ 动作音效层（时间感）+ 情绪音乐层（情感感）。声音要具体到「什么物体 + 什么动作 + 什么材质 = 什么声音」。

```
声音：雨打钢架的密集声，远处交通底噪，结尾一声轻柔杯子碰触。
音乐：大提琴低音区长弓，每个音之间留两秒空白，无节奏。
```

## 5. 避坑清单（必看）

| 坑 | 现象 | 处理 |
|----|------|------|
| **否定会召唤** | 写「无 X」反而生成 X | 不写「无 X」，直接描述存在的东西（如「无文字」→ 换「画面纯净无叠加元素」，或干脆不提） |
| 对话口型错位 | 嘴型对不上 | 台词 <10 词 + 锁定镜头 + 减少头部转动 |
| 长片段身份漂移 | 5s 后脸变了 | **每 2–3 段用原始参考图 / 视频重新锚定身份**；单段尽量 ≤5s |
| 手部不稳定 | 手变形 | 减少复杂手部动作；手放口袋 / 桌面 / 身后 |
| 面部微表情弱 | 近景脸僵 | 用身体 / 姿势传情绪；近景减少大动作 |
| 文字 / logo 漂移 | 字糊 | 文字 / logo 放后期；或用锁定镜头 + 光线运动 |
| 多主体互相干扰 | 脸串味 | 选 1 个主角，其余读成形状 / 轮廓 |

## 6. 时长衔接（>15s 用「视频续写」）

可灵单段 5-15s。需要 30s+ 时，**仅当分镜（Phase 7）标记「尾帧衔接 = 是」的连续段**走**视频续写**（从上一片段最后一帧续接，原生高清，**不允许在衔接处用低清尾帧糊弄**）；跳切段（分镜标「否」）直接新景别独立生成，不取尾帧。**不是 Seedance 的尾帧重绘**：

1. 按自然停顿拆 15s 内每段，每段独立写提示词（可灵时间轴格式）
2. 生成段1 → 导出
3. 用段1 尾帧作为段2 的首帧参考，PROMPT 写「从这张帧无缝继续」
4. **每 2–3 段用原始参考（图 / 视频）重新锚定身份**，防漂移
5. 音频不跨片段连续 → 统一配乐 / 复杂音效放后期

## 7. 去哪生成

可灵提示词产出后，去可灵平台生成（网页 klingai.com 粘贴，或接入 API / MCP 自动出片——按你的接入方式）。原生音频在生成时一并产出，无需后期配音。
