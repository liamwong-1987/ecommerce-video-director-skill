# Seedance 2.0 / 2.5 提示词规范

中文提示词。**2.0** 单次最长 15s（一个 PROMPT 写满 15s，超 15s 才多段+视频延长）；**2.5** 单次 30s（超长模式 180s，一个 PROMPT 写满 30s）。叙事氛围镜可按最大时长组织；但 Phase 7.5 标为 **P2 产品动作镜 / P3 SKU 保真镜** 时必须优先服从镜头路由：P2 单镜独立图生视频 1-3 秒，P3 用真实产品资产微动或合成，不能为了写满 15/30 秒让模型重画产品包装。

## 0. 产品镜路由（含产品时先判断）

- **P0/P1 叙事镜**：Seedance 可做人物、场景、酒液、情绪与产品局部；产品仅保留精简视觉 DNA，不要求包装正面可读。
- **P2 产品动作镜**：仅在已确认 Seedance 可作为该镜备选模型时使用。每镜独立生成、重新上传 `P-HERO` 或真实产品参考；只写 4-6 个大结构视觉 DNA + 动作边界。不要把 Logo、小字、精确字体或固定版式当作可保证目标。
- **P3 SKU 保真镜**：不使用 Seedance 重绘产品包装。用 `P-PACKSHOT` 真实产品资产做静帧微动/前景合成；Seedance 只生成场景、光影、景深、冷凝水、背景动态。

**P2 写法示例：**

```text
@图片1 仅定义同一罐装产品的外观：细高哑光白色铝罐、银色易拉环、大号金黄色“28”、罐身中下部黄色横向色带、白色麦穗大形状。
特写，冰箱冷白光，罐体保持正面朝向镜头，镜头缓慢推进；仅允许轻微位移，旋转不超过 10 度，手部不遮挡罐身正面。
不改变罐体比例、主色、主要色带和主要图形；不要求生成可读的小字或精确 Logo。
```

**P3 写法原则：**真实产品图保留为前景主体，提示词只描述“缓慢推近、冷凝水滑落、冰箱冷光反射、背景景深变化”等可运动内容；不要让模型负责罐身文字、Logo、包装版式。

> **规则来源**：六板块结构、@引用来自源 SKILL（seedance-director）；时间戳/括号/精准标注/语言标注/镜头运动命名/区域编辑来自 OpenArt《Seedance 2.5 Prompt Guide》（字节跳动官方示例措辞，2026-08 核实）。

## 一、六板块结构（每段提示词必须包含）

```
## 角色 + 参考图
- 角色A（主角）：@图片1 — [外貌、服装、年龄描述]
- 场景参考：@图片2 — [环境描述]
- 产品外观参考（P1/P2 按路由使用）：@图片3 — [仅定义产品视觉 DNA：轮廓/主色/材质/主要色块或图形；P2 取 P-HERO 或同一真实产品参考，并写清允许动作边界]；P3 不在此处要求模型重画包装，而是走 P-PACKSHOT 真实资产微动/合成链路。

## 背景介绍
[前情、环境、情绪氛围]

## 镜头描述
> ⚠️ 镜头时长必须随「剪辑节奏」走，禁止一律写 3-5s：
> - **快节奏**（抖音/小红书等带货短视频，硬要求）：每镜 1-2s，密集跳切，景别频繁切换
> - **慢节奏**（品牌 TVC 静物/高端）：每镜 3-5s+，少切、长镜头
> - 快节奏 ≠ 人物动作飞快：镜头内运动该升格仍升格，只是「切得勤、景别换得快」

[快节奏示例 —— 1-2s/镜，密集跳切]
镜头1（0-1s）：[景别]，[画面内容]，[运镜：硬切]
镜头2（1-2s）：[景别]，[画面内容]，[运镜：硬切]
镜头3（2-4s）：[景别]，[画面内容]，角色A [动作]，角色A："[台词]"，[运镜：微推]

[慢节奏示例 —— 3-5s+/镜，少切]
镜头A（0-3s）：[景别]，[画面内容]，[运镜：固定]
镜头B（3-6s）：[景别]，[画面内容]，[运镜：缓慢推近]

## 声音设计
- 音效（环境音+动作音）：[按时间段标注]
- 对白/旁白（二选一或混用，必须写完整文案；有发声镜头时必须标说话人、语言，并逐字复制确认剧本原话；无发声镜头写 `N/A（本镜无发声）`）

## 风格指令
[质感、色调、光线、景深]

## 禁止项
（模板，实际产出时按下方「负向约束强化」必带 3-5 条）
禁止出现文字、水印、电话号码、二维码
禁止在视频模型正文写“后期叠加/后期添加”等制作元指令（P3 合成、字幕和发布标签在生产说明单列）
【负向约束强化 · 必带 3-5 条，防止模型生成失控，缺则补全】
- 禁止人物肢体变形（手指多余、手部扭曲、关节错位、身体比例失真）
- 禁止面料穿模 / 撕裂 / 漂浮 / 扭曲（电商服饰类必带）
- 禁止额外人物或路人误入、主体身份突变、多人变一人
- 禁止霓虹光 / 卡通高饱和 / 伪 3D 渲染 / 塑料质感
- 禁止镜头抽搐（snap zoom）、恶意晃动、跳切突变、画面失焦
- 禁止品牌 logo / 文字标板叠加（品牌靠 @图片 与口播承载，见 §十七 IP 规则）
```

> **每块最低内容标准（缺任一则该板视为未完成，须补写后重交）**：
> - 角色 + 参考图：≥1 个 @引用，且每个都带"仅"字限定（如 `@图片1 仅定义腕表正面表盘`）；**含产品时必须另含产品外观参考图 `@图片N 仅定义产品外观（轮廓/主色/材质/包装形态/尺寸比例）`**
> - 背景介绍：≥1 句环境 / 情绪描述，非空白
> - 镜头描述：叙事氛围线覆盖目标模型计划时长；P2/P3 产品镜按 Phase 7.5 独立短镜执行，每镜含 景别 + 画面内容/动作 + 运镜
> - 声音设计：**环境音/动作音效 + 对白或旁白 两子项必须全写**，任一为空则该板不合格；不含 BGM（默认不生成背景音乐）
> - 风格指令：质感 / 色调 / 光线 / 景深 至少写全三项
> - 禁止项：≥1 条具体生成约束（如随机文字 / 水印 / 肢体变形）；受控后期步骤不写进视频模型正文

## 二、@引用规范（2.5 重点：精准标注"仅"字）

- 图片 1-9（2.5 支持 30 张）、视频 0-10 段、音频 0-10 段，共上限 50 个文件。
- 必须中文名称（`@图片1` 不是 `@image1`）。
- **每个 @引用必须标注用途，且用"仅"字限定你要的部分**，防止背景/路人/多余颜色被带进来：
  - ✅ `@图片1 仅定义角色的面部和绿色外套`
  - ✅ `@图片2 仅定义咖啡馆柜台和窗光`
  - ❌ `@图片1 定义这位女性`（会把背景一起带进来）
- **同一物体多角度分组**：多张图是同一物时明说，否则会被当成多个不同产品：
  - `@图片1 定义台灯正面；@图片2 定义同一台灯左侧；@图片3 定义同一台灯背面。三张图是同一盏灯，视频中只能出现一盏灯。`
- 单个视频里 8 个以内人物/产品最稳定；5-10 秒短参考片段比长片段效果好。

## 三、时间戳拆段（2.5 核心，2.0 不适用）

把 30 秒拆成时间点写进 prompt，比"开场是/接着/最后"更精准控制顺序与节奏：

```
0-5秒：厨师把空盘子放到台面，拿起一把勺子。
5-15秒：酱汁淋在盘子上，镜头缓缓推近。
15-25秒：一只手将三只扇贝逐一放下。
25-30秒：拉远至暖色顶光下成品菜肴的广角镜头。
```

三条规则：
1. **只用整秒**，绝不用半秒。
2. **时间轴无缝**：下一段从上一段结束处接续，不留空隙。
3. **每段只给一个明确动作**：塞太满会丢节拍，留空会被填进你没要求的内容。

时间戳不是计数器：描述"动作"而非重复次数（"一秒内点头三次"行不通）。

**2.0 差异**：2.0 读的是镜头编号而非时间戳，把 `0-5s` 改写成 `Shot 1`、`Shot 2` 即可。

### 节奏/速度控制（升格慢动作 / 快动作）

对应 Phase 7 分镜「运动速度」列。**2.5 用时间锚点变速，2.0 用提示词**：

- **慢动作（升格）**：
  - 2.5：时间锚点语法 `(0-3s 速度0.25x)`，可分段设置不同速度系数；支持「停帧」（速度=0，顿挫感）+ 动效画板速率曲线（缓入/强加速）。
  - 2.0：提示词写 `慢镜头` / `slow motion`，或导演模式「叙事节奏:慢镜头」参数。
- **快动作**：2.5 速度系数 `(3.3-7s 速度1.2x)`；2.0 提示词 `快剪辑` / `快节奏` / `fast motion`。
- **用途**：升格慢动作用于静物细节展示（手表/珠宝上手、美食特写），不是"画面切快"——剪辑节奏靠时间戳分镜，镜头内运动速度靠速度系数/提示词，两者分开。

## 四、声音括号体系（区分四类，避免乱成一团）

| 类型 | 括号 | 示例 |
|------|------|------|
| 音效 | < > | <远处传来钟声> |
| 配音台词 | { } | {Hello, welcome back.} |
| 画面字幕 | 【 】 | 【第一章】 |

- 不必每行都加括号；仅当一句普通话可能有两种读法（如台词被当成字幕）时用括号。
- 字节跳动较新示例常只用"引号 + 说话人名字"，也行。
- 关掉效果用大白话："无字幕""无背景音乐，保留房间原声"（有文档说明，可生效）。

## 五、语言与口音标注（配音说对语言）

- 同一 prompt 内所有台词用**同一种语言**，混用两种会出问题。
- 台词非英语/中文时，台词前注明语言：`她用日语说：{もう大丈夫です}`
- 要特定口音/表达方式，顺序：**语言和口音 → 说话方式 → 台词**：
  `Spoken language: American English. She says it fast and a little annoyed: {I told you this would happen.}`
- 开头就写明，比末尾加"美式口音"更可靠。

## 六、命名镜头运动

Seedance 能直接读镜头指令，写出来即可。有效词：跟拍、缓慢推近、大远景、手持、航拍、向前移动、环绕、变焦拉焦、低角度、俯视。

- **"电影感"不是运镜方式，无效**。
- **每个节拍只选一个运镜动作**，别一次堆三个；一个贯穿十秒的清晰运镜 > 三个互相冲突的动作。
- 可从已有片段复制运镜：上传视频参考并标注 `@视频1 仅用于定义运镜和节奏`。

**运镜动机动词（补密度 · 全中文）**：Seedance 原生强调"每个运镜都要有物理动机动词"，不要只写"跟拍/推近"这类孤立导演术语，要写清镜头**为什么动、贴着谁**：
- "镜头锁死主体、贴住模特不让其出画"（对应 lock-on / staying glued）
- "镜头随人物横移、始终框住上半身"
- "缓慢推近至腰头特写、不再平移"
- 原则：运镜词 + 主体锚定，模型拿到的可执行信号远多于孤立的"跟拍"。

## 七、关键原则

- 提示词只写画面内容和风格；宽高比、分辨率、时长在平台 UI 独立设置，不进正文。
- **描述场景与变化，而非静止瞬间**：说清 30 秒里发生什么，不是某一帧长什么样。
- **能展示的别用文字描述**：参考图承担外观，文字留给动作/运镜/节奏。
- 台词必须标注说话人（角色A："台词"）；对白/旁白全由模型生成，不走后期配音。
- 台词只能逐字逐标点复制确认剧本的原话。凡画面写了说话、口播、介绍、回答、对镜讲解或张嘴表达却没有完整台词，直接判定不合格；无对白时必须明确标 `N/A（本镜无发声）`，不得用“自然讲解”等概括语代替。
- 技术参数（宽高比/时长）不写进提示词正文。

## 八、活人感判断

| 场景 | 质感取向 | 写法 |
|------|---------|------|
| 种草/Vlog/日常 | 真实生活感 | 微动作、生活痕迹、手持微晃、自然反应 |
| 短剧/情感 | 视情况混合 | 日常戏活人感，高潮戏制作感 |
| TVC/品牌大片/电商产品 | 精致制作感 | 专业布光、稳定运镜、完美构图 |
| 科普/MV | 精致制作感 | CGI/卡点 |

## 8.5 六维表演（真人还原低，降级写）+ 官方运镜词

Seedance 真人还原度低于可灵，**六维物理表演降级**（详见 `model-specs.md`「导演思维公式」→「各模型能力边界」）：重点写不依赖脸的体态与动作中间态，微表情少写（脸容易漂）。

- 情绪禁抽象词，用可见生理细节：重心前压、双肩起伏、指尖拧衣角、脚步半停、抬手悬空、转身一滞（动作中间态优先）。
- **光影呼吸可写**：呼吸带动面部轮廓/眼窝阴影细微位移（`ambient light drift`）。
- **微表情少写**（脸还原不准）：不写「瞳孔骤缩、睫毛颤动」这类依赖脸的细节，改用身体/姿势传情绪。
- **微表情分级白名单**：禁「情绪渲染型微表情」（瞳孔骤缩/睫毛颤动/咬肌收紧/视线失焦这类纯脸情绪细节）；**允许「动作型面部中间态」**——嘴角位移仅作为说话/咀嚼/呼吸等动作的一部分写（如「说话时单侧唇角随字音微动」），不作情绪渲染。判定边界：写的是「动作」而非「心情」。
- 动作描述写「这几秒里发生的变化」，不写静止瞬间。

**物理中间件写法（补密度 · 把卖点翻译成可计算的物理变化，而非广告词）**：
电商卖点不能直接写"弹力好/透气"，要写成模型能模拟的中间过程：
- "深蹲时面料随大腿拉伸、不起褶不堆料，起身顺势回弹"（对应四面弹力）
- "面料贴腿不闷、运动出汗后不黏腿"（对应透气不闷）
- "腰头无前中缝、无勒痕，平铺无尴尬线"（对应无尴尬线）
- "玻璃杯从桌面滑落、落地前被接住，液体不洒"（对应防摔/稳定）
原则：每个卖点 → 一个可见的物理动作/材质变化，模型才能"演"出来。

**运镜意图 → 官方词**（对照 `model-specs.md`「运镜意图对照表」，每节拍只选 1 个，不堆砌）：

| 导演运镜意图 | Seedance 官方词 |
|---|---|
| 特写要「稳」 | 固定镜头 / 镜头静止不动 |
| 中近景要「轻手持+惯性」 | 镜头跟随 / 跟拍 + 轻微 |
| 全景要「呼吸感/纪实」 | 镜头环绕 / 航拍 / 镜头拉远 |

> 避坑后缀（防翻车必加）：无抖动、无失焦、运镜流畅、无过度晃动、画面清晰、细节锐利。呼应上文「六、命名镜头运动」：每个节拍只选一个运镜动作，「电影感」不是运镜方式。

## 九、人物参考与真实摄影风格转换

正式人物资产保持**黑白素描铅笔画风格**。需要真人感成片时，可以把已确认素描作为人物参考，并在视频 PROMPT 中明确转换为真实摄影风格；若用户另行提供且授权真人照片/视频，也可作为生成阶段参考，但正式人物资产仍不改变：

- 形象图 PROMPT：黑白素描铅笔画 + 手绘排线 + 纸张纹理 + 无文字
- 视频参考图说明：`@图1 仅作为五官/发型/脸型参考，视频中必须还原为写实真人`
- 视频风格指令：`写实真人质感，真实皮肤纹理、自然光影，禁止保留手绘/素描/黑白质感`

## 十、多段拼接（2.0 超 15s / 超长内容）

**首选视频延长（链式续写）**：`将 @视频1 延长 X 秒。[后续内容]`。段 N 不满意需重做该段及后续所有段。

**需独立生成新段（仅当分镜 Phase 7 标记「尾帧衔接 = 是」的连续段；场景跳转 / 跳切段直接新景别，不取尾帧）时，用尾帧高清重绘衔接（Seedance 同样强制高清还原，不豁免）：**
1. 截取上一段最后一帧。
2. 用「同构图高清重绘」提示词，把尾帧重绘为高清图（画面内容、构图、主体、服装、光源完全一致，仅提升分辨率）：
```
高清重绘参考图：[尾帧图]
保持原构图、主体位置、服装、光线、色调完全不变，仅提升分辨率与细节清晰度。
写实摄影质感，4K 级清晰，无新增元素、无文字、无水印。
```
3. **强制校验-重试闭环**：逐条视觉比对重绘图与尾帧——主体、构图、服装、光源、色调、姿态必须一致；并用客观指标（SSIM / 感知哈希，设阈值）辅助。首次通过即停止；不一致才重做（降去噪 / 升参考权重 / 加约束词 / 换种子），累计最多 3 次。**重试耗尽前禁止回退低清尾帧、禁止跳过还原步骤**；3 次仍不一致**上报用户**，不静默降级。
4. 重绘图作为本段「首帧参考」`@图片N`，本段提示词首句写：`画面从这张首帧无缝继续，[后续镜头内容]`。

## 十一、区域编辑（2.5，片段 90% 对了只改一处时用）

不重做整段，只针对出错的一处处理。措辞结构：**命名片段 → 说明什么不变 → 说明什么变**：

```
编辑 @视频1。保持人物、动作和运镜不变。只把她手中的瓶子换成 @图片2 里的那个，并匹配原有的光线。
```
```
使用 @视频1，仅将背景替换为 @图片3 中的场景。保持人物、衣着和动作完全不变。
```
```
编辑 @视频1。0-5s：不变。5-12s：将标牌文字替换为 @图片4 中的文字，匹配原有字体和光照。12-20s：不变。
```

- 生成结果保持与输入片段相同的画幅比例和时长，无法在同一步骤裁剪/修剪。
- 20 秒及以内的片段编辑比更长片段更稳定。

## 十二、浪费生成次数的五个错误（务必避免）

1. **描述一张照片而非一段视频**——说清 30 秒的变化，不是某一帧。
2. **参考图无标注**——上传了文件就要说明每个文件的用途。
3. **标签文字过宽**——"@图1 定义这位女性"会把背景带进来，写"仅她的脸和外套"。
4. **叠加运镜**——一拍塞三个动作只会打架，选一个。
5. **把多场景故事硬塞一个段落**——用时间戳拆段。

## 十五、即梦 Seedance 电影化叙事法（镜头描述的写法）

> 来源：storyboard-artist Skill，2026-08 吸收。六板块（第一节）是**组织框架**，本节的叙事化写法用于**填充「镜头描述」板块**——即梦镜头描述不是参数清单，而是有情节、情绪、动作的微型剧本。

1. **叙事优先，参数第二**：先想清楚"这个镜头讲什么故事"，再补镜头参数。
2. **情绪弧线是灵魂**：用情绪动词链推动变化，例：`一脸紧张地凝视 → 皱起眉头 → 瞳孔收缩 → 嘴角上扬 → 突然开怀大笑`。
3. **动作要微观具体**：不说"看手机"，说"双手紧握手机，指尖发白，屏幕的光映在瞳孔里"。
4. **环境要有感官**：声音暗示（引擎轰鸣）、温度暗示（闷热潮湿的午后）、气味暗示（柴油和汗水混合的味道）。
5. **对白直接嵌入**：对话直接写在提示词里用引号标注，不用"后期配音"。
6. **群体反应增加戏剧性**：不只写主角反应，还要写周围人的连锁反应。
7. **结尾要有冲击力**：最后一个画面必须有记忆点。

## 十六、即梦内容合规处理（境内审核）

> 合规目标是让内容本身满足平台规则，不是用替换词或“电影语境”规避审核。平台拒绝时，先检查题材、人物授权、商品资质、广告主张和画面行为，再决定是否能够真实地改成合规内容。

1. **不做绕审改写**：不得把受限行为仅换成隐喻、同义词、错别字或影视术语后保持原意；不得把真实名人/公众人物改成高度可识别的影射形象。
2. **版权与肖像**：没有授权时不使用真实人物身份、品牌 IP 或受版权保护角色；可改为原创且不具可识别性的角色设定。
3. **受监管商品与广告主张**：资质、功效、价格、适用人群和风险提示以用户提供的真实材料及目标平台当前规则为准；缺资料就暂停，不猜写。
4. **拒绝后的处理**：记录平台报错原文和触发片段；若能在不欺骗、不改变事实的前提下删去或改掉风险内容，先把改动告知用户再重试；否则停止并说明平台限制。
5. **提示词质量**：补足场景、人物、动作、光线、镜头与声音等真实制作信息，不用空泛“高质量/无不良内容”假装合规。

## 十七、交付配套：生成参数块（独立于六板块）+ 品牌名 IP 规则

### 1. 生成参数块（必附给用户，平台 UI 设置项，不进六板块正文）
Seedance 原生交付习惯在 prompt 外单独列「生成参数」，出片前必填，缺则用户无从下手：
- 时长：2.0 = 15s（写满）/ 2.5 = 30s（写满）
- 比例：带货默认 9:16（竖屏），品牌片可 16:9
- 一致性 / 创意滑杆：电商产品建议 一致性 60% / 创意 40%
- 测试建议：先 5s 试跑确认主体/运镜对了，再延长到满时长

> 与 §七「技术参数不进正文」不冲突：参数块是给用户的设置清单，不是写进 prompt 正文的字段。

### 2. 品牌名、包装原文与当前平台审核
- 先以用户当前 Seedance 界面/接口和品牌授权为准，不把“品牌词一定被拦”当永久事实。
- 镜头需要展示包装文字、Logo、型号或固定版式时，PROMPT 仍须逐字附上用户确认的原文，并写“产品外观、比例、位置与参考图 100% 一致”；这属于模型约束目标，不是效果担保。
- 若平台实际拒绝品牌词，保留包装事实卡，不得静默删品牌或改字；把报错告知用户，并将该镜切换到 P3 真实包装 PNG、实拍、微动或受控合成链路。产品视觉描述仍写可计算属性，便于背景与光影生成。
