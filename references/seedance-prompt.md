# Seedance 2.0 / 2.5 提示词规范

中文提示词。**2.0** 单次 4-15s（超 15s 需多段+视频延长）；**2.5** 单次 30s（超长模式 180s）。

> **规则来源**：六板块结构、@引用来自源 SKILL（seedance-director）；时间戳/括号/精准标注/语言标注/镜头运动命名/区域编辑来自 OpenArt《Seedance 2.5 Prompt Guide》（字节跳动官方示例措辞，2026-08 核实）。

## 一、六板块结构（每段提示词必须包含）

```
## 角色 + 参考图
- 角色A（主角）：@图片1 — [外貌、服装、年龄描述]
- 场景参考：@图片2 — [环境描述]

## 背景介绍
[前情、环境、情绪氛围]

## 镜头描述
镜头1（0-3s）：[景别]，[画面内容]，角色A [动作]，角色A："[台词]"，[运镜]
镜头2（3-6s）：[景别]，[画面内容]，[运镜]

## 声音设计
- BGM：[风格/乐器/节奏变化]
- 环境音：[按时间段标注]
- 对白/旁白（二选一或混用，必须写完整文案）

## 风格指令
[质感、色调、光线、景深]

## 禁止项
禁止出现文字、水印、电话号码、二维码
禁止"后期叠加""后期添加"等指示
```

## 二、@引用规范（2.5 重点：精准标注"仅"字）

- 图片 1-9（2.5 支持 30 张）、视频 0-10 段、音频 0-10 段，共上限 50 个文件。
- 必须中文名称（`@图片1` 不是 `@image1`）。
- **每个 @引用必须标注用途，且用"仅"字限定你要的部分**，防止背景/路人/多余颜色被带进来：
  - ✅ `@图片1 仅定义角色的面部和绿色外套`
  - ✅ `@图片2 仅定义咖啡馆柜台和窗光`
  - ❌ `@图片1 定义这位女性`（会把背景一起带进来）
- **同一物体多角度分组**：多张图是同一物时明说，否则会被当成多个不同产品：
  - `@图片1 定义台灯正面；@图片2 定义同一台灯左侧；@图片3 定义同一台灯背面。三张图是同一盏灯，视频中只能出现一盏灯。`
- 单个视频里 8 个以内人物/产品最稳定；5-10 秒短参考片段比长片段效果好。

## 三、时间戳拆段（2.5 核心，2.0 不适用）

把 30 秒拆成时间点写进 prompt，比"开场是/接着/最后"更精准控制顺序与节奏：

```
0-5秒：厨师把空盘子放到台面，拿起一把勺子。
5-15秒：酱汁淋在盘子上，镜头缓缓推近。
15-25秒：一只手将三只扇贝逐一放下。
25-30秒：拉远至暖色顶光下成品菜肴的广角镜头。
```

三条规则：
1. **只用整秒**，绝不用半秒。
2. **时间轴无缝**：下一段从上一段结束处接续，不留空隙。
3. **每段只给一个明确动作**：塞太满会丢节拍，留空会被填进你没要求的内容。

时间戳不是计数器：描述"动作"而非重复次数（"一秒内点头三次"行不通）。

**2.0 差异**：2.0 读的是镜头编号而非时间戳，把 `0-5s` 改写成 `Shot 1`、`Shot 2` 即可。

## 四、声音括号体系（区分四类，避免乱成一团）

| 类型 | 括号 | 示例 |
|------|------|------|
| 音乐 | （ ） | （轻柔的钢琴声在场景中响起） |
| 音效 | < > | <远处传来钟声> |
| 配音台词 | { } | {Hello, welcome back.} |
| 画面字幕 | 【 】 | 【第一章】 |

- 不必每行都加括号；仅当一句普通话可能有两种读法（如台词被当成字幕）时用括号。
- 字节跳动较新示例常只用"引号 + 说话人名字"，也行。
- 关掉效果用大白话："无字幕""无背景音乐，保留房间原声"（有文档说明，可生效）。

## 五、语言与口音标注（配音说对语言）

- 同一 prompt 内所有台词用**同一种语言**，混用两种会出问题。
- 台词非英语/中文时，台词前注明语言：`她用日语说：{もう大丈夫です}`
- 要特定口音/表达方式，顺序：**语言和口音 → 说话方式 → 台词**：
  `Spoken language: American English. She says it fast and a little annoyed: {I told you this would happen.}`
- 开头就写明，比末尾加"美式口音"更可靠。

## 六、命名镜头运动

Seedance 能直接读镜头指令，写出来即可。有效词：跟拍、缓慢推近、大远景、手持、航拍、向前移动、环绕、变焦拉焦、低角度、俯视。

- **"电影感"不是运镜方式，无效**。
- **每个节拍只选一个运镜动作**，别一次堆三个；一个贯穿十秒的清晰运镜 > 三个互相冲突的动作。
- 可从已有片段复制运镜：上传视频参考并标注 `@视频1 仅用于定义运镜和节奏`。

## 七、关键原则

- 提示词只写画面内容和风格；宽高比、分辨率、时长在平台 UI 独立设置，不进正文。
- **描述场景与变化，而非静止瞬间**：说清 30 秒里发生什么，不是某一帧长什么样。
- **能展示的别用文字描述**：参考图承担外观，文字留给动作/运镜/节奏。
- 台词必须标注说话人（角色A："台词"）；对白/旁白全由模型生成，不走后期配音。
- 技术参数（宽高比/时长）不写进提示词正文。

## 八、活人感判断

| 场景 | 质感取向 | 写法 |
|------|---------|------|
| 种草/Vlog/日常 | 真实生活感 | 微动作、生活痕迹、手持微晃、自然反应 |
| 短剧/情感 | 视情况混合 | 日常戏活人感，高潮戏制作感 |
| TVC/品牌大片/电商产品 | 精致制作感 | 专业布光、稳定运镜、完美构图 |
| 科普/MV | 精致制作感 | CGI/卡点 |

## 九、写实真人脸过审技巧

即梦禁止上传清晰真人脸部素材。形象图用**黑白素描铅笔画风格**生成过审，视频 PROMPT 里强制还原：

- 形象图 PROMPT：黑白素描铅笔画 + 手绘排线 + 纸张纹理 + 无文字
- 视频参考图说明：`@图1 仅作为五官/发型/脸型参考，视频中必须还原为写实真人`
- 视频风格指令：`写实真人质感，真实皮肤纹理、自然光影，禁止保留手绘/素描/黑白质感`

## 十、多段拼接（2.0 超 15s / 超长内容）

**首选视频延长（链式续写）**：`将 @视频1 延长 X 秒。[后续内容]`。段 N 不满意需重做该段及后续所有段。

**需独立生成新段（仅当分镜 Phase 7 标记「尾帧衔接 = 是」的连续段；场景跳转 / 跳切段直接新景别，不取尾帧）时，用尾帧高清重绘衔接（Seedance 同样强制高清还原，不豁免）：**
1. 截取上一段最后一帧。
2. 用「同构图高清重绘」提示词，把尾帧重绘为高清图（画面内容、构图、主体、服装、光源完全一致，仅提升分辨率）：
```
高清重绘参考图：[尾帧图]
保持原构图、主体位置、服装、光线、色调完全不变，仅提升分辨率与细节清晰度。
写实摄影质感，4K 级清晰，无新增元素、无文字、无水印。
```
3. **强制校验-重试闭环**：逐条视觉比对重绘图与尾帧——主体、构图、服装、光源、色调、姿态必须一致；并用客观指标（SSIM / 感知哈希，设阈值）辅助。一次不一致就重做（降去噪 / 升参考权重 / 加约束词 / 换种子），**至少 2 次、至多 3 次，直到一致**。**重试耗尽前禁止回退低清尾帧、禁止跳过还原步骤**；3 次仍不一致**上报用户**，不静默降级。
4. 重绘图作为本段「首帧参考」`@图片N`，本段提示词首句写：`画面从这张首帧无缝继续，[后续镜头内容]`。

## 十一、区域编辑（2.5，片段 90% 对了只改一处时用）

不重做整段，只针对出错的一处处理。措辞结构：**命名片段 → 说明什么不变 → 说明什么变**：

```
编辑 @视频1。保持人物、动作和运镜不变。只把她手中的瓶子换成 @图片2 里的那个，并匹配原有的光线。
```
```
使用 @视频1，仅将背景替换为 @图片3 中的场景。保持人物、衣着和动作完全不变。
```
```
编辑 @视频1。0-5s：不变。5-12s：将标牌文字替换为 @图片4 中的文字，匹配原有字体和光照。12-20s：不变。
```

- 生成结果保持与输入片段相同的画幅比例和时长，无法在同一步骤裁剪/修剪。
- 20 秒及以内的片段编辑比更长片段更稳定。

## 十二、浪费生成次数的五个错误（务必避免）

1. **描述一张照片而非一段视频**——说清 30 秒的变化，不是某一帧。
2. **参考图无标注**——上传了文件就要说明每个文件的用途。
3. **标签文字过宽**——"@图1 定义这位女性"会把背景带进来，写"仅她的脸和外套"。
4. **叠加运镜**——一拍塞三个动作只会打架，选一个。
5. **把多场景故事硬塞一个段落**——用时间戳拆段。

## 十五、即梦 Seedance 电影化叙事法（镜头描述的写法）

> 来源：storyboard-artist Skill，2026-08 吸收。六板块（第一节）是**组织框架**，本节的叙事化写法用于**填充「镜头描述」板块**——即梦镜头描述不是参数清单，而是有情节、情绪、动作的微型剧本。

1. **叙事优先，参数第二**：先想清楚"这个镜头讲什么故事"，再补镜头参数。
2. **情绪弧线是灵魂**：用情绪动词链推动变化，例：`一脸紧张地凝视 → 皱起眉头 → 瞳孔收缩 → 嘴角上扬 → 突然开怀大笑`。
3. **动作要微观具体**：不说"看手机"，说"双手紧握手机，指尖发白，屏幕的光映在瞳孔里"。
4. **环境要有感官**：声音暗示（引擎轰鸣）、温度暗示（闷热潮湿的午后）、气味暗示（柴油和汗水混合的味道）。
5. **对白直接嵌入**：对话直接写在提示词里用引号标注，不用"后期配音"。
6. **群体反应增加戏剧性**：不只写主角反应，还要写周围人的连锁反应。
7. **结尾要有冲击力**：最后一个画面必须有记忆点。

## 十六、即梦过审合规化（境内审核）

> 来源：storyboard-artist Skill，2026-08 吸收 + 你实测的「招商/加盟」敏感词。即梦跑在境内服务器，提示词输出前必须合规化，否则被平台拦截导致生成失败。

**1. 硬拦截内容（必换，与写法无关）**
- 真实人脸（名人/政客/公众人物）→ 改虚构人物描述，不用真实姓名
- 版权角色（迪士尼/漫威/DC）→ 改通用描述（"穿红蓝紧身衣的超级英雄"）
- 敏感议题（人物/事件/敏感符号）→ 完全避免

**2. 敏感词替换表**
| 高风险词 | 安全替代 |
|---------|---------|
| 儿童、小孩、child、loli | 年轻人、青少年、人物 |
| 血、流血、blood | 红色液体、伤痕 |
| 暴力、violence | 激烈动作、冲突场面 |
| 杀、谋杀、死亡 | 倒下、失去意识 |
| 裸、性感、sexual | 优雅的、穿着得体的 |
| 赌博、博彩 | 游戏画面、娱乐活动 |
| 自杀、self-harm | 情绪低落、陷入困境 |
| 毒品、drug | 不提及 |
| 招商、加盟、代理、投资 | 开店、合作、品牌宣传（你实测） |

**3. 场景安全化重写**：用电影语境包裹，加入影视术语（镜头/灯光/画幅/风格）能显著提升通过率。例：`一个人在街上开枪` → `电影质感，1940年代战火街道，一名士兵向画外方向开火，阴天散射光，35mm胶片颗粒感，手持拍摄`。

**4. 负面后缀**（每个即梦提示词末尾附加）：`电影质感，高质量，物理真实，角色一致性强，无不良内容`。

**5. 长度 ≥ 30 字**：提示词过短（<30 字）系统无法判断意图，倾向保守拦截。最简扩展模板：`[场景地点]，[人物描述]，[动作]，[光影氛围]，[镜头风格]，电影质感，高质量`。
