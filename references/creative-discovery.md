# 电商视频前置头脑风暴与创意蓝图协议

> 本文件是正式电商视频生产前的最高级创意闸门。它解决的是“这次应该做什么样的视频”，不是从固定类型中挑一个模板。完成并确认本文件规定的《视频创意蓝图》后，才允许进入 `process-flow.md` 的 Phase 0。

## 1. 强制调用关系

1. 加载本 Skill 后，先检查当前环境是否可读取名为 `头脑风暴` 的 Skill。
2. 可读取时，必须在当前对话/任务内完整执行该 Skill，并把范围限定为 `ecommerce_video_creative_discovery`；不得另开无关项目，也不得在脑暴阶段调用生图、生视频或付费接口。
3. 不得复制、改写或维护一份独立的头脑风暴规则来冒充已调用。电商 Skill 只定义业务输入、输出契约和下游硬门。
4. 找不到 `头脑风暴` Skill、无法读取其完整指令或宿主不支持组合 Skill 时，明确报告 `BRAINSTORM_SKILL_UNAVAILABLE` 并暂停正式生产；只有用户明确授权降级时，才可按本文件字段整理一份临时创意简报，且必须标记 `未经过头脑风暴 Skill`。
5. 同一项目已经有用户确认的 `creative_blueprint_id + version` 时直接继承，不重复脑暴。只有核心方向发生实质变化时才重新打开受影响字段。

## 2. 脑暴输入包

调用 `头脑风暴` Skill 时一次性传入：

- 用户原始需求与已经确认的决定；
- 产品图片、视频、文档、会议记录、参考广告及其来源；
- 产品真实身份、卖点证据、禁说项和不可变项；
- 平台、地区、时长、比例、语言、声音、客户二剪等已知生产限制；
- 已有脚本、拆解结果、反面案例、客户评价和失败原因；
- 当前仍未知且确实影响创意方向的事项。

先输出 `已知事实 / 合理推断 / 未知项` 三栏。用户已经给过的信息不得再问；附件可以回答的问题不得转问用户。

## 3. 十维视频 DNA

头脑风暴不得要求用户先从有限“视频类型”中选一个答案。它必须基于项目资料设计下列十个维度：

1. **商业目标**：一个主目标，可有一至两个副目标；如立即转化、建立信任、解释功能、品牌记忆、收集二剪素材。
2. **受众时刻**：观众在什么具体场景遇到什么问题、已有认知和购买阻力是什么。
3. **前 3 秒钩子**：痛点事故、人物冲突、结果先行、反常识、视觉奇观、挑战、ASMR 等只是灵感，不是固定枚举。
4. **叙事发动机**：痛点→解决、失败→成功、冲突→产品介入、挑战→测试→结果、教程→效果等，可按项目原创组合。
5. **产品角色与身份边界**：客户产品何时出现；对照物、旧产品或竞品如何隔离；哪些结构、颜色、包装和功能不可变化。
6. **卖点证明动作**：每个主卖点对应观众可看见的动作或结果，不用空泛旁白替代证据。
7. **人物关系与表演**：无人、手模、单人、双人、家庭或职业关系；角色动机、冲突、反应和表演强度。
8. **视觉语法**：真实度、机位、运镜、构图、光线、色彩、材质和画面质感；锁定一条主视觉基线，可登记镜头级局部强调。
9. **节奏与声音**：总时长、节拍、镜头内动作速度、剪辑速度、对白/旁白/环境音/动作音效/BGM和客户二剪要求。
10. **结尾与转化**：强 CTA、软 CTA、无字动作、效果停留、前后对照、循环或品牌收尾；CTA 为条件项，不是所有项目必需。

## 4. 创意路线比较

- 信息足够时直接提出 2–3 条真正不同的创意路线；信息不足时，每轮用结构化交互集中询问 3–4 个会改变方向的问题。
- 每条路线至少给出：一句话创意、钩子、叙事因果、卖点证明、视觉语法、声音、结尾、AI 生成风险和推荐理由。
- 路线差异必须来自钩子、人物关系、动作因果、证明方式或视觉语法，不得只是换颜色、换台词、换场景名。
- 主负责人必须明确推荐一条；用户可以选择、混合或修改，但最终必须收敛成一张蓝图。
- 六大视频类型和风格库只作标签、案例与灵感，不得用来裁掉用户提出的混合创意。

## 6. 下游继承与禁止反向改写

- Phase 0–3 只补生产事实、真实性资料和合规信息，不得重新让用户选择已确认的创意方向。
- Phase 4 剧本必须继承钩子、叙事发动机、产品身份边界、证明动作、声音和结尾；需要改变任一核心字段时先回本阶段更新蓝图。
- Phase 7 分镜可以把蓝图具体化为镜头，但不得把对照物和客户产品融合、删掉关键证明动作或改写人物因果。
- Phase 8 资产必须记录 `creative_blueprint_id / version`，并追溯到对应分镜和真实产品来源。
- Phase 10 PROMPT 只能翻译已确认蓝图、剧本、分镜、路由和资产，不得让模型公式反向创造新剧情。

## 7. 何时局部更新，何时重新脑暴

只更新蓝图版本、无需整轮重做：颜色、尺寸、平台比例、某镜时长、单个道具、同方向台词微调。

必须重新打开相关字段并重新确认：主目标、受众洞察、前 3 秒钩子、叙事发动机、人物关系、客户产品与对照物身份、核心卖点证明、主要视觉语法或结尾转化逻辑改变。

已确认字段持续有效。只问变化造成的新问题，不从头复述或重复收集全部资料。

## 8. 脑暴阶段禁止项

- 禁止生成图片、视频、关键帧、九宫格或调用付费接口。
- 禁止先选模型再倒推创意；用户已明确模型时只把它记录为生产限制。
- 禁止把“产品向/人物 IP 向/大促向”作为唯一三选一。
- 禁止用默认平台、默认年龄、默认人物或默认 CTA 填补会改变创意方向的未知项。
- 禁止将内部类型名和风格名直接当成完整视频方案。
