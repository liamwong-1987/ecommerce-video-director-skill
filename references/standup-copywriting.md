# 脱口秀类口播文案：怎么用真实段子带货

## 先说铁律

**AI 不硬编段子。** 脱口秀段子靠真实生活洞察和意外角度，模板填空只会产出空壳（本文件初版的面膜/咖啡/零食/耳机示例就是反面教材，已删）。

正确做法：从**真实段子**（你给的脱口秀资料库、或演员/你本人现成段子）里取材，只借其**笑点逻辑/骨架**，在剧本里改写成产品场景的**原创台词**。SKILL 负责把段子变成能拍的视频方案，不负责替你写段子，更**禁止把素材库段子原句直接照搬进视频剧本**（那是照抄，不是改编）。

## 内核

好段子 = **情理之中 + 意料之外**。

- 情理之中（地基）：场景真实、人物行为符身份，观众先信。
- 意料之外（翻转）：结局意外，回头一想"对啊，就该这样"。
- 只意外不情理 = 无厘头；只情理不意外 = 冷笑话。

## 结构规则（脱口秀节奏，吸收通用脱口秀生成最佳实践）

- **call back 首尾呼应**：结尾回调开头铺垫的梗/人设，形成结构闭环。这是"像脱口秀"和"像广告"的分水岭——只开头抖梗、结尾硬转卖货，观众会觉得被套路。Phase 4 剧本的【结尾】必须回扣【开头】的某个点（德伦堡示例"别背词"呼应"背词"即此）。
- **笑点节拍（按时长定密度）**：脱口秀不能只有一个包袱，中段要有节奏。
  - 15s：1 个主翻转（钩子即包袱）+ 结尾 callback，无中段。
  - 30s：1 个主翻转 + 结尾 callback，中段可有 1 个小 beat。
  - 60s：开头钩子 + 中段 ≥1 个笑点 beat + 结尾 callback，形成"钩子→发展→落点→呼应"四段。
- **三段式映射（与 Phase 4 剧本一致）**：开头=钩子（抓情感/设预期）；发展=铺垫→翻转（递进的意外）；结尾=商品落点+call back（金句回扣开头）。
- *溯源：call back 与笑点节拍吸收自公开脱口秀文本生成器（Largzx/API_application）的提示词规则，已重写为本 SKILL 表述。*

## 四种构造法（用来"分析"真实段子，不是"生成"段子）

- **A 神评真相**：表面神评/装逼 → 真相是写/说的人没真用 → 逻辑自洽反转。
- **B 反转打脸**：对方装 X/贬低 → 最后自己打自己脸（真香/偷拿/认怂）。
- **C 层层递进荒诞**：小事 → 一步步升级荒诞 → 离谱但回头想通。
- **D 直白自黑**：贬低自己（小毛病）制造亲近，不贬产品。

**移植要点**：打脸/真相必须打在**行业乱象或竞品虚标**上，绝不能打在自己产品上（否则观众觉得产品差，不买）。

**脱口秀人设底色**：默认"幽默有哲理、擅长讽刺调侃"的脱口秀演员调性——嘴毒但立得住观点，拆台不骂人。人设要和品牌调性一致（反玄学真香派、毒舌拆台派等），全程统一不漂移。

## 改编工作流（Phase 4 调用）

1. **取材**：从资料库或用户提供的真实段子里，挑一个笑点逻辑匹配品类的（装逼品类用 A，有对手设定用 B，生活琐事用 C，人设亲和用 D）。优先从**日常小事**入手，夸张+幽默描述，引发共鸣（别一上来就宏大叙事）。
2. **保骨架**：留住原段子的"铺垫→翻转→落点"节奏和那一下意外感（保的是**笑声结构**，不是原文字）。
3. **换素材**：把原段子的人/事换成产品场景，但反转逻辑不变。
4. **落产品**：结尾自然带出产品（实在好/解决痛点），不硬塞。
5. **校验**：反转回头想得通吗？打脸打的是行业不是自己吗？过 10 平台合规吗？

## 正确示范（用户认可，保留）

**德伦堡啤酒（A+B 型，基于"神评真相+反转打脸"真实段子逻辑改编）**

"前两天网购一款精酿，评论区全神评：'回甘''尾韵''喝完想谈恋爱'。我就纳闷，这酒是喝的还是月老的？
后来我才懂——写这些的全是经销商，没一个真开的。你让他们吨一口试试？吨完就该写'明天不头疼'了。
我就换德伦堡。它评论区特干净，就三句话：'能喝。''好喝。''再来一打。'
昨天我那精酿朋友来我家，非说他那酒高级。我给他开了罐德伦堡。第一口：'嗯……还行。'第三罐喝完，人走了——顺手把我冰箱那打也拿走了。
你看，好酒不用背词。德伦堡，开了就干。"

> 黑的是精酿圈装逼和评论区水军（行业/竞品乱象），落点是德伦堡实在好喝——打别人，不打自己。

## 真实段子素材（用户按项目提供）

本 SKILL **不分发段子素材库**，也不依赖固定外部文件。用户如有合法可用的本地资料库、本人旧稿或授权段子，应在当前项目中另行提供；先记录来源与授权范围，再只借笑点逻辑改写原创台词。没有资料时，向用户索取真实经历/观察作为素材，不伪装成“已有全量库”。

## 反面特征（AI 硬编空壳 / 照抄原文，禁止）

- 把"构造法"当填空题：面膜→美容院倒闭、耳机→司机报站，只有品类词替换，没有真笑点。
- **照抄素材库原文入剧本**：把用户资料库或第三方段子原句搬进视频剧本——这是照抄不是改编，禁止；应基于获准使用的笑点逻辑改写成产品原创段子。
- 自黑产品：把"真相"写成产品本身坑人，转化归零。
- 堆砌网络烂梗（"体检报告""背词"用第二遍就腻）。

## 合规边界

- 用户另行提供的资料只能按其授权范围使用；不默认拥有转载、改编或商用权。
- 不碰低俗擦边；保持正能量、避开敏感争议话题；过 10 平台规则（涉政/医疗宣称/引战砍）。
- 脱口秀是钩子/人设工具，不能为了好笑忘卖货。
