# 脱口秀类口播文案：构造法与示例

## 内核

好段子 = **情理之中 + 意料之外**。

- **情理之中（地基）**：场景真实、人物行为符合身份逻辑，观众先信。
- **意料之外（翻转）**：结局意外，但回头一想"对啊，就该这样"。
- 只意外不情理 = 无厘头；只情理不意外 = 冷笑话。两者缺一不好笑，或好笑但不高级。

> 本文件示例均基于真实脱口秀资料库的"构造法"改写，为**原创内容，不搬运原资料**（版权红线）。AI 硬编段子易尬，优先用真实段子构造法，而非凭空造梗。

## 四种构造法

### A 神评真相型
表面神评/装逼 → 真相是"写/说的人根本没真用" → 逻辑自洽的反转。
- 保情理之中：装逼场景必须是观众见过的（精酿背词、面膜详情页、耳机参数），观众才信。
- 反转点：从"同一前提的另一种解读"翻，不硬插外部设定。

### B 反转打脸型
对方装 X / 贬低 → 最后自己打自己脸（真香 / 偷拿 / 认怂）。
- 保情理之中：打脸来自产品本身好，不是外部强行。
- 反转点：用对方自己的嘴/手完成打脸。

### C 层层递进荒诞型
小事 → 一步步升级荒诞 → 最后离谱但回头想通。
- 保情理之中：每一步都有"普通人会这样"的动机，荒诞是累积出来的，不是凭空。
- 反转点：结尾点破"这事荒谬但我懂"。

### D 直白自黑型
贬低自己制造亲近感，不贬产品。
- 保情理之中：自黑点是观众也有的小毛病（懒、馋、穷），共鸣强。
- 反转点：自黑收尾落产品。

## 示例库（原创，跨品类）

### 德伦堡啤酒（A + B 型）
"前两天网购一款精酿，评论区全神评：'回甘''尾韵''喝完想谈恋爱'。我就纳闷，这酒是喝的还是月老的？

后来我才懂——写这些的全是经销商，没一个真开的。你让他们吨一口试试？吨完就该写'明天不头疼'了。

我就换德伦堡。它评论区特干净，就三句话：'能喝。''好喝。''再来一打。'

昨天我那精酿朋友来我家，非说他那酒高级。我给他开了罐德伦堡。第一口：'嗯……还行。'第三罐喝完，人走了——顺手把我冰箱那打也拿走了。

你看，好酒不用背词。德伦堡，开了就干。"

### 面膜 / 护肤品（A 型）
"前两天看一款面膜，详情页写'用完年轻十岁''胶原直达肌底'。我就想，这要是真的，美容院早倒闭了。

后来我闺蜜真用了，第二天发朋友圈：'肿成猪头，但心态年轻了。'

你看，它没骗你，确实'年轻'了——年轻到照镜子认不出自己。"

### 速溶咖啡（B 型）
"我们办公室咖啡党，天天手冲，聊'花果香''醇厚度'。我默默泡速溶。

下午三点那哥们盯我杯：'这啥？没灵魂的。'

结果他手冲喝完，盯我杯：'来一口。'一口变三口，临走把我剩的速溶全顺走。

你看，灵魂不重要，好喝最重要。"

### 螺蛳粉 / 零食（C 型）
"我昨天说戒零食。薯片扔了，辣条扔了，饼干也扔了。

扔完坐那，突然特想吃螺蛳粉。忍。忍到半夜，起来煮一包。

吃完看空锅：扔那么多就为吃这包？那我扔它干嘛？于是又煮一包。

你看，减肥的终点，是双份螺蛳粉。"

### 耳机 / 3C（A 型）
"看一款耳机，评论区：'空间音频''降噪如真空''听出制作人呼吸'。我就纳闷，这耳机是听的还是算命的？

后来懂了——写这些的，全用手机外放听的，根本没戴过。

我就换个实在的。评论区就一句：'地铁里听歌，司机报站都听不见。'——这才是真降噪。"

## 应用规则（Agent 在 Phase 4 调用）

1. **选构造法**：装逼品类用 A，有"对手/朋友"设定的用 B，生活琐事多的用 C，人设亲和的用 D。
2. **套结构**：铺垫（真实场景）→ 抖包袱（情理之中意料之外的翻转）→ 落商品时刻。
3. **校验**：反转回头想得通吗？人物行为符身份吗？落回产品了吗？过 10 平台合规吗？
4. **禁**：不抄原资料原文（版权）；不碰低俗擦边；商品时刻不丢；脱口秀是钩子/人设工具，不能为了好笑忘卖货。
