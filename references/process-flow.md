# 执行阶段流程（内部指令）

> 本文件由 SKILL.md 的「## 阶段流程」拆分而来，包含前置创意确认门与 Phase 0~11 的完整生产指令。
> 公开 SkillHub 页面不展示本文件全文（SKILL.md 仅以折叠指针引用）。
> WorkBuddy 加载 SKILL.md 时，按「参考文件导航」中 references/process-flow.md 一行按需读取。

## 阶段流程（前置头脑风暴 + Phase 0~11，含 9.5 成本治理与人工审批门）

**执行顺序**：Creative Discovery → **【视频创意蓝图确认门】** → Phase 0 → 1 →（1.5 爆款拆解，仅爆款复刻时触发）→ 2 → 3 → 4 → **【用户剧本确认关卡】** → 5 → 6 → 6.5（基础资产包）→ 7 → 7.5 → 8（派生资产包）→ 9 → 9.5（视频成本治理+人工审批门）→ 10 → 10.5 → 11
（前置阶段先调用独立“头脑风暴”Skill并确认创意蓝图；Phase 0 再确认真实产品和拍法；Phase 7.5 必须在资产、模型 PROMPT 之前为每镜路由。）

### Creative Discovery：前置头脑风暴与视频创意蓝图（最高级硬门）

1. 首先加载 `references/creative-discovery.md`，按其“强制调用关系”调用独立的“头脑风暴”Skill。
2. 头脑风暴先读取用户消息、附件、参考视频、会议记录、真实产品资料和已确认限制；不得重复询问资料中已经存在的答案。
3. 信息足够时提出 2–3 条真正不同的创意路线；信息不足时每轮只集中询问 3–4 个会改变方向的问题。
4. 最终产出《视频创意蓝图》，至少锁定钩子、叙事发动机、客户产品身份、对照物隔离、卖点证明动作、人物关系、视觉语法、节奏、声音和结尾。
5. 只有 `status=confirmed` 且具有用户确认记录，才允许进入 Phase 0。找不到头脑风暴 Skill 时报告 `BRAINSTORM_SKILL_UNAVAILABLE` 并暂停，不得自行假装完成。

> **禁止项**：脑暴阶段不得生成图片/视频、不得调用付费接口、不得先选模型后倒推创意、不得强迫用户从六大类型或固定场景包中选一个答案。

### Phase 0：先把产品和拍法说清楚（必经前置）

**为什么先做这一步**：先把真实产品怎么拍、哪些镜头要看清包装、哪些镜头只做氛围、视频是整段生成还是拆镜生成说清楚。这样后面的分镜、资产、模型和 PROMPT 才不会来回返工。

#### 0A. 先确认真实产品和拍摄方式（产品默认按真实包装做）

先说清楚：**产品默认按客户提供的真实包装和真实外观来做。**视频模型可以负责人物、场景、动作和光影，但产品包装上的 Logo、文字、型号和固定版式，必须靠真实产品图、实拍、微动或合成来保真，不能指望模型凭空重画。

**产品真实包装是默认前提，不需要用户选择。**

电商带货视频里的产品，默认必须按客户提供的真实包装、真实外观和真实 SKU 来做；不能把“要不要真实包装”当成选项。L1/L2/L3 只是内部按镜头职责划分的生产等级，不是让用户选择产品是否真实：

| 内部等级 | 说人话 | 用在哪些镜头 | 执行规则 |
|---|---|---|---|
| **L1：只保证像同类产品** | 产品只在远景、背景或氛围里出现，观众看不清包装 | P0/P1 氛围镜 | 可用精简产品视觉信息，但不能把它当成真实 SKU 正面展示 |
| **L2：保证产品长相接近** | 观众能看清产品的大致外形、颜色和材质 | P2 产品动作镜 | 每镜独立生成，重新注入真实产品参考；不把包装小字交给模型硬画 |
| **L3：保证真实包装信息** | 观众要看清真实包装、Logo、文字、型号或固定版式 | P3 包装/信息镜 | 必须使用真实产品图、P-PACKSHOT、实拍、微动或合成；禁止纯视频模型重画包装 |

**硬规则：**只要产品正面、包装、Logo、包装文字、型号或固定版式需要被看见，就直接按 L3 处理，不再让用户选择“要不要真实”。

**先确认产品素材：**
- 请提供产品正面实拍图；如果镜头会拍到侧面、罐顶、开盖或手持，还要补对应角度。
- 如果包装文字、Logo、型号或固定版式要清楚出现，请提供高清正面 PNG 或透明底产品图。
- 请直接告诉我：哪些地方绝对不能变？比如罐体比例、主色、色带、主要图形、Logo、包装文字和型号。
- 没有真实产品图时，暂停正式电商视频流程，先补齐真实产品素材；不能用概念产品顶替，也不能先生成“相似包装”交付。

**再确认怎么拍：**
- 是整段连续生成，还是拆成多个短镜头？
- 如果产品要被拿起、旋转、展示，产品动作镜要单独生成，并重新放入真实产品参考图。
- 如果要看清包装、Logo、文字或型号，就走真实产品图、实拍、微动或合成，不让视频模型重新画包装。

> 这些信息确认后，内部会按镜头职责自动分成 L1、L2、L3，不需要用户自己判断等级：远景/氛围镜走 L1，产品动作镜走 L2，包装信息镜走 L3。

**通用前置：可灵 Kling 优势与其它模型对比（涉及人物且需要选模型时讲）**

用户尚未选择模型或明确要求比较时，先讲与当前镜头有关的差异，再让客户拍板；用户已经明确模型时直接记录，不重复展开整表。下表的版本、帧率、时长与能力是编写时快照，执行时以用户当前 UI/API 为准。

| 维度 | 可灵 Kling | Seedance 2.0/2.5/Mini | MiniMax H3 |
|------|-----------|----------------------|------------|
| 真人样貌一致性 | I2V + 视频提取人物特征，还原度最高【你实测】 | 能做写实真人，还原度较低【你实测】 | Omni-Reference 全向参考锁定跨镜头角色一致性【官方】 |
| 口型同步 | 优秀 | 优秀 | 优秀 |
| 中文场景理解 | 优秀 | 优秀 | 优秀 |
| 适用场景 | 真实模特/主播口播/探店/真人脸（还原度最高） | 商品/虚拟/真人（还原度较低） | 商品/虚拟/真人（还原度较低） |
| 慢动作/升格 | 原生支持（slow-motion 提示词 + 60fps） | 2.5 时间锚点精确变速最强；2.0/Mini 提示词级 | 间接（高帧率后后期放慢，无直接开关） |
| 人物资产形式 | **可灵走授权真人 I2V 参考、免素描**（选定可灵不强制黑白素描） | 人物资产统一黑白铅笔素描 / 黑白线稿 | 人物资产统一黑白铅笔素描 / 黑白线稿 |

> 本技能不接数字人方案；正式人物资产（非可灵路径）固定为黑白铅笔素描 / 黑白线稿，不输出真人照片或彩色肖像。Seedance/H3 路径直接用已确认素描生成真人感视频；**可灵路径免产素描**——选定可灵即直接以用户授权的真人照片/视频作 I2V 身份锚定。用户另行提供并授权的真人素材也可作生成输入。视频风格须单独确认，不能反向改变正式人物资产。

**结论一句话**：真人出镜视频场景，推荐可灵 Kling（视频还原度最高最稳）；客户也可选 Seedance / H3 做真人视频。**可灵路径免产黑白素描**，直接走授权真人 I2V 参考；Seedance/H3 路径仍须交付黑白铅笔素描 / 黑白线稿，不输出真人照片或彩色肖像。视频风格由用户单独确认，不能反向改变人物资产。

**模型与人物由客户决定，Agent 不得替客户拍板、不预设能力门槛。** 先继承创意蓝图中的人物关系、真实/虚构身份和用户已明确模型；只有缺失会阻断生产时才补问。使用结构化交互时每轮集中 3–4 个相关问题，不逐题打断。

**缺口一：画面里有人吗？**
- 有真人或虚构角色出镜 → 继续问下面的人物问题。
- 只有产品、场景或动画 → 不问人物问题，直接继续。

**缺口二（有人的时候才问）：你要什么样的人？**
- 真实模特、主播、探店达人，还是 AI 生成的虚构角色？
- 不管选 Seedance 还是 H3，人物资产都先做黑白素描三视图；**选定可灵则免素描**，直接走授权真人照片/视频 I2V 参考，不生成真人照片或彩色人物图。

**缺口三（选择虚构角色时才问）：这个角色长什么样？**
- 必答项（客户未明确回答前**禁止进入 Phase 4**）：性别（男 / 女）+ 年龄感（青年 / 中年 / 老年）+ 体型 / 发型 / 着装基调
- Agent 不得替客户定性别——此问缺失则退回重问，不擅自补"男性/女性"
- 采集结果写入资产 SPEC，Phase 8 按 `references/asset-workflow.md`「② 人视三视图」模板的 `[核心身份：年龄段、性别、脸型…]` 字段生成

**接下来问模型：你更想用哪个模型？**
涉及人物时，先用大白话说明可灵、Seedance、H3 各自更适合什么，再让客户选；不替客户拍板，也不把一个模型默认成全片唯一模型。

列出本技能已适配提示词与镜头路由的 **5 条模型路线**供选择：Seedance 2.0 / Seedance 2.0 Mini / Seedance 2.5 / MiniMax H3 / 可灵 Kling。是否能自动调用取决于用户当前接口适配。**选择以“镜头职责”而非“一条视频只选一个模型”为单位：**
- 叙事与氛围镜：Seedance 2.0/2.5、Mini、H3 或可灵，优先画面、人物、声音与节奏。
- 产品动作镜（L2）：优先可灵 O3 的参考驱动能力；其他模型只能作为已确认的备选，并要求单镜图生视频和产品参考重注入。
- SKU 保真镜（L3）：真实产品图/实拍/合成优先；视频模型仅做微动，不替代真实包装。
- 人物=现实真人：人物镜优先推荐可灵；客户可选 Seedance/H3，但须接受较低的人物还原度。
- 客户有偏好：将其登记为某条生产线或某类镜头的偏好，不自动扩大成全片唯一模型。
- 客户无偏好：Agent 可基于成本/时长/效果提出每条生产线的推荐组合，仍须客户确认。

> **本技能对客户无任何生成能力门槛**：客户的 API、账号、付费属于客户自己的选择。Agent 的职责是说明模型能力边界、镜头适配与成本，不替客户拍板，也不把模型能力虚构成 SKU 保真能力。

- **人物资产约定（贯穿 Phase 8）**：凡涉及人物，**可灵路径免产素描**——选定可灵即直接以用户授权的真人照片/视频作 I2V 身份锚定，不要求先产黑白素描；Seedance/H3 路径 Phase 8 正式人物资产一律交付**黑白铅笔素描 / 黑白线稿**，不得改成真人照片、彩色肖像或写实真人三视图。用户授权的人物照片可用于生成素描；视频生成阶段可直接使用素描（Seedance/H3），也可使用用户另行授权的真人照片/视频（含可灵 I2V）。视频是否使用真实人物风格必须单独确认，不能反向改变正式资产格式。

**生产策略写入「生产策略上下文」，贯穿 Phase 1→11：**
- Phase 8 资产：按 L1/L2/L3 和 Phase 7.5 路由制备；人物资产、场景锚点、产品真实资产分别管理。**可灵路径人物资产走授权真人 I2V 参考、免素描**；Seedance/H3 路径人物资产始终保持黑白素描，不因真人出镜而改成真人照片。
- Phase 7 分镜：先按叙事节奏拆镜，不被任何单一模型的时长上限反向绑架；实际生成段长由 Phase 7.5 镜头路由确定。
- Phase 7.5 路由：为每镜绑定生成方法、目标模型/工具、参考资产、允许动作、验收标准；未路由不得写视频 PROMPT。
- Phase 10 PROMPT：每镜严格按路由中目标模型的格式写；不同模型的镜头可以并存，但同一镜头只能有一个主生成链路。
- Phase 11：负责片段衔接、产品保真回检、剪辑拼接与最终交付；连续叙事段按各自模型的续写规则处理，跳切镜不强行尾帧继承。
- **模型角色 → 具体 model id 映射**：SKILL 只输出「模型角色」语义标签，不写具体 model id；生成模式下由用户本地配置 `VIDEO_MODEL` 或脚本参数完成映射。

> **铁律**：模型由客户确认，Agent 可以依据“镜头职责”给出组合建议，但不得把某个模型自动扩大为全片唯一解；更不得把任何视频模型说成可以单靠提示词保证真实 SKU 包装。

### Phase 1：接收创意蓝图并建立项目事实包（必须）

读取已确认的 `creative_blueprint_id + version`，把用户原始资料、头脑风暴结果和 Phase 0 的真实产品/生产信息合并为项目事实包。此阶段只做继承和差异扫描，不重新选择视频类型、场景包或风格。

必须检查：
- 蓝图中的钩子、叙事发动机、产品身份边界、证明动作、人物关系、视觉语法、声音和结尾是否完整；
- 用户附件、参考视频、客户脚本、产品资料和蓝图是否存在冲突；
- 哪些内容是用户事实、哪些是脑暴推断、哪些仍待生产层补齐；
- 后续所有表格都写入 `creative_blueprint_id / version`。

**爆款复刻触发识别**：若客户带了爆款参考视频/链接，或说"复刻/仿这个/照这个做/同款视频/换个品做同款" → 标记进入**爆款复刻**入口，下一步走 Phase 1.5 爆款拆解（加载 `references/viral-replicate.md`）。

**客户自带剧本触发识别**：若客户直接发了完整脚本/文案/口播稿（任何格式）→ 标记进入**客户自带剧本**入口。头脑风暴仍要分析客户真实意图和脚本适配性，但不擅自重写；Phase 0/2/3 只补蓝图和客户脚本尚未覆盖的真实产品、平台、生产与合规信息，Phase 4 使用客户剧本分支。

### Phase 1.5：爆款拆解（仅当 Phase 1 识别到"爆款复刻"时触发）

对参考视频做**六维拆解**，产出「爆款拆解表」作为后续剧本的唯一事实源（加载 `references/viral-replicate.md` 第三节）：

| 维度 | 拆什么 |
|---|---|
| 钩子 | 前 3 秒靠什么留人 |
| 脚本结构 | 开头→发展→高潮→结尾怎么走 |
| 节奏 | 剪辑节奏 + 镜头内运动速度 |
| 卖点 | 卖点怎么带出来 |
| 情绪 | 情绪怎么推（好奇→认同→下单） |
| CTA | 结尾怎么收 |

拆解结果分两类：**"骨架"（结构/节奏/情绪弧线/卖点逻辑，可复刻）** 和 **"血肉"（具体画面/文案/人物/音乐，要改）**。复刻只照搬骨架，血肉必须原创改写——详见 `references/viral-replicate.md` 版权四层面与复刻姿势。

### Phase 2：生产事实完整度扫描（必须）

本阶段只检查创意蓝图没有负责确认、但正式生产必须知道的事实。禁止重新发起“选类型、选场景包、选风格”问卷。

| 维度 | 执行规则 |
|------|---------|
| 产品身份 | 品牌名可明确为“无品牌/白牌/暂不公开”；产品名、品类、SKU、真实外观与不可变项必须明确 |
| 卖点证据 | 核心卖点按优先级登记，并记录检测报告、证书、成分表、参数、实测或客户确认来源；不得虚构 |
| 价格/优惠 | 写真实机制；不提则明确“不在视频中表达价格/优惠” |
| 平台与区域 | 登记具体平台、主要发布地、语言和需要叠加的次区域规则 |
| 时长与画幅 | 登记每条时长、比例、数量及客户二剪交付方式 |
| 能力模式 | 纯提示词或生成模式；生成模式另检查接口、模型映射、凭证和预算审批 |
| 素材 | 产品图、人物授权、参考视频、脚本、品牌规范、可复用素材及缺失项 |
| 客户硬要求 | 审核标准、禁用项、必须动作、声音、字幕、CTA、AIGC披露和交付格式 |

所有已由蓝图或附件回答的字段直接继承。只有空缺会阻断下一阶段时才进入 Phase 3；不以“品牌未公开”为理由虚构品牌，也不把用户没有要求的价格、人物或 CTA 默认补上。

### Phase 3：最小必要生产补充（按缺口触发）

1. 先输出缺口清单，并区分 `必须补充 / 可由真实资料推断 / 不影响生产可留空`。
2. 需要用户输入时，使用平台结构化交互，每轮集中询问 3–4 个互不重复的问题；不得恢复旧版“一屏 4 题 × 2 轮 + 场景包单选”。
3. 用户已经说“按默认”时，只能默认不会改变创意与真实性的生产参数，例如纯提示词模式、无 BGM、无价格；不得默认人物性别、产品结构、国家、主卖点或 CTA。
4. 模型在创意蓝图之后选择：先按镜头职责提出建议，再登记用户偏好；不得用模型能力反向改写已确认创意。
5. 六大类型和十四种风格只可用于给蓝图加辅助标签、查案例和展开视觉语法。场景包是可选灵感预设，不是单选硬门，也不能一次锁死受众、节奏和创意。

**进入 Phase 4 前硬门**：
- `creative_blueprint_id / version / status=confirmed / 用户确认记录` 齐全；
- 产品名、品类、真实产品来源、核心卖点及证据、目标受众、平台/区域、时长/比例、声音与客户硬要求齐全或明确“不使用”；
- 钩子、叙事发动机、客户产品与对照物身份、证明动作、人物关系、视觉语法和结尾没有被 Phase 0–3 反向改写；
- 爆款复刻项目另完成同品/不同品、可复刻骨架、必须原创部分和目标平台核对。

任一项不满足时，只补对应缺口；不得从头重问整个项目。

### Phase 4：纯文字剧本创作（必须，唯一事实源）

**客户自带剧本（Phase 1 已识别时）**：**不重写剧本**，直接把客户剧本作为「纯文字剧本」（唯一事实源）。但必须先做「剧本对齐检查」，缺要素问客户补，**不擅自改写客户剧本**：
- **完整性**：钩子（前 3 秒）、卖点（真实、有证据）、台词/动作密度、蓝图规定的结尾方式——缺哪项标哪项，问客户「补还是按原样走」；蓝图未要求 CTA 时不得强补。
- **合规预检**：扫极限词/导流词/敏感词（Phase 5 会正式做，这里先提示）。
- **可提取性**：客户剧本能否支撑 Phase 7 分镜提取？只有台词、没有画面/镜头描述 → 问客户补画面；太简略 → 提示需补充。
- **节奏/时长对齐**：调研定的时长/节奏与客户剧本台词量是否匹配？不匹配 → 提示客户对齐。
- 过完对齐检查 → 客户剧本成为唯一事实源，照常进下方「用户确认关卡」。

按已确认《视频创意蓝图》写**纯文字**剧本（不生成任何图、不写分镜表）。`references/video-types.md` 与 `references/style-guide.md` 只提供案例和视觉语法，不得机械套模板或覆盖蓝图：
- **蓝图继承**：钩子、叙事发动机、产品与对照物身份边界、卖点证明动作、人物关系、主要视觉语法、节奏、声音和结尾必须逐项落地。
- **视觉语法展开**：把蓝图中的机位、运镜、光线、色彩、材质和真实度写成可拍内容；不得只写“UGC/TVC/高级感”等风格名。
- 前 3 秒钩子（黄金三秒，钩子库见 `references/copywriting-library.md`，按类型选，带货/种草须绑定商品时刻）
- 台词密度（按风格，不按平台）：**自拍/UGC/vlog 等聊天式 3-4 字/秒**（自然有停顿）；**口播/信息流 5 字/秒**（30s≈150字写满）；**ASMR/沉浸式**基本无台词（详见 `style-guide.md` 第三节）。
- 留存锚点埋 30%-70% 处
- 金句/反转仅在蓝图需要时设置；结尾按蓝图执行强 CTA、软 CTA、无字动作、效果停留、循环或品牌收尾，不强制所有视频出现 CTA
- 卖点完整不缩水（自然带出，不是堆参数）；脱口秀/剧情类不硬套卖点
- **爆款复刻剧本（仅爆款复刻时）**：按 Phase 1.5 拆解表的「骨架」+ Phase 3 定的复刻度，写**原创**剧本——结构/节奏/情绪弧线/卖点逻辑复刻，画面/文案原句/人物/音乐原创改写。**严禁照搬爆款画面描述、台词原句、BGM**。这与"段子改编铁律"一致（见 `references/standup-copywriting.md`、`references/viral-replicate.md` 第二节）。

文案风格参照 `references/copywriting-library.md`。

> 本 Phase 产出的是**纯文字剧本**，作为 Phase 7 提取分镜、Phase 8 提取资产的叙事依据；《视频创意蓝图》继续作为上位创意事实源。后续阶段不得脱离二者另起炉灶。

> **⏸ 用户确认关卡（必停，不可跳过）**：Phase 4 产出纯文字剧本后，**必须停住并用 AskUserQuestion 弹窗让用户确认**：
> - 用户说"行 / 可以 / 继续" → 进入 Phase 5 合规检查；
> - 用户说"不行 / 要改 / 换钩子" → 回到 Phase 4 修改（可多轮，直到用户确认通过）。
> - **未获用户明确确认，不得进入 Phase 5，不得自行推进后续任何阶段。**
> 确认时一并请用户核对：钩子是否吸引、卖点是否完整、台词密度/时长是否够、有无要补的信息。

- 产品建模与清晰度：产品（如小金罐）须重做三视图，罐体清晰、大小稳定，禁止忽大忽小、模糊或缺原图参考。
- 关键信息展示：视频中须清晰展示罐身配料表及酒精度数，细节明确，满足电商挂车销售需求。
- 饮酒镜头限制：严禁出现饮酒/吞咽镜头；允许碰杯或喝到嘴边的动作，禁止吞咽动作。
- 未成年人保护：所有视频结尾必须添加「未成年人不得饮酒」提示语。
- 音频与字幕修正：修正音频翻译错误及字幕不匹配问题（口播/字幕逐条核对）。
> 本标准由 Phase 2「客户特定要求」字段流入；不同酒类/受管制商品客户若有各自的硬标准，按该字段填写内容执行，不套用德伦堡案例的细节。

不合规处直接改写到合规，不改用户真实卖点。

**兜底闭环（敏感词改写仍不过时，逐级降级 + 明确反馈）**

含敏感/违规表述时，不要只改一次就停，按下面四级降级；**每一步都明确告诉用户：卡在哪个词、为什么、降级到了哪一步**，不能让用户自己猜。

1. **一级·换表达**：把触发词换成同义中性表述（如"最/第一"→"行业领先/头部"），保留原卖点意图。
2. **二级·换角度**：换表达仍触发，就换一个卖点角度重新表述（如"根治"改为描述使用感受，不谈疗效）。
3. **三级·删卖点**：仍不过，删除该敏感卖点，改用其他真实卖点补位（卖点必须真实，不得凭空捏造）。
4. **四级·降级不提**：所有卖点都触发，就降级为"该维度不提"，只保留最安全的卖点。

> 反馈原则：每次改写/降级后，向用户说明「原表述 → 触发原因 → 处理方式 → 结果」，让用户一眼看懂发生了什么，不要默默改完让用户自己对照。

### Phase 6.5：基础资产包（分镜前，批次确认一次）

先加载 `references/asset-workflow.md` 的“批次授权与确认”。从已确认蓝图、剧本和用户真实资料建立分镜所需的基础事实源：

- 客户真实产品图及等价产品主资产；需要补角时制备 `P-CORE`，不得用概念产品替代。
- 需要跨镜保持身份的人物资产或已授权真人参考。
- 用户提供的真实场景资料、品牌规范和必须跨镜复用的系列级基础场景。

纯提示词模式输出完整基础资产 SPEC 和引用清单；生成模式在第一次付费生图前一次性提交“基础资产包”的数量、模型、预计成本和重试上限，获得整批批准后连续执行，禁止逐张确认。基础资产包未完成或真实产品来源不成立，不得生成九宫格。

### Phase 7：按纯文字剧本提取分镜（必须）

从已通过 Phase 5/6 的纯文字剧本中**提取**分镜表（不新增剧本没有的内容）：
- 镜头序号 / 时间轴 / 画面描述（按下方五维规范展开） / 台词 / 声音（环境音/动作音效 + 旁白/对白，不含 BGM） / 连续性（角色编号+状态变化+秒数） / **运动速度（正常 / 升格慢动作 / 快动作，对应 Phase 3 节奏调研）**
- 每个镜头标注是否需要资产（对应 Phase 8）、是否关键帧
- 留存锚点、金句镜头单独标注

**分镜 7 条原则**（来源：storyboard-artist Skill，2026-08 吸收）：
1. **节奏控制**：开场镜头定调 → 铺垫中景渐入 → 高潮景别切换加快、特写密集 → 收束回归大景别。**区分「剪辑节奏」（镜头切换快慢，靠镜头时长/切点密度）与「镜头内运动速度」（单镜头内动作快慢/升格慢动作）**——升格镜头（如手表静物细节展示）在「运动速度」列单独标"慢动作"，不靠切快镜头表达。
2. **景别禁忌**：连续 3 个同景别镜头 = 犯规，必须插入对比景别；进一步严禁连续相同机位 + 相同角度 + 相同构图。仅正反打可相近景别，但须改方位 / 前景遮挡 / 焦距感。30 秒以内短视频靠分镜本身的多镜头切替保持视觉节奏，不另设"换挡"硬指标，唯一要求是全程景别丰富、不连续同机位同角度，避免观感单调。
3. **蒙太奇意识**：每个镜头标注与前后镜头的组合关系（蒙太奇意图）
4. **人物一致性**：角色首次出现分配唯一编号并锁定特征（脸型/发际线/发色/肤色/体型/服装/配饰/鞋履）；后续镜头复用「编号 + 姓名」指代，不重复描述长相。衍生图一次只改一个条件。
5. **动作具体化**：不说"走路"，说"双手插兜缓步前行"
6. **光影即情绪**：暖光=温馨，冷光=疏离，逆光=戏剧性，顶光=压迫
7. **转场靠内容**：用相似构图/色彩/运动方向衔接，不依赖"转场"指令

**分镜表连续性列**：逐镜标注角色服装 / 身体状态 / 道具状态 / 场景状态是否在此时变化，标准确秒数（如 `12s 图1 换装`）。人物一律用「编号 + 姓名」指代，禁止用"他 / 她 / 它"等代词替代角色。

**分镜表尾帧衔接列（必填）**：逐段（首段无前段，不填）按「场景 / 主体 / 景别 / 运镜」四字段与上一镜对照，判定是否需尾帧衔接，结果写入分镜表「尾帧衔接」列，供 Phase 11 照单执行：
- **连续（标记「是」）**：同一场景 + 同一/连续主体 + 景别渐进 + 运镜延续（如中景→近景→特写跟拍、同一人物叙事流）。UGC 探店 / 种草 / 口播拆段常见。
- **跳切（标记「否」）**：场景切换 / 主体切换 / 景别大跳无过渡 / 蒙太奇快切。直接新景别独立生成，不取尾帧。
判定以分镜脚本的镜头意图为准，**不按视频类型一刀切**（UGC 也可能跳切、TVC 也可能连续跟拍）。

**分镜表「产品可见级别」列（含产品视频必填）**：逐镜标 `P0/P1/P2/P3`，供 Phase 7.5 路由，不再只用“产品主镜”二分法。
- `P0`：产品不出现或不可辨识。
- `P1`：产品只是叙事背景/虚焦局部，走 L1；仍须逐镜引用已确认 `P-CORE` 或同等真实产品参考，只是不要求包装文字可读。
- `P2`：产品动作镜，产品轮廓、主色、主要色块/图形需要可辨识，目标 L2。
- `P3`：SKU 信息镜，正面包装、Logo、文字、型号、价格或固定版式必须真实，目标 L3。

**分镜表新增「产品交互风险」列（P2/P3 必填）**：写清产品是否被手遮挡、旋转角度、移动速度、是否要求正面可读。P2 默认：旋转不超过 15°、手部遮挡不超过罐身 30%、单镜 1-3 秒；P3 默认：正面朝镜头、禁止明显旋转、只允许缓推/环境光/冷凝水等微动。若剧本动作超过该边界，必须拆镜或降级可见级别，不能靠长 PROMPT 硬扛。

**画面描述五维规范**：画面描述不再只写动作，按以下维度展开（关键近景尽量覆盖五维）：
1. 微表情与视线：瞳孔骤缩/慢扩、睫毛颤动、视线失焦或重聚、咬肌收紧、嘴角肌理位移（**分级**：可灵/Seedance/H3 禁情绪渲染型微表情，仅允许动作型面部中间态——嘴角位移只作为说话/咀嚼动作的一部分、不作情绪渲染；边界判定见 model-specs.md「各模型能力边界」与 seedance-prompt.md §8.5 白名单）
2. 肢体与体态：重心微调、双肩随呼吸起伏、指尖拧抓衣角、指节泛白
3. 动作中间态：欲言又止、转身一滞、半步悬停、抬手悬空、触碰前微顿
4. 生理应激：喉结滚动、鼻翼微翕、额角青筋微凸、呼吸节律变化
5. 光影呼吸：呼吸/体态带动皮肤与轮廓阴影实时位移
硬规则：严禁「难过 / 愤怒 / 委屈 / 崩溃」等抽象情绪名词，用可见生理与动作呈现。关键表演处可混简短英文 tag（micro expressions / realistic camera inertia）提升模型理解。
表演范式（融化进动作，不得直接当描述）：轻俏嗔笑（眼底细碎反光收敛，单侧唇角微翘，头部轻偏，手腕抬起半挡，呼吸平缓）；强忍情绪（眼尾泛红含水光，双唇反复轻抿微颤，呼吸短暂停顿，双肩微收，喉结低频滚动）；沉绪落空（视线失焦下坠，长气缓慢吐出，胸腔塌落，双肩下垂，重心后移）。

**创意蓝图基线锚定（必查）**：全片由已确认蓝图定义一条主要视觉语法与一条主叙事因果；允许蓝图明确登记的镜头级局部强调，不要求所有镜头机械保持同一节奏档。

| 项 | 规则 |
|---|---|
| 主要视觉语法 | 继承蓝图的真实度、镜头、光线、色彩和材质基线；局部变化必须有蓝图或剧情依据 |
| 节奏结构 | 继承蓝图的总节拍；痛点、转折、证明、ASMR停留和结尾可以使用不同镜长，但必须服务同一因果链 |
| 镜头级局部强调 | 只允许使用蓝图已登记的局部视觉、节奏、声音或转化强调，并在分镜表写明来源与作用 |
| 变化位置 | 在分镜表对应镜头备注 `蓝图局部强调：<字段/内容>`，便于溯源核查 |

**FAIL 判定（发现即回退）**：分镜改变蓝图钩子、删掉核心证明动作、混淆客户产品与对照物、无依据改变人物关系/主要视觉语法，或节奏变化无法解释其叙事职责 → 回 Creative Discovery 或 Phase 4 修正；仅镜长不同不构成 FAIL。

**分镜粒度**：快节奏通常 1-2s/镜，中速/UGC 通常 3-5s/镜，慢节奏或概念演示通常 5-10s/镜；P2/P3 产品镜按路由通常独立 1-3s。镜长服从已确认的节奏和模型能力，不把整片 15/30 秒误写成单镜默认时长。每批不超过 15 个镜头，超出则分批。

#### 7A. 9 宫格分镜图（所有视频强制必做）

分镜表完成后，先把时间轴转成视觉分镜图，再进入 Phase 7.5 路由。它不是可选的装饰图，而是所有视频必交付的视觉控制层：在昂贵的视频生成前约束产品的样子与位置、人物关系、场景和构图，让用户快速看懂成片并及时修改。**没有分镜图或分镜图未获用户确认，不得进入 Phase 7.5、Phase 8、Phase 10 或视频生成。**

- **15 秒视频**：制作 1 张 9 宫格，按时间顺序对应 9 个节拍，默认每格约 1.5-2 秒；每格标注时间、景别、产品状态、人物动作、镜头运动。
- **30 秒视频**：制作 2 张 9 宫格，分别对应 0-15 秒与 15-30 秒；两张之间必须检查第 9 格到下一张第 1 格的场景、人物、产品状态、光线和运动方向。
- **超过 30 秒**：按每 15 秒 1 张 9 宫格继续拆分，最后一张不足 15 秒时按实际时长分格，不强行填满。
- **所有视频必须制作分镜图**：产品视频、人物口播、剧情、品牌片、纯氛围、动画/3D、无产品视频均不得跳过。无产品视频只是不触发产品保真检查，不代表可以跳过分镜图。

**每格必须记录 7 项**：时间范围 / 景别与构图 / 人物动作 / 产品状态与朝向 / 镜头运动 / 产品可见级别 P0-P3 / 与前后格的连续性。仅有九宫格图片、没有文字台账，视为不完整。

**分镜图生成规则：**
1. P2/P3 产品格优先使用真实产品 PNG、实拍图或已确认的 P-HERO/P-PACKSHOT 合成进构图，不让图像模型凭空重画包装。只要产品格要求看见包装文字、Logo、型号、配料表、酒精度或固定版式，必须把已确认包装原文逐字写入分镜图 PROMPT；原文未确认时标记待客户提供，不得猜写。
2. 9 宫格用于锁定镜头顺序、构图、产品位置、产品大小、人物关系和动作起点；不把低分辨率宫格当作最终产品保真素材。
3. 按目标模型、动作复杂度、产品保真、九宫格清晰度和连续性风险，建立需生成 `KF-N` 的镜头清单与 SPEC；实际关键帧在 Phase 8 派生资产包中生成。简单镜头可登记“分镜格 + 真实产品资产足够”的豁免证据。
4. **所有视频**只有在用户确认 9 宫格与逐格台账后，才进入 Phase 7.5；不合格只改分镜图和台账，不先写视频 PROMPT。若生成失败、画格串景或构图不符合台账，整张 9 宫格作废并按同一台账重跑，不允许跳过、拼合、单格替换或用文字表替代。每张最多尝试 3 次；仍不合格则报告具体失败项与已花/预估成本，暂停等待用户调整台账或素材。

**宫格不是视频输入的唯一条件：**视频生成时，氛围格可用场景/人物参考，P2 格用对应高清关键帧 + 产品参考独立生成，P3 格用真实产品资产微动/合成。禁止把一张 9 宫格整体图直接当成 15 秒视频模型的唯一参考，避免模型把九个格子当成一张拼图或同时重绘九个产品。

#### Phase 7 硬门：停—查—报（必须）

完成分镜表、九宫格、逐格台账及关键帧触发清单/SPEC后，**必须暂停**，加载 `references/phase-checklist.md` 的「Phase 7：分镜与九宫格确认门」，逐项输出核验报告。分镜表、整张九宫格、逐格台账、分镜一致性、关键帧触发判定或用户确认任一阻断项 FAIL，禁止进入 Phase 7.5、8、10 或视频生成；不得用文字分镜表代替图片证据。

### Phase 7.5：镜头级生产路由（必经，未完成禁止进资产与 PROMPT）

Phase 7 的分镜只是“拍什么”；本 Phase 决定“怎么做”。逐镜建立下表，任何 P2/P3 产品镜缺行即 FAIL：

| 镜号 | 镜头职责 | 产品级别 | 生产线/生成方法 | 目标模型或工具 | 参考资产 | 允许动作 | 验收标准 | 失败处理 |
|---|---|---|---|---|---|---|---|---|
| 示例 1 | 人物/氛围叙事 | P0/P1 | 叙事氛围线，连续或独立生成 | Seedance / 可灵 / H3 | 人物、场景 | 正常表演与运镜 | 人物、节奏、场景成立 | 单镜重跑 |
| 示例 2 | 产品取放/展示 | P2 | 产品动作线，独立图生视频 | 优先可灵 O3；确认后的备选模型 | P-CORE + P-HERO | 1-3s，正面优先，旋转≤15° | L2 轮廓、主色、主要色块/图形稳定 | 只重跑该镜 |
| 示例 3 | 正面 Packshot/信息镜 | P3 | SKU 保真线，真实产品微动或合成 | 真实产品图/实拍/合成工具 | P-PACKSHOT（必要时 P-HERO） | 缓推、光影、凝露；无明显旋转 | Logo、文字、版式与实物一致 | 重新合成或换真实资产 |

**三条生产线硬规则：**
1. **叙事氛围线**：让模型负责人物、情绪、场景、酒液、口播和节奏。产品若出现，只作为 P0/P1 背景或局部，不要求包装正面可读。
2. **产品动作线**：只做 P2；每镜独立生成、每镜重新注入同一产品参考资产、单镜独立验收。快节奏来自剪辑快切，禁止通过让产品高速旋转、甩动或复杂手部交互制造速度。
3. **SKU 保真线**：只做 P3；真实产品资产永远在前景保留，视频模型只能提供环境、光影、景深、凝露和轻微镜头运动。价格、卖点文字、品牌文字等由真实资产或后期文字层承载，禁止让生成模型重画。

**路由判定：**
- L1：所有镜头可用叙事氛围线；允许单模型连续生成。P1 即使仅作背景，也必须逐镜携带 `P-CORE` 或同等真实产品参考。
- L2：至少所有 P2 镜必须走产品动作线；P1 仍可走叙事氛围线，但不得省略真实产品参考。
- L3：P3 必须走 SKU 保真线；P2 仍走产品动作线；P1/P0 走叙事氛围线；其中 P1 仍须按审计总表引用真实产品参考。
- 一条视频可以同时使用多个模型；**需要一致的是产品资产与验收标准，不是强行用同一个模型。**

### Phase 8：派生资产包（按蓝图、分镜与路由条件触发）

从剧本与已确认的 Phase 7 分镜台账中提取本视频相关的**所有资产清单**（角色锚点/场景/产品/道具/首尾帧），产出资产 SPEC。开始前必须加载 `references/asset-workflow.md` 的「资产触发矩阵」，逐镜判定每类资产为必出或豁免；禁止凭主观“按需”跳过。

**统一编号机制**（全片强制复用、不重置）：为每项资产分配稳定编号，跨镜头、多段拼接（Phase 11）时沿用；这样 AI 生成才能锁定同一张脸/同一个场景，避免"上一秒一个长相"。
- 角色资产：Seedance/H3 路径用黑白素描参考 `图1`、`图2`…（记录角色结构 / 发型 / 发色 / 体型 / 服装）；可灵路径用用户授权真人照片/视频作 I2V 身份锚定 `I2V-人物1`、`I2V-人物2`…，免产素描。未经授权的真人素材不得使用。
- 角色服装：按场景风格设定，每条视频独立变化；同视频内换装沿用身份编号加后缀（如 `图1-A`），并在变更处标秒数
- 场景：`场景1`、`场景2`…（锁定 门窗位置 / 家具 / 主光方向 / 材质 / 前中后景关系）
- 道具：`道具1`、`道具2`…（锁定 材质 / 颜色 / 尺寸感 / 状态）

> **每类资产的完整 PROMPT 字段结构见 `references/asset-workflow.md`「资产视觉指令集」**：产品四视图 / 人视三视图 / 服装 / 场景 / 道具 / 首尾帧各一套【】字段化指令 + 固定「生成要求」尾巴（可直接复制去平台），全局禁用抽象审美词。

- **产品资产分层（L2/L3 必做）**：产品不再只有一张四视图，按 Phase 7.5 路由建立可追溯台账：
  - `P-CORE`：**产品四视图**（1×4 拼接单图：正/背/侧/顶，客户实拍图为唯一参考，锁定产品视觉总档案）。
  - `P-HERO`：场景化产品保真首帧（9:16；真实产品已进入本镜目标场景；正面清晰、产品占画面约 35%-50%，供 P2 产品动作线每镜重新注入）。
  - `P-PACKSHOT`：真实 SKU 正面高清透明 PNG 或可抠图实拍（供 P3 保真线；Logo、包装文字、版式必须可读）。
  - `P-TOP`：罐顶/易拉环/开合结构近景（有开罐/开盖镜时必备）。
  - `P-SIDE`：侧面或手持可见面（有取放、手持、倒酒镜时必备）。
  - `SB-15`：15 秒 9 宫格分镜预演图；`SB-30-A/B`：30 秒两张 9 宫格；每张宫格必须关联逐格文字台账。
  - `KF-N`：按 Phase 7 触发清单，从对应分镜格和真实产品/人物资产派生的高清关键帧，N 为镜头号；在派生资产包中整批确认。
  - 台账字段：`asset_id / 类型 / SKU或角色 / 关联镜号 / 触发原因 / 真实性来源 / 可见面 / 允许用途 / 是否含可读文字 / 不可变项 / 生成或SPEC状态 / 客户确认状态 / 豁免理由`；分镜台账另加 `时间 / 构图 / 动作 / 产品状态 / 运动 / P级 / 连续性`。
  - 台账汇总必须写：计划数 / 已生成或已完成 SPEC 数 / 已确认数 / 待补数；每个“未做”项必须填对应镜号与 `asset-workflow.md` 资产触发矩阵中的豁免条件。
  - **逐镜产品资产审计总表（必交付）**：另列 `镜号 / P级 / 路由等级 / 最低资产标准 / 实际资产ID或参考 / 状态 / 客户确认 / 豁免理由或回退动作`。P1/P2/P3 镜任何一个最低资产缺失即 FAIL，禁止以“后续补”“默认参考”“产品概念图”或“资产完整”通过。
  - P0 无产品资产；P1 至少需 `P-CORE` 或同等真实产品参考并逐镜引用；P2 至少需 `P-CORE + P-HERO` 并逐镜重新注入或登记获准复用来源；P3 至少需 `P-CORE + P-PACKSHOT`，若同镜含产品动作则再加 `P-HERO`。缺失则禁止承诺相应产品保真。

- **P-CORE 产品四视图**（**1×4 拼接单图**：正/背/侧/顶四角度左→右并排，单张图；白底电商风 16:9，**只做图生图**——喂客户实拍图作唯一参考，实物一致 100%，整图一次性交客户确认；缺角度先问客户「补拍还是 AI 补」，AI 补的标「待客户确认」。**禁止拆成 4 张独立图交付**。）
- **人视三视图**（**1×3 拼接单图**：正/侧/背三角度左→右并排，单张图；白底电商风 16:9）：
  - **Seedance/H3 路径的现实真人或虚构角色**：正式人物资产生成黑白铅笔素描 / 黑白线稿的 1×3 三视图；用户授权的真人照片可用于生成素描。
  - **可灵路径的现实真人**：不生成黑白素描；必须使用用户授权的真人照片/视频作为 I2V 身份锚定，并在资产台账登记 `I2V-人物N`、授权状态与关联镜号。虚构角色如无授权真人素材，则不适用该路径，应改走可用的素描资产或其他合规方案。
  - 除可灵 I2V 的授权参考外，人物资产禁止输出真人照片、彩色肖像、写实真人三视图或图生真人。
  - **禁止拆成 3 张独立图交付**。
- 角色服装设定（锁定「穿什么」，**每条视频按场景风格变化**；真人 IP 换装不换脸）
- 场景锚点（对应 `场景N`，脚本出现几个场景就做几张，**每条视频独立**）
- 关键道具（对应 `道具N`）、首尾帧

**资产复用规则（多条视频之间）**：产品主资产和人物身份资产按同 SKU/同角色复用；品牌级/系列级场景、服装和道具在蓝图明确要求连续性时允许跨视频复用，但必须登记来源、关联视频和不可变项。禁止未经台账的盲目复用；临时动作关键帧和首尾帧默认不跨视频。资产数量按分镜和路由实际触发，不套默认值。详见 `references/asset-workflow.md`。
- **人物资产统一规则**：Seedance/H3 路径人物形象图只交付黑白铅笔素描 / 黑白线稿；**可灵路径免素描**，直接以授权真人照片/视频作 I2V 参考。视频 PROMPT 如需真实人物风格，必须另行确认，不能把人物资产图改成真人照片
- **国外人物/场景资产注意**：人物须多元选角、忌群体刻板与冒犯；信仰相关服饰、敏感标识谨慎使用；场景避免文化禁忌（如特定手势/饮食/节日误解）；脚本用目标市场语言+本地字幕，幽默与文化梗本地化，不硬搬中文梗
- **爆款参考素材清单（仅爆款复刻时）**：爆款视频本体/链接（画面/运镜/节奏参考）、爆款文案/字幕（台词参考）、爆款 BGM（仅拆解节奏点、剪辑密度与情绪曲线；不写入生成 PROMPT、不复用原曲或同风格替代曲）、爆款数据（点赞/转发/评论，判断"爆"在哪一段）、客户自己的产品图/素材（不同品同款必需）。详见 `references/viral-replicate.md` 第七节。

**交付形态（双模式）**：
- 纯提示词模式：本阶段只产出「资产提示词 / SPEC 清单」交给用户去平台生成。
- 生成模式：由 agent 实际生成资产文件——
  · 产品四视图 1×4 拼接单图、Seedance/H3 路径的人视三视图 1×3 拼接单图，按资产 SPEC 调 `node video_api.cjs image --prompt "<资产提示词>" [--image @参考图]` 整图一次性产出；可灵路径不产人视三视图，登记并校验用户授权的真人 I2V 参考；
  · 统一编号（图1 / 场景1 / 道具1…）跨镜头复用，确保同一张脸 / 同一个场景锁定；
  · 每条视频独立生成不同变体（复用规则见上方「资产复用规则」）。
  · 资产文件或授权参考就绪后，交用户确认（产品四视图按 100% 一致强约束逐项验收；Seedance/H3 的人物黑白素描三视图与已确认设定一致；可灵的真人 I2V 参考须逐项确认授权、身份匹配与关联镜号；其它资产完整），通过再进 Phase 9 / 10。

资产 SPEC 先以模型无关形式列出，Phase 10 再按 Phase 7.5 每镜路由映射到对应格式。九宫格按有效视觉状态组织；关键帧仅按 Phase 7 触发清单生成。

#### Phase 8 硬门：停—查—报（必须）

派生资产 SPEC 或资产文件完成后，**必须暂停**，加载 `references/phase-checklist.md` 的「Phase 8：资产完整性确认门」，输出资产总台账及核验报告。报告必须给出计划数、已生成数、已确认数、待补数，以及每项资产的资产 ID、蓝图版本、来源分镜格、关联镜号、触发原因、状态和豁免理由。P-HERO/P-PACKSHOT、场景锚点、道具/首尾帧和被触发关键帧等条件阻断项，均须按实际镜头逐项通过或写明允许的豁免；用户确认以整批派生资产包为单位，不逐张打断。任一阻断项 FAIL，禁止进入 Phase 9/9.5/10。

### Phase 9：生产路由与资产一致性复核（生成前必做）

本 Phase 不再检查“全片是否锁同一个模型”，而是逐镜确认路由表、资产和目标能力是否一致：

- **复核 1·镜头产品职责不越级**：L1 不得宣称 SKU 保真；L2 不得把 Logo/文字/固定版式列为验收条件；L3 的所有 P3 镜必须已经路由到 SKU 保真线。
- **复核 2·资产匹配镜头**：P2 每镜都有 P-HERO 或同一真实产品参考可重新注入；出现顶部/开合/接口结构则有对应顶部或开启状态资产，出现侧拿/倾倒/侧面图形则有侧面资产；P3 必有客户确认的 P-PACKSHOT。缺一项回 Phase 8 补。
- **复核 3·模型匹配职责**：人物/氛围镜、产品动作镜、SKU 保真镜均使用路由表指定的能力；任何模型不能被分配其明确不擅长的 SKU 重画职责。
- **复核 4·时长与动作匹配**：P2/P3 单镜时长和动作边界符合路由表；产品主视觉不塞进复杂人物表演、高速旋转、快速遮挡和多次转场的同一镜。
- **复核 5·剪辑计划可执行**：所有独立片段都有清晰的切点、声音衔接和片段编号；跳切镜不强行用尾帧续写。

五项通过 → 才能进入 Phase 10 分镜头写 PROMPT。若用户改变产品、包装不可变项或生产模式，必须回到 Phase 0；L1/L2/L3 由内部按镜头职责自动分配，不需要用户选择。若仅替换某个镜头的模型，在不改变镜头职责、资产和验收标准的前提下，只更新该镜的路由与对应 PROMPT。

### Phase 9.5：视频成本治理与人工审批门（出片前必经关口）

图片资产成本已经分别在 Phase 6.5 基础资产包和 Phase 7/8 分镜/派生资产包批准；本关口只审批尚未发生的视频生成、微动、合成和必要声音制作成本，避免重复审批已完成图片：

- **① 成本预估（estimate）**：Phase 10 写 PROMPT 前，按 Phase 7.5 路由逐镜估尚未发生的总花费：叙事线片段 + P2 产品动作镜独立片段 + P3 微动/合成片段 + 必要声音层。每一项写明模型/工具、时长、单价或待询价状态，最后给合计区间。不得再按“一个锁定模型 × 全片时长”粗算。
- **② 预算红线 + 90% 预警（reserve/预警）**：客户给了预算上限 → 预估超 90% 即报警、不静默继续；未给上限 → 按默认安全档提示客户确认量级，不默认无上限。
- **③ 人工审批门（human approval，硬卡）**：预估完成后、**调用任何视频生成/微动/合成/付费声音 API 之前**，必须一次性把「模型 + 段数 + 参考资产 + 预估花费 + 时长 + 重试上限」报给客户，等客户明确同意才动手。图片资产继续受各自批次授权约束，不在这里重复确认。
- **④ 出片后对账（reconcile）**：生成完成后，记录实际花费 vs 预估，差异 >20% 回溯分镜/资产是否超配；审批与对账结论建议记入 decision_log 便于回溯。

> 本关口是「花钱」闸门，不是「出 PROMPT」闸门——纯提示词模式照常交付，只是多带一张成本预估单；生成模式（调用 video_api.cjs）必须卡过 ③ 才动手。

### Phase 10：生成视频 PROMPT（必须）

> **Phase 10 总闸门（先加载）**：写任何模型 PROMPT 前必须先读 `references/prompt-delivery-contract.md`，逐镜建立事实卡并按其最终 FAIL 门验收。**模型官方公式的用途**是提供目标模型可识别的语法、字段、素材引用、时间轴和能力边界；公式不是脱离项目的固定填空题。PROMPT 的内容必须以已确认视频创意蓝图、剧本、分镜、台词、路由、资产、时长和平台要求为事实源，再翻译成该模型的官方格式。

> **铁律·导演思维公式（来自小逻，定死框架：以后所有视频按这个做）**：写 PROMPT 必须分两步走，**严禁跳过第 1 步直接写**——加载 `references/model-specs.md`「导演思维公式」完整执行：
> 1. **第 1 步【导演决策】（模型无关）**：每个镜头先定 4 件事——景别与功能 / 运镜意图 / 六维表演（禁情绪词）+ 电商范式 / 节奏。1-2s 与 3-5s 只作经验区间；实际时长必须足以完成动作、说完台词、看清证明并符合蓝图节拍，不能为匹配标签机械重排。
> 2. **第 2 步【模型翻译】（按 Phase 7.5 每镜路由）**：查「运镜意图对照表」换该镜目标模型的官方运镜词 → 查「各模型 PROMPT 翻译公式」把导演意图转成对应语法 → 套该镜模型格式（六板块/一句话/分镜标签/英文字段）；P3 则输出真实资产微动/合成指令，而不是让模型重画包装。
>
> 两步走完，才进入下方各模型具体格式。**不走两步直接写 PROMPT = 不合格，打回重写。**

按 Phase 7.5 的镜头级路由，把分镜（Phase 7）+ 资产（Phase 8）逐镜转成对应格式（5 条模型路线格式完全不同，P3 走真实资产微动/合成指令）：

> **段长与拆镜铁律（以镜头路由为准）**：叙事氛围线可按目标模型单次最大时长组织（可灵/Seedance 2.0/Mini/H3 通常 15s，Seedance 2.5 通常 30s）；**P2 产品动作镜和 P3 SKU 保真镜例外，必须按镜独立生产，推荐 1-3 秒，不得为了“写满 15 秒”把产品保真镜与人物表演、复杂转场硬塞成一段。**快节奏来自剪辑切点，不来自产品高速运动。镜头段长由 Phase 7.5 路由表决定；只有连续叙事段才进入 Phase 11 尾帧衔接。

- **Seedance 2.0/2.5** → `references/seedance-prompt.md`（中文六板块 + @引用）。**六板块为强制骨架，缺一板视为不合格、必须重写**：
  ① 角色 + 参考图（每个 @引用必须带"仅"字限定用途；**含产品时必须另含产品外观参考图 `@图片N 仅定义产品外观（轮廓/主色/材质/包装形态/尺寸比例）`——取自 Phase 8 产品四视图**）
  ② 背景介绍
  ③ 镜头描述（按该镜 Phase 7.5 路由的时长与产品级别写；叙事镜可按模型最大时长组织，P2/P3 必须按独立短镜；每镜含 景别 + 画面内容/动作 + 运镜 + 情绪弧线；**动作按"物理中间件写法"把卖点翻译成可计算的物理变化，不写广告词**）
  ④ 声音设计（**必须含两个子项且非空**：环境音/动作音效按时间 / 对白或旁白完整文案；不含 BGM，默认不生成背景音乐）
  ⑤ 风格指令（质感 + 色调 + 光线 + 景深——**必须按 `references/style-guide.md` 第三节「风格→视觉语法映射」展开成具体镜头语言/色调/质感/剪辑语法，禁止只写风格名**）
  ⑥ 禁止项（**必带 3-5 条负向约束强化**，如肢体变形/面料穿模/额外人物/霓虹卡通/镜头抽搐，详见 seedance-prompt.md §一/§十七）
  ⑦ **生成参数块（独立于六板块，必附给用户）**：按用户当前 UI/API 写时长、比例、一致性/创意设置和低成本试跑方案。需要展示包装文字、Logo、型号或版式时，仍逐字附已确认原文并写 100% 一致强约束；若当前平台实际拒绝品牌词，告知用户并把该镜切到 P3 真实资产/合成链路，不得静默删改。
- **Seedance 2.0 Mini** → `references/seedance-mini-prompt.md`（中文一句话公式 + @引用 + 时间戳，不可套用六板块）
- **MiniMax H3 关键帧模式** → `references/h3-prompt.md`（英文 3 字段；**仅用于纯视觉无口播**，如 ASMR/产品特写）
- **MiniMax H3 全能参考模式** → `references/h3-prompt.md`（英文 6 区段；**含口播/对白强制走此模式**，关键帧模式无对白字段会静默丢弃，详见 h3-prompt.md「口播/对白路由规则」）
- **可灵 Kling** → `references/kling-prompt.md`（中文场景英文参数 + 分镜标签时间轴 + I2V 身份锚定 + 口型同步，不可套用六板块）

> **纯 AI 视角交付铁律（防元注释污染）**：交付给视频生成模型的 PROMPT（六板块 + 参数块）必须**纯 AI 视角**——只写镜头 / 画面 / 声音 / 动作 / 风格 / 禁止项与生成参数，**严禁写入任何 SKILL 内部元注释**：版本号（如 v1.x.x）、"铁律""验算 PASS""Phase X""治漂移"等。视频模型无本 SKILL 上下文，看不懂这些标记，还会污染镜头描述、诱发角色 / 产品漂移。Phase 10.5 的「验算输出模板」是给客户的交付自检附件，**不喂给视频模型**，二者严格分开。

> **产品一致性生产铁律（按 L1/L2/L3 路由，不靠堆文字假装锁定）**：
> 1. **L1 / P0-P1 叙事氛围镜**：可用精简产品视觉 DNA（轮廓、主色、材质、一个主要色块），并保留“产品外观、比例、位置与参考图 100% 一致”的强约束；不要求包装正面小字可读，也不把该约束当效果担保。
> 2. **L2 / P2 产品动作镜**：每镜必须独立生成，并重新上传 `P-HERO` 或同一真实产品参考；PROMPT 只写 4-6 项模型可执行的视觉 DNA（如细高哑光白铝罐、银色易拉环、大号金黄色 28、罐身中下部黄色横向色带、白色麦穗大形状、冷凝水），同时写允许动作边界。不得把品牌小字、成分表、精确字体当作模型验收项。
> 3. **L3 / P3 SKU 保真镜**：必须调用 `P-PACKSHOT` 或实拍产品视频；真实包装保持原样，视频模型只能生成背景、光影、景深、冷凝水和缓慢推近。Logo、文字、价格、版式不得交给生成模型重画。
> 4. **出片回检**：先按路由对应的 L1/L2/L3 目标验收。P2 漂移只重跑该镜；P3 不一致必须回到真实资产/合成链路，禁止继续加长 Prompt 赌模型。

> **Mini → 2.0 升级铁律**：凡用户要求把 Seedance 2.0 Mini 的 5 秒分段 PROMPT 升级为 2.0 完整版，**必须丢弃分段骨架、从纯文字剧本（Phase 4）重新按六板块写满单次最大时长**，严禁把多段 5s 拼接充当"完整版"——拼接产物缺声音设计/风格指令/禁止项，且镜头无整条情绪弧线。

输出后附操作指引：素材准备 → 生成参数 → 检查要点 → 可选优化。

> **节奏联动**：① 镜头时长服从创意蓝图的节拍职责——快节拍通常 1-2s/镜，观察/ASMR/安装等需要看清因果的镜头可以 3-5s 或更长；不得为了标签统一而压缩未完成动作。实际以台词可说完时长、动作完成时间和 Phase 7.5 路由为准。② 镜头内运动速度（升格/正常）按目标模型规范写。模型差异查本 SKILL 内的 `references/seedance-prompt.md`、`references/seedance-mini-prompt.md`、`references/h3-prompt.md`、`references/kling-prompt.md` 与 `references/model-specs.md`，不得使用占位路径。

#### Phase 10 硬门：停—查—报（必须）

逐镜 PROMPT 与操作指引完成后、交付前，**必须暂停**，加载 `references/phase-checklist.md` 的「Phase 10：逐镜 PROMPT 交付门」，输出核验报告。逐镜覆盖、模型格式、剧本台词、资产引用、声音字段、Prompt Delivery Contract FAIL 门、Phase 10.5 验算报告任一阻断项 FAIL，禁止交付；生成模式还须在 Phase 9.5 成本审批通过后，才可调用生图/生视频能力。

### Phase 10.5：PROMPT 交付前自检门（必须，未通过禁止交付）

> **核心规则：本门是「验算式」，不是「勾选式」。** Agent 禁止只打勾了事——必须按下方 4 个验算流程，逐项**产出「验算过程 + 结论」**，并附「验算输出模板」。任一验算 FAIL → 回到对应 Phase 重写，不准带病交付。

#### 基础合规清单（快速确认，每项须引用证据，不得只打勾）

- [ ] **导演思维双步已执行**：先定导演意图（景别/运镜/表演/节奏，模型无关），再按 Phase 7.5 每镜路由翻译（查运镜对照表+PROMPT 翻译公式，见 `model-specs.md`）；P3 已改为真实资产微动/合成指令，未跳过第 1 步直接写
- [ ] **目标模型必需结构齐全**：Seedance 2.0/2.5 验六板块；Mini 验一句话公式 + 时间轴；H3 验所选模式的英文字段；可灵验分镜标签时间轴/I2V；P3 验真实资产微动/合成指令。不得用六板块检查其他模型。
- [ ] **产品路由与资产匹配（含产品必查）**：每个 P2/P3 镜已在 Phase 7.5 路由表登记；P2 有 `P-HERO`/真实产品参考并写明视觉 DNA + 动作边界；P3 有 `P-PACKSHOT`/实拍或合成方案，未把 Logo、文字、固定版式交给视频模型重画。
- [ ] **产品包装文字逐字核对**：凡分镜、资产或视频 PROMPT 要求展示包装文字、Logo、型号、配料表、酒精度或固定版式，已确认原文已逐字写入对应 PROMPT；未确认原文已标记待补；没有使用“见参考图”“文字清晰即可”等模糊表达。
- [ ] **禁止项含负向约束强化**：必带 3-5 条（肢体变形/面料穿模/额外人物/霓虹卡通/镜头抽搐等），仅写"禁文字水印"视为不合格
- [ ] **生成参数与当前界面一致**：给出目标模型当前可用的时长、比例、参考强度/一致性设置和试跑建议；reference 数值仅为快照，若当前 UI/API 不同则以当前界面为准并注明差异。已确认包装原文不得因品牌过滤规则被静默删除。
- [ ] **声音字段按模型验收**：Seedance 2.0/2.5 的环境音/动作音效、对白或旁白两子项非空（不再要求 BGM 子项）；Mini/H3/可灵按各自声音/台词字段检查，无对白镜明确标注无对白；默认不含背景音乐。
- [ ] **镜头段长符合路由**：叙事氛围线覆盖目标模型的计划时长；P2/P3 均为独立短镜（通常 1-3 秒）且没有被“必须写满 15/30 秒”的旧规则强行合并
- [ ] **@引用带"仅"字**：每个 @图片/@视频/@音频 都标注"仅定义…"，限定只取所需部分
- [ ] **模型格式正确**：Seedance 走六板块、Mini 走一句话公式、H3 走英文字段、可灵走中文场景英文参数，未混淆

#### 验算 1：逐镜时长验算（程序化，强制）

1. **提取**：从 PROMPT/分镜提取每个镜头的 `[起-止]` 时间戳，逐镜列出（不得跳过任一镜）。
2. **计算**：每镜实际时长 = 止 − 起。
3. **判定**：对照「声明区间」逐镜判 PASS/FAIL：
   - 声明「快节奏」→ 每镜 ≤ 2s，且相邻镜景别必须切换
   - 声明「慢节奏」→ 每镜 ≥ 3s
   - 声明「自拍/UGC/vlog/情景剧/中速连续」→ 每镜 3-5s 且连续不跳切
4. **产出「逐镜验算表」**（镜号 | 起-止 | 实际s | 声明区间 | 判定），任一 FAIL → 整体不通过。
5. **硬 FAIL**：出现「声明快节奏却某镜 >2s」或「实际时长与声明区间矛盾」→ 打回重排，不得交付。

#### 验算 2：对白 / 价格落地验算（强制）

1. **扫描 on-screen**：通读视频模型 PROMPT 正文，确认没有要求模型随机生成价格、促销标板或额外品牌文字。P3 真实包装原文、平台强制字幕/免责声明和 AIGC 标签必须被列入真实资产/受控剪辑/平台元数据层，不得误判为应删除内容。
2. **确认声音落地**：对白 / 旁白 / 口播 / 画外音完整文案必须出现在「声音设计 → 对白或旁白」子项（H3 落在 `detailed_description`），不在画面层。
3. **产出「落地验算表」**（要素 | 是否 on-screen | 是否在声音字段 | 判定）：
   - 价格 / 对白 既不在声音字段又无 on-screen → **丢失 FAIL**（被静默丢弃）
   - 价格 / 对白既在声音字段又要求视频模型生成随机标板 → **违规 FAIL**；若画内信息来自已确认 P3 真实资产或合规剪辑层，则按对应资产/发布规则验收
   - 价格 / 对白仅在声音字段、零模型生成标板 → **PASS**；若 P3 真实包装或平台规则要求画内信息，另按真实资产/受控剪辑/发布层验收

#### 验算 3：风格指令展开验算（强制）

1. **提取视觉语法**：从已确认《视频创意蓝图》提取真实度、镜头语言、色调、光线、材质和节奏；风格名只作辅助标签。
2. **对照展开**：查 `references/style-guide.md` 的视觉语法词典，确认每镜已把蓝图要求翻译成具体可生成指令，而不是套用固定风格模板。
3. **产出「风格展开验算表」**（要素 | 风格原名 | 展开后的具体视觉语法 | 判定）：
   - 只写「电影感 / 高级感」等空泛词未展开 → **FAIL**
   - 展开内容与所选风格矛盾（如风格=自拍自然却写「棚拍打光硬切」）→ **FAIL**
   - 四要素均展开成具体视觉语法且贴合风格 → **PASS**

#### 验算 4：产品路由与真实包装保真验算（含产品视频强制）

1. **提取镜头路由**：逐镜列出产品可见级别（P0/P1/P2/P3）、内部生产等级（L1/L2/L3）、生产线、参考资产、验收标准。
2. **查真实资产是否匹配**：P1 也必须有真实产品参考；P2 是否逐镜重新注入 P-HERO/真实产品参考、是否限制动作；P3 是否使用 P-PACKSHOT/实拍/合成，而非让模型重画包装。
3. **查验收标准是否匹配镜头职责**：L1 只用于远景/背景/氛围；L2 验产品外观动作；L3 验真实包装、Logo、文字、版式与 SKU 信息。只要产品正面或包装信息需要看清，必须按 L3 处理。
4. **相邻 P2 比对**：比较实际成片中轮廓、材质、主色、主要色块/图形；任一突变即为 L2 漂移。P3 与真实产品资产逐项比对，任一包装信息不一致即为 L3 FAIL。
5. **产出「产品一致性验算表」**（镜号 | P级别/L级别 | 生产线 | 参考资产 | 验收点 | 实际结果 | 判定 | 失败处理）。P2 FAIL 只重跑该镜；P3 FAIL 回真实资产/合成，不得通过继续添加文字 Prompt 解决。

#### 矛盾扫描（收口，任一命中即 FAIL）

逐条扫描以下经典自相矛盾，命中即整体不通过：
- 剪辑节奏=快 但 存在 >2s 的镜头
- 风格=自拍自然/UGC/vlog 但 镜头密集跳切
- 禁止项含「禁文字/禁标板」但 价格/对白 出现在画面层
- 声明时长=15s（或 2.5 的 30s）但 镜头时间戳累计 ≠ 该时长
- Seedance 2.0/2.5 六板块齐全但声音设计三子项有空白；或 Mini/H3/可灵缺其模式必需字段
- 需要展示已确认包装原文却被静默删掉；或让视频模型凭空生成额外品牌/价格标板
- **分镜或 PROMPT 偏离蓝图主要视觉语法，且变化没有对应镜号、叙事职责或用户确认依据** → 回 Phase 7/10 修正；蓝图已登记的局部节奏或视觉强调不判冲突
- **P2 产品动作镜在任两镜间出现轮廓/材质/主色/主要色块或比例突变**（非剧本刻意设计所致）→ L2 FAIL，只回炉重跑该产品镜；不得连带重做叙事镜。
- **P3 SKU 信息镜的 Logo、文字、固定版式、型号或价格与 P-PACKSHOT 不一致** → L3 FAIL，回真实产品资产/微动/合成链路；禁止通过增加 Prompt 文字继续赌生成模型。

#### 验算输出模板（强制提交，附在 PROMPT 之后）

```
【Phase 10.5 验算】
· 基础清单：目标模型结构全 ✓（导演双步/模型字段/负向/参数/声音/时长/素材引用/格式）
· 验算1 逐镜时长：[镜1 0-2s(2)✓][镜2 2-4s(2)✓]…[镜N …] → 整体 PASS/FAIL
· 验算2 对白价格：价格→口播带出·零模型生成标板 ✓；P3/法定画内信息→真实资产或受控剪辑层 ✓ → PASS/FAIL
· 验算3 风格展开：自拍手持→手持晃动+自然光+生活质感 已展开 ✓ → PASS/FAIL
· 验算4 产品一致性：[镜3 P2/L2·P-HERO·轮廓/主色/色块✓][镜7 P3/L3·P-PACKSHOT·SKU信息✓] → PASS/FAIL
· 矛盾扫描：无命中 ✓
· 结论：PASS → 可交付 / FAIL → 打回重排（注明哪条）
```

### Phase 11：片段衔接、SKU 回检与剪辑交付（按镜头路由执行）

本阶段不再把“视频超过 15 秒”视为唯一拆段原因。Phase 7.5 已产出独立的叙事镜、P2 产品动作镜、P3 SKU 保真镜；现在按分镜表的切点进行生成后验收与剪辑拼接。仅当某一条**连续叙事线**超过其目标模型单次时长且分镜标记「尾帧衔接 = 是」时，才对该条线执行尾帧续写。

- **跳切镜 / 独立 P2/P3 镜**：直接按路由独立生成或合成，不取上一镜尾帧；生成完成后按各自 L1/L2/L3 验收，不把尾帧续写误当产品一致性方案。
- **尾帧衔接 = 是（连续叙事段）**：仅对同一叙事线强制走「尾帧高清还原 + 校验-重试闭环」，所有参与该连续线的模型一致执行，**绝不允许跳过还原、绝不用低清尾帧直接当首帧、绝不在重试耗尽前回退**：

  1. **拆段**：按剧本自然停顿拆成 15s 内每段（段1、段2…），每段独立写提示词。
  2. **生成段1**，导出视频。
  3. **取尾帧**：截取段1 最后一帧（画面构图）。
  4. **强制高清还原**：以尾帧为参考底图，用「同构图高清重绘」提示词超分 / 重绘到更高清（画面内容/构图/主体/服装/光源/色调完全不变，仅提升分辨率与细节清晰度）。Seedance 见 `references/seedance-prompt.md` 第十节；Mini 走视频延长链式续写（见 `references/seedance-mini-prompt.md` 第六节）；H3 用首尾帧 FL2VA 对齐 / Regenerate-2K（见 `references/h3-prompt.md`）；可灵走视频续写从尾帧无缝继续（见 `references/kling-prompt.md` 第六节）。
  5. **校验一致（强制）**：逐条视觉比对重绘图与尾帧——主体、构图、服装、光源、色调、姿态必须一致；并用客观指标（SSIM / 感知哈希，设阈值）辅助。
  6. **重试闭环（最多 3 次总尝试）**：首次校验通过就停止；不一致才重做（降去噪 / 升参考权重 / 加约束词 / 换种子），累计最多 3 次。**重试耗尽前禁止回退低清尾帧、禁止跳过还原步骤。**
  7. **当首帧**：把通过校验的高清图作为段2 的「首帧参考」，段2 提示词开头写「画面从这张首帧无缝继续」。
  8. 循环直到末段，最后在平台/剪辑里拼接成片。

> **红线**：尾帧高清还原是强制步骤，不存在「画质够就跳过」「漂移就回退截图当首帧」的退路。连续段必须还原到高清且校验一致；极端情况（3 次仍不一致）**上报用户**，不静默降级、不拿低清尾帧糊弄。

**产品一致性回检（出片后强制，与尾帧闭环同级）**：按 Phase 7.5 的镜头级目标验收，而不是拿同一把尺子误判所有产品镜：
- `P0/P1 / L1`：验品类、主色和叙事合理性；不把包装小字、Logo 当失败依据。
- `P2 / L2`：逐镜截图比对 P-HERO/P-CORE 的轮廓、比例、材质、主色、主要色块/图形。单镜漂移只重跑该镜；可尝试区域编辑，但不能把文字/Logo 精确修复承诺给生成模型。
- `P3 / L3`：逐镜与 P-PACKSHOT 或实拍素材比对 Logo、文字、版式、型号、价格等。任一不一致立即回真实资产微动/合成链路，不允许继续改长 Prompt 重赌模型。
- 多镜系统性 L2 漂移：回 Phase 8 复核 P-HERO/参考图质量，再重跑产品动作线；不得连带重做合格的叙事镜。
- 极端情况（3 次 P2 重跑仍失败，或 P3 无可用真实资产）必须上报用户，说明是资产/模型边界，不静默交付“好看但不对”的产品。
> **红线**：产品一致性回检不可省。纯提示词模式须附“产品一致性自检表”和对应的失败回炉路径，不能只交一段 Prompt。
