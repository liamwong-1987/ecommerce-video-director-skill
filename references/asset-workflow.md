# 资产制备工作流

> **执行方说明（重要）**：本文件里的「图片生成提示词结构 / 资产SPEC」是**交付物**，不是 agent 自动执行的指令。
> - **纯提示词模式**（默认）：agent 只把这些提示词与 SPEC 交给用户，由用户去即梦/Seedance/MiniMax/GPT-Image 等平台手动生成资产。
> - **生成模式**：仅当用户已接生图能力时，agent 才实际调用生成并把文件存到下方目录。
> 严禁在纯提示词模式下指挥 agent 调用 imagegen / 生图动作。

资产数量由分镜脚本逐镜盘点决定，脚本里出现几个就做几个，不套固定默认值。只生成实际镜头需要的资产，避免超过模型素材预算。

## 资产盘点规则（按脚本，不套默认值）

Phase 8 从分镜脚本逐镜盘点，脚本需要什么就列什么，数量等于脚本实际出现的次数：

| 类型 | 数量依据 | 用途 |
|------|---------|------|
| 产品四视图 | 每 SKU 一套（正/背/侧/顶 4 张） | 锁定产品外观，跨视频共用 |
| 角色身份锚点 | 每个出镜角色 1 张 | 锁定「是谁」（脸/体型/发型） |
| 角色服装设定 | 每条视频按场景风格 1 套 | 锁定「穿什么」，每条视频变化 |
| 场景锚点 | 脚本出现几个场景就做几张 | 锁定空间、光线、关键物位置 |
| 关键道具 | 脚本出现几个道具就做几个 | 道具参与反转时使用 |
| 首尾帧 | 每镜 0-2 张，按脚本定 | 固定构图或跨镜衔接时使用 |

## 资产复用规则（多条视频之间）

- **产品四视图：跨视频共用**。同一 SKU 所有视频共用一套四视图，只生成一次，不重复生成。
- **其它资产（角色/场景/道具/首尾帧）：每条视频独立，禁止跨视频复用**。即使两条视频用「同类型场景」（比如都是办公室），也要各自重新生成不同变体，不沿用上一条的图。生成时每次产出新变体（文件名带视频编号或 `-v2`/`-v3`），不覆盖旧文件。
- **多品（多 SKU）**：每个 SKU 一套四视图，互不混用。

## 产品四视图制备规范（重要）

产品资产是唯一要求「实物一致性 100%」的资产，生成方式与验收都比其它资产严格：

- **四视图**：正视图 / 背视图 / 侧视图 / 顶视图，共 4 张。
- **画幅与风格**：白底电商风格，16:9 横版。
- **生成方式**：**只做图生图**——把客户提供的产品实拍图（多角度）作为唯一参考输入（Input images），让生图模型基于实拍图做角度规整/补全。**禁止文生图凭空画产品**（Logo 字体、颜色数值、接口位置、背面结构一定会漂移）。
- **一致性 100%**：产品轮廓、颜色、材质、Logo 方向、文字、型号、接口/开合状态必须与实物完全一致，不得增删任何细节。
- **缺角度处理**：客户只给了部分实拍角度时，**先问客户**——「缺失的 X 视图，是补拍给我，还是用 AI 基于现有实拍图补全？」。客户选 AI 补的角度，必须在资产台账里标「待客户确认」，不得当作实拍看待。
- **验收**：四视图逐张交客户确认，客户点头才进视频；其它与产品相关的资产（产品图、Logo、品牌名、店铺/包装相关）同样严格确认，不自动放行。

## 角色资产 = 身份锚点 + 服装设定（拆分）

角色资产拆成两件事，分别管理：

### 身份锚点（锁定「是谁」）

- 年龄段、性别、脸型、肤色、五官比例、发型发色、体型、身高关系
- 正面或四分之三视角、全身可见、干净中性背景
- **真人 IP**：跨视频共用同一套身份锚点（因为是同一个真实的人，共用才能保证「同一个人」）
- **虚构角色**：每条视频独立生成（每条是不同的角色设定）
- 不要把不同年龄/发型/五官塞进同一锚点；衍生图一次只改一个条件（表情/姿势/机位）
- 多人先分别生成锚点，再用身高/站位区分

### 服装设定（锁定「穿什么」，每条视频变化）

- 上衣/下装/鞋/配饰、主辅色、材质
- **无论真人 IP 还是虚构角色，服装每条视频都要有变化**，不沿用上一条的服装
- 服装按「视频场景风格」来定：办公室场景穿正装、户外场景穿休闲、居家场景穿便服，先看脚本场景再定服装
- 真人 IP 换装时，保留身份锚点（脸/体型/发型不变），只换服装设定

## 场景/产品/道具

电商短视频默认竖版 9:16 交付画幅（产品四视图资产例外，为白底 16:9），资产构图与分镜留白按此预留（横版仅当平台明确要求时）。

- 场景锚点写清：入口方向、窗户方向、主光方向、桌椅产品位置、镜头运动路径；跨镜保持轴线
- 场景按脚本逐镜盘点，出现几个场景就做几张，不同视频各自独立生成
- 产品四视图见上方「产品四视图制备规范」，已有实拍图优先作参考输入，不重绘精确 Logo/包装文字/型号/成分表/认证
- 没有产品图只生成"概念占位图"，不把虚构包装当最终资产

## 写实真人脸过审技巧（重要）

Seedance 平台对真实人脸内容审核极严，即使 AI 生成的写实真人形象也常过不了审。形象图用**黑白素描铅笔画**过审：

```
黑白素描铅笔画风格人物肖像，[性别]，[年龄]，单人正面半身像，正对镜头。
手绘铅笔素描质感，黑白灰调，细腻排线，明暗层次分明，纸张纹理。
[体型/脸型/发型/五官]，[表情]，眼神看向镜头。
[服装]，背景留白浅灰。
纯手绘素描风格，无文字，无水印。
```

视频 PROMPT 里强制还原写实（见 `seedance-prompt.md`）。

## 本地保存规范

```
assets/
  products/      product-<sku>-front.png / back.png / side.png / top.png   ← 跨视频共用
  characters/    char-01-identity.png（身份锚点）                           ← 真人IP共用/虚构每条独立
                 char-01-outfit-<scene>.png（服装设定，每条视频变体）
  scenes/        scene-01-office-anchor.png（每条视频独立，变体 -v2 -v3）
  props/         prop-01.png
  keyframes/     s03-first-frame.png
```

- 产品四视图放 `products/`，跨视频共用，只生成一次
- 其它资产按视频各自生成新变体，文件名带视频编号或 `-v2`/`-v3`，不覆盖旧文件
- 文件名小写英文+数字+连字符。目标存在时创建 `-v2`、`-v3`，不覆盖

## 资产验收

- 产品四视图：轮廓/颜色/材质/Logo 方向/文字/开合状态与实物 100% 一致；**逐张交客户确认**，客户点头才进视频
- 与产品相关资产（产品图、Logo、品牌名、店铺/包装相关）：严格确认，不自动放行
- 角色：身份锚点（脸型/发型/体型）稳定；服装设定每条视频有变化且匹配场景风格
- 场景：空间布局/光源方向/时间/关键物位置连续
- 构图：符合画幅，主体完整，留出动作和字幕空间
- 安全：无可识别真人脸参考、第三方水印、随机品牌文字
- 文件：能打开，路径存在，台账状态与实际一致

不合格时只针对一个失败点重生成，保留旧文件为版本。
