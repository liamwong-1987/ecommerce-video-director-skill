# 资产制备工作流

> **执行方说明（重要）**：本文件里的「图片生成提示词结构 / 资产SPEC」是**交付物**，不是 agent 自动执行的指令。
> - **纯提示词模式**（默认）：agent 只把这些提示词与 SPEC 交给用户，由用户去即梦/Seedance/MiniMax 等平台手动生成资产。
> - **生成模式**：仅当用户已接生图能力时，agent 才实际调用生成并把文件存到下方目录。
> 严禁在纯提示词模式下指挥 agent 调用 imagegen / 生图动作。

只生成实际镜头需要的资产，避免超过模型素材预算。

## 最小资产包

| 类型 | 默认数量 | 用途 |
|------|---------|------|
| 角色锚点 | 每个主角 1 张 | 锁定脸型、发型、体型、服装、配色 |
| 表情/姿态 | 每个主角 0-1 张 | 复杂反应或动作才需要 |
| 场景锚点 | 每个主场景 1 张 | 锁定空间、光线、关键物位置 |
| 产品图 | 1-2 张 | 锁定外观、包装、打开/使用状态 |
| 关键道具 | 0-1 张 | 道具参与反转时使用 |
| 首尾帧 | 每镜 0-2 张 | 固定构图或跨镜衔接时使用 |

## 角色锚点

- 年龄段、性别、脸型、肤色、五官比例、发型发色、体型、身高关系
- 上衣/下装/鞋/配饰、主辅色、材质
- 正面或四分之三视角、全身可见、干净中性背景
- 不要把不同服装/年龄/发型塞进同一锚点；衍生图一次只改一个条件（表情/姿势/机位）
- 多人先分别生成锚点，再用身高/站位/服装颜色区分

## 场景/产品/道具

- 场景锚点写清：入口方向、窗户方向、主光方向、桌椅产品位置、镜头运动路径；跨镜保持轴线
- 已有产品实拍图优先直接用，不重绘精确 Logo/包装文字/型号/成分表/认证
- 没有产品图只生成"概念占位图"，不把虚构包装当最终资产

## 图片生成提示词结构

```
Use case: <stylized-concept|product-mockup|identity-preserve>
Asset type: <角色锚点/场景锚点/产品参考/首帧/尾帧>
Primary request: <核心要求>
Input images: <Image 1: 角色锚点；Image 2: 产品参考>（如有）
Scene/backdrop: <空间与背景>
Subject: <主体和可观察特征>
Style/medium: <3D stylized/动画/插画/产品摄影>
Composition/framing: <9:16、景别、机位、留白>
Lighting/mood: <光线方向与情绪>
Color palette: <稳定色彩>
Materials/textures: <服装或产品材质>
Text (verbatim): "<必须准确的文字>"
Constraints: <必须保持的特征>
Avoid: <无关人物、随机文字、水印、Logo 漂移>
```

## 写实真人脸过审技巧（重要）

即梦禁止上传清晰真人脸部素材。形象图用**黑白素描铅笔画**过审：

```
黑白素描铅笔画风格人物肖像，[性别]，[年龄]，单人正面半身像，正对镜头。
手绘铅笔素描质感，黑白灰调，细腻排线，明暗层次分明，纸张纹理。
[体型/脸型/发型/五官]，[表情]，眼神看向镜头。
[服装]，背景留白浅灰。
纯手绘素描风格，无文字，无水印。
```

视频 PROMPT 里强制还原写实（见 `seedance-prompt.md`）。

## 本地保存规范

```
assets/
  characters/    char-01-anchor.png
  scenes/        scene-01-office-anchor.png
  products/      product-01-front.png
  props/         prop-01.png
  keyframes/     s03-first-frame.png
```

文件名小写英文+数字+连字符。目标存在时创建 `-v2`、`-v3`，不覆盖。

## 资产验收

- 角色：脸型/发型/体型/服装/配色/配饰稳定
- 场景：空间布局/光源方向/时间/关键物位置连续
- 产品：轮廓/颜色/材质/Logo 方向/开合状态正确
- 构图：符合画幅，主体完整，留出动作和字幕空间
- 安全：无可识别真人脸参考、第三方水印、随机品牌文字
- 文件：能打开，路径存在，台账状态与实际一致

不合格时只针对一个失败点重生成，保留旧文件为版本。
