# Seedance 2.0 Mini 提示词规范

> **模型**：`doubao-seedance-2-0-mini-260615`。成本减半（约 0.5 元/秒，`--service-tier flex` 离线再省 50% ≈ 0.25 元/秒），速度更快，画质略低于标准版 2.0，但电商/营销/批量场景够用。
> **单次时长（铁律）**：单次最长 15 秒（API 单次最长 12s、平台最长 15s）。**一个 PROMPT 必须写满 15s**，时间戳在 15s 内细分，**禁止拆成 5 秒一段单独生成**；超过 15s 才走第六节「视频延长」。分辨率 2K。宽高比 16:9 / 9:16 / adaptive。
> **规则来源**：本文件规则来自 SkillHub `@user_c246cf13/rong-shu-seedance-mini-video-creation`（Seedance 2.0 Mini 官方 SKILL）及即梦官方 prompt 示例，2026-08 吸收。

## ⚠️ 最坑的一点：不要套用 2.0/2.5 的六板块

Seedance 2.0/2.5 走「六板块 + @图片N」的**结构化长提示词**（见 `seedance-prompt.md`）。**Mini 不吃这套**——它的提示词是**一句话式简洁公式**，塞六板块标题反而会干扰生成、浪费生成次数。

**Mini 的核心公式（官方推荐）**：

```
提示词 = 主体 + 运动，背景 + 运动，镜头 + 运动
```

- **具象描述**，杜绝抽象词（❌"美丽的" → ✅"穿白裙的女孩站在樱花树下"）。
- **重要内容前置**，不重要的一律省略。
- **描述场景与变化，不是静止瞬间**：写清这几秒里发生了什么。

## 一、提示词模板

### 电商产品视频（本 SKILL 主场景）

```
@图片1 作为产品主视觉
[产品名称] 在 [场景] 中，[核心卖点动作]，镜头 [运镜方式]，[光线/氛围]，[品牌质感]
```

### 营销/口播短视频

```
@图片1 作为背景/参考
[人物/产品] 做出 [关键动作]，[情绪高潮点]，镜头 [运镜]，[节奏/音乐感]，[品牌信息露出]
```

### 通用快速生成

```
[主体] 在 [环境] 中，[动作/变化]，[镜头语言]，[风格/色调]
```

## 二、@引用规则（和 2.0/2.5 一样，但更依赖首帧图）

- 命名：`@图片1`~`@图片9`、`@视频1`~`@视频3`、`@音频1`~`@音频3`（必须中文命名，不是 `@image1`）。
- **每个 @ 必须标清用途**：`@图片1为首帧`、`参考@视频1的运镜`、`背景音乐参考@音频1`。
- 区分「参考」与「编辑」。
- **图生视频优先**：文生视频随机性大，建议先用图片生成模型造好首帧，再图生视频；上传图片要**高清高质量**，图片质量直接决定视频效果。

## 三、时间戳分镜（一个 PROMPT 写满 15s）

一个 PROMPT 覆盖完整 15s，时间戳在 15s 内细分，**不拆成 5 秒一段**：

```
0-3秒：[画面描述 + 镜头语言]
4-8秒：[画面描述 + 镜头语言]
9-12秒：[画面描述 + 镜头语言]
13-15秒：[画面描述 + 镜头语言]
```

## 四、技术参数前缀（可选，写开头）

提示词开头写画幅/帧率/时长/色调总纲：

```
2.35:1，24fps，15秒，霓虹高饱和冷暖对比
```

## 五、禁止项声明（结尾写）

```
禁止：任何文字、字幕、LOGO 或水印
```

## 六、视频延长 / 多段（>15s 时）

Mini 单段写满 15s，超 15s 才用「视频延长」链式续写：

```
将@视频1延长15秒。1-5秒：[接上段结尾画面 + 动作]；6-10秒：[……]；11-15秒：[……]
```

- 每段写清**衔接点**：上段结尾画面 = 下段开头。
- 分段逻辑：16–30s 拆 2 段、31–45s 拆 3 段、46–60s 拆 4 段、>60s 多段 + 剪辑拼接。
- 与 2.0 的「尾帧高清重绘衔接」不同，Mini 优先用「视频延长」链式续写直接衔接——但**仅在分镜（Phase 7）标记「尾帧衔接 = 是」的连续段**才走；跳切段（分镜标「否」）直接新景别独立生成，不取尾帧。视频延长本身是平台内高清续写，**不允许在衔接处用低清尾帧糊弄**（不存在"画质略低就免还原"的退路）。

## 七、电商广告场景策略

- **产品展示**：产品 360° 旋转、爆炸分解、3D 渲染；第一人称手作体验。
- **运镜选词**：环绕拍摄、推镜头、焦点转移、微距（静物特写 → 缓推/浅景深/微距）。
- **慢动作（升格）**：继承 2.0 能力，提示词写 `慢动作` / `慢镜头`；`@参考视频` 可作节奏迁移（上传节奏参考视频，标注 `@视频1 仅用于定义运镜和节奏`）。用于静物细节展示（手表/珠宝/美食特写）。
- **音效**：音效先行（画面未到声音先到）、ASMR 质感适合美妆/美食。

示例（官方真实可用）：

```
图1中的可口可乐饮料，360度高速旋转2圈后，突然停住蓄力分裂成了3个部分进行展示。随后分解后的可口可乐饮料罐的上中下三部分快速向内旋转合成，一罐完整的可口可乐饮料，3D渲染产品展示特效
```

## 八、Mini 的坑（务必避开，每条都浪费生成次数）

1. **不要套六板块**：Mini 用一句话公式，不是 2.0/2.5 的 `## 角色+参考图` 那套结构化标题。
2. **不要抽象词**：写具象动作和画面，别写"高级感、有质感"这类空词。
3. **不要只描述静止一帧**：要写"这几秒里发生了什么变化"。
4. **不要漏 @ 用途**：上传了图就必须标注每张图用来干嘛。
5. **不要塞多个动作打架**：一拍只给一个清晰运镜。
6. **文生视频能不用就不用**：先造首帧再图生视频，稳定性高得多。

## 九、API 参数（生成模式接入时用）

- 模型：`doubao-seedance-2-0-mini-260615`（默认）
- 成本：约 0.5 元/秒；`--service-tier flex` 离线生成再省 50%
- 时长：单次最长 15s（写满，不拆 5 秒）；分辨率 2K；比例 16:9 / 9:16 / adaptive
- 环境变量：`ARK_API_KEY`（火山引擎 key）
- 依赖：Python 3.8+、requests 库；脚本 `scripts/seedance.py`（参考 SkillHub 源 SKILL）
