# 最终视频 PROMPT 交付契约（所有模型必读）

> 本文件是 Phase 10 的模型无关总闸门；与其他 reference 出现冲突时，以本契约确定交付边界，再按目标模型文件确定语法。`seedance-prompt.md`、`seedance-mini-prompt.md`、`kling-prompt.md`、`h3-prompt.md` 的字段规则必须遵守，但不是把同一套模板机械填空。每条最终 PROMPT 必须以已确认的视频创意蓝图、剧本、分镜、镜头路由、资产和发行要求为事实源，再翻译成目标模型格式。模型价格、能力、时长和界面参数会变化，执行时以用户当前可见界面或官方接口为准，reference 中的数值仅作版本快照。

## 1. 三层优先级

1. **事实源优先**：已确认视频创意蓝图、剧本、分镜台词、客户真实产品资产、镜头级生产路由不可被公式改写；优先级为用户真实资料与明确决定 > 已确认创意蓝图 > 已确认剧本/分镜 > 资产与路由 > 模型格式。
2. **模型官方格式优先**：目标模型的字段、时间轴、素材引用、台词语法与模式限制必须按官方方式输出，不能混用其他模型公式。
3. **项目目标优先**：在不违背前两层的前提下，PROMPT 必须围绕本镜实际职责、时长、真实产品资产、真实视频风格、台词和平台要求写，不堆无关公式字段。

## 2. 分镜图硬门（所有视频必交付）

- 所有视频在进入镜头级路由和视频 PROMPT 前，必须先生成至少 1 张整张 3×3 宫格分镜图；超过 15 秒按每 15 秒增加 1 张。
- 产品视频、人物口播、剧情、品牌片、纯氛围、动画/3D、无产品视频全部适用，不存在“纯氛围可跳过”例外。
- 九宫格不是装饰稿：它用于在付费生视频前锁定产品的样子、所在位置、人物关系、场景与构图，让用户快速理解成片并尽早发现不合适之处。
- 宫格必须由图像模型单次直出整张 3×3，不允许后期拼合、单格替换、裁切拼接或用文字分镜表冒充图片。
- 每格必须有逐格台账；分镜图生成失败、串格、串景、时间码错或与台账不一致时，整张作废并按同一台账重跑，不得局部修补。每张最多尝试 3 次；3 次仍不合格时，报告失败项与成本，暂停等待用户调整台账或素材，禁止无限付费重跑。
- 用户未确认分镜图和逐格台账前，禁止进入 Phase 7.5、Phase 8、Phase 10 或视频生成。

## 3. 逐镜事实卡（写 PROMPT 前必齐）

```text
creative_blueprint_id / version / 镜号 / 时间范围 / 镜头职责 / P0-P3等级 / 目标模型与模式 /
角色ID / 服装ID / 场景ID / 产品资产ID /
说话人ID / 台词原文 / 台词语言 / 画内口播或画外音 /
视觉风格 / 运镜 / 动作 / 声音 / 不可变项 / 验收标准
```

- 台词原文只能来自用户确认的剧本；不得在 Phase 7 或 Phase 10 临时改写、概括为“自然讲解”或自行补写。
- 有说话、口播、介绍、回答、喊话、对镜讲解、张嘴表达的镜头：`说话人ID + 完整台词 + 语言 + 时间范围 + 口型/画外音方式` 全部必填。
- 纯动作镜：必须明确写 `无对白；仅环境音/动作音`，不能用空白代替。
- 台词因模型单镜时长过长必须拆分时，只能按原句自然停顿拆到相邻镜头；不得删改。拆分改变剧本节奏时，先回剧本层确认。

## 4. 真实视频风格总锁

除已确认的 `13 动画/3D 演示` 路线外，所有人物视频默认使用真实摄影风格：真实人物、自然皮肤纹理、真实服装材质、可信的光影与物理接触、非夸张镜头运动。

- 人物资产图固定为黑白铅笔素描 / 黑白线稿（可灵路径除外：选定可灵即直接以用户授权的真人照片/视频作 I2V 身份锚定，免产素描）；不得写成真人照片、彩色肖像或写实真人三视图。
- 黑白素描可以作为 Seedance/H3 等模型的图生视频参考；若用户另行提供且授权真人照片/视频，也可仅作为生成阶段的身份锚点。两者都不改变正式人物资产（非可灵路径）仍为黑白素描的交付规范；可灵路径直接走授权真人 I2V 参考、免素描。
- 真人/真人感视频 PROMPT 是否使用真实摄影风格，必须以用户确认的视觉路线为准，不得反向改变人物资产图。
- 不允许把插画、动漫、黑白素描、3D 人物、CGI 人物、数字人、塑料皮肤作为真人视频的默认结果。
- 产品 CGI/3D 演示仅适用于已确认的非真人 `13 动画/3D 演示` 路线；不得污染同条真人镜头。

## 5. 产品等级与资产路由

| 级别 | 含义 | 允许的产品方式 | 不可承诺 |
|---|---|---|---|
| P0 | 产品不出现 | 不需产品资产 | 产品展示/识别 |
| P1 | 产品是背景、远景或局部氛围 | 仍需真实产品参考；只是不要求包装文字可读 | 远景中包装文字清晰可读 |
| P2 | 产品承担动作、近景展示或卖点 | `P-CORE + P-HERO`，逐镜重注入真实参考 | Logo、文字、固定版式逐字保真 |
| P3 | 产品承担 Logo、包装文字、型号或转化信息 | `P-PACKSHOT` 实拍/透明 PNG/微动/合成 | 让纯视频模型重画包装 |

- 只要 PROMPT 需要约束产品外观，就保留“产品外观、比例、位置与已确认参考图 100% 一致”等强指令，让模型明确最高优先级；这里的“100%一致”是提示词目标，不是对随机生成能力的效果担保。实际验收仍按 P0-P3 路由执行，P3 必须用真实产品资产或合成兜底。
- 视频模型 PROMPT 正文不得出现“后期添加/后期叠加”这类模型无法执行的元指令；生产交付说明可明确 P3 真实包装合成、字幕、法务文案和平台 AIGC 标签等受控编辑步骤。

## 6. 模型模式硬路由

| 模型 | 含对白/口播时必须满足 | 无对白时 |
|---|---|---|
| Seedance 2.0/2.5 | 声音设计中有说话人 + 完整原话；按该模型六板块/时间轴语法落地 | 对白/旁白明确写 `N/A（本镜无发声）` |
| Seedance Mini | 在对应时间戳内写说话人 + 引号原话 + 语言/口型说明；保持 Mini 简洁公式，不套六板块 | 对应时间戳写 `无对白，仅…` |
| 可灵 Kling | 口播/对白人物走 I2V/O3 身份锚定；每句台词在对应时间轴内紧邻说话人 | 时间轴明确 `无对白`，不写“对镜说话” |
| MiniMax H3 | 强制 Ref2VA；`detailed_description` 含 `(S1)` 等说话人和 `<d>[Language] 原话</d>` | 可用关键帧模式；若 Ref2VA 则明确无对白 |

## 7. 最终交付 FAIL 门（任一项不通过不得交付）

- [ ] 每个最终 PROMPT 已关联逐镜事实卡，模型、时长、资产与 Phase 7.5 路由一致。
- [ ] 每个最终 PROMPT 继承正确的 `creative_blueprint_id / version`，没有改写钩子、产品与对照物身份、证明动作、人物关系、主要视觉语法、声音或结尾。
- [ ] 有发声行为的镜头，台词数量、顺序、说话人、语言和原话与确认剧本一致。
- [ ] 无发声镜头明确标为无对白；没有用“说话/讲解/口播”一词留下歧义。
- [ ] 每句台词在模型允许的时间范围内可说完；必要拆句未删改原意，且镜头/剧本已同步。
- [ ] 真人视频已写入真实摄影风格；黑白素描（非可灵路径）没有进入最终视频风格；可灵路径已确认使用授权真人照片/视频作 I2V 参考且未违反肖像授权。
- [ ] P2/P3 的资产、动作边界和可承诺范围正确；P3 没有交给模型重画真实包装。
- [ ] 只要镜头要求展示包装文字、Logo、型号、配料表、酒精度或固定版式，已确认原文已逐字写入该视频 PROMPT；没有写“见参考图”“文字清晰即可”等模糊替代。
- [ ] 只要资产图要求出现包装文字、Logo、型号、配料表、酒精度或固定版式，已确认原文已逐字写入该资产 PROMPT；原文未确认时已明确标记待补，不得猜写。
- [ ] 使用的是目标模型官方公式，不混用其他模型字段。
- [ ] 画面内文字、价格、Logo 与平台合规规则不冲突；台词/画外音没有被误写成字幕。

## 8. 最终交付包

1. 已确认纯文字剧本；2. 逐镜分镜表；3. 逐镜事实卡与台词核对表；4. **必交付的整张 3×3 宫格分镜图与逐格台账**；5. 产品/人物/服装/场景资产台账；6. P2/P3 高清关键帧清单；7. 镜头级生产路由表；8. 按模型分组的视频 PROMPT；9. 合规与成本检查；10. 未确认项、风险与下一步。
