# 最终视频 PROMPT 交付契约（所有模型必读）

> 本文件是 Phase 10 的模型无关总闸门。`seedance-prompt.md`、`seedance-mini-prompt.md`、`kling-prompt.md`、`h3-prompt.md` 的官方公式和字段规则必须遵守；但公式只是模型语法与能力边界，不是把同一套模板机械填空。每条最终 PROMPT 必须以已确认的剧本、分镜、镜头路由、资产和发行要求为事实源，再翻译成目标模型的官方格式。

## 1. 三层优先级

1. **事实源优先**：已确认剧本、分镜台词、客户真实产品资产、镜头级生产路由不可被公式改写。
2. **模型官方格式优先**：目标模型的字段、时间轴、素材引用、台词语法与模式限制必须按官方方式输出，不能混用其他模型公式。
3. **项目目标优先**：在不违背前两层的前提下，PROMPT 必须围绕本镜实际职责、时长、产品一致性等级、真实视频风格、台词和平台要求写，不堆无关公式字段。

## 2. 逐镜事实卡（写 PROMPT 前必齐）

```text
镜号 / 时间范围 / 镜头职责 / P0-P3等级 / 目标模型与模式 /
角色ID / 服装ID / 场景ID / 产品资产ID /
说话人ID / 台词原文 / 台词语言 / 画内口播或画外音 /
视觉风格 / 运镜 / 动作 / 声音 / 不可变项 / 验收标准
```

- 台词原文只能来自用户确认的剧本；不得在 Phase 7 或 Phase 10 临时改写、概括为“自然讲解”或自行补写。
- 有说话、口播、介绍、回答、喊话、对镜讲解、张嘴表达的镜头：`说话人ID + 完整台词 + 语言 + 时间范围 + 口型/画外音方式` 全部必填。
- 纯动作镜：必须明确写 `无对白；仅环境音/动作音/BGM`，不能用空白代替。
- 台词因模型单镜时长过长必须拆分时，只能按原句自然停顿拆到相邻镜头；不得删改。拆分改变剧本节奏时，先回剧本层确认。

## 3. 真实视频风格总锁

除已确认的 `13 动画/3D 演示` 路线外，所有人物视频默认使用真实摄影风格：真实人物、自然皮肤纹理、真实服装材质、可信的光影与物理接触、非夸张镜头运动。

- 人物资产图中的黑白素描只用于审核/身份锚定，绝不代表最终视频风格。
- 真人/真人感视频 PROMPT 必须明确写：写实真人、真实摄影/实拍质感、自然光影与真实材质。
- 不允许把插画、动漫、黑白素描、3D 人物、CGI 人物、数字人、塑料皮肤作为真人视频的默认结果。
- 产品 CGI/3D 演示仅适用于已确认的非真人 `13 动画/3D 演示` 路线；不得污染同条真人镜头。

## 4. 产品等级与资产路由

| 级别 | 含义 | 允许的产品方式 | 不可承诺 |
|---|---|---|---|
| P0 | 产品不出现 | 不需产品资产 | 产品展示/识别 |
| P1 | 产品是背景、远景或局部氛围 | 概念/场景参考可用 | 真实 SKU 外观 |
| P2 | 产品承担动作、近景展示或卖点 | `P-CORE + P-HERO`，逐镜重注入真实参考 | Logo、文字、固定版式逐字保真 |
| P3 | 产品承担 Logo、包装文字、型号或转化信息 | `P-PACKSHOT` 实拍/透明 PNG/微动/合成 | 让纯视频模型重画包装 |

## 5. 模型模式硬路由

| 模型 | 含对白/口播时必须满足 | 无对白时 |
|---|---|---|
| Seedance 2.0/2.5 | 声音设计中有说话人 + 完整原话；按该模型六板块/时间轴语法落地 | 对白/旁白明确写 `N/A（本镜无发声）` |
| Seedance Mini | 在对应时间戳内写说话人 + 引号原话 + 语言/口型说明；保持 Mini 简洁公式，不套六板块 | 对应时间戳写 `无对白，仅…` |
| 可灵 Kling | 口播/对白人物走 I2V/O3 身份锚定；每句台词在对应时间轴内紧邻说话人 | 时间轴明确 `无对白`，不写“对镜说话” |
| MiniMax H3 | 强制 Ref2VA；`detailed_description` 含 `(S1)` 等说话人和 `<d>[Language] 原话</d>` | 可用关键帧模式；若 Ref2VA 则明确无对白 |

## 6. 最终交付 FAIL 门（任一项不通过不得交付）

- [ ] 每个最终 PROMPT 已关联逐镜事实卡，模型、时长、资产与 Phase 7.5 路由一致。
- [ ] 有发声行为的镜头，台词数量、顺序、说话人、语言和原话与确认剧本一致。
- [ ] 无发声镜头明确标为无对白；没有用“说话/讲解/口播”一词留下歧义。
- [ ] 每句台词在模型允许的时间范围内可说完；必要拆句未删改原意，且镜头/剧本已同步。
- [ ] 真人视频已写入真实摄影风格；黑白素描没有进入最终视频风格。
- [ ] P2/P3 的资产、动作边界和可承诺范围正确；P3 没有交给模型重画真实包装。
- [ ] 使用的是目标模型官方公式，不混用其他模型字段。
- [ ] 画面内文字、价格、Logo 与平台合规规则不冲突；台词/画外音没有被误写成字幕。

## 7. 最终交付包

1. 已确认纯文字剧本；2. 逐镜分镜表；3. 逐镜事实卡与台词核对表；4. 九宫格分镜图与逐格台账；5. 产品/人物/服装/场景资产台账；6. P2/P3 高清关键帧清单；7. 镜头级生产路由表；8. 按模型分组的视频 PROMPT；9. 合规与成本检查；10. 未确认项、风险与下一步。
