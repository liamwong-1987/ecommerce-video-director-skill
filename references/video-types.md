# 电商短视频营销目的与案例库（6 大类标签，非穷举）

按营销目的提供六大类标签和历史案例，每类含定义、适用场景、推荐钩子、示例结构、话术特点和时长建议。

> 本文件不负责决定“这个客户应该拍什么”。正式生产前必须先执行 `creative-discovery.md`，由独立“头脑风暴”Skill根据客户资料设计十维视频 DNA并确认《视频创意蓝图》。一条视频可以同时包含剧情冲突、产品证明、ASMR、教程或促销机制；六大类只用于标记主/副商业目标和查询案例，不能把混合创意强行归入唯一类型。

> 下文所有“推荐结构/默认风格/CTA”均为灵感示例，不是硬模板。与已确认视频创意蓝图冲突时，以蓝图为准。

---

## ① 种草转化

**定义**：以"真实用户/博主分享"的口吻安利产品，让观众产生"我也想试试"的冲动。核心是「信任感 + 自然感」，不是硬广。

**⚠️ 用户明确界定（2026-08-16）：种草 / 探店 = 小红书形式的「自拍 + 自然」风**——第一人称博主出镜、手持自拍或对镜自拍、生活化真实场景、口语像跟朋友聊天、**绝对不像念广告稿**。这才是"种草视频"的标准形态。

**风格分支（按发行区域区分，种草/探店默认走各自区域的原生风）**：

| 风格 | 区域 | 形态 | 何时用 |
|------|------|------|--------|
| **小红书自拍自然风（默认·国内）** | 国内 | 博主第一人称自拍/对镜、生活感、自然口语、卖点轻带、闺蜜词可用 | 国内种草/探店的标准形态，**默认走这条** |
| **UGC 原生风（默认·国外）** | 国外 | 普通用户"随手拍"质感：手机原生拍摄、不精致不脚本化、真实反应/真实试用、"TikTok made me buy it"那种安利感；第一人称口语、本地语言+本地字幕、本地化幽默；多元选角忌刻板 | 国外种草/探店的标准形态，**默认走这条**（不是精致 Creator vlog 风） |
| 抖音信息流口播风 | 国内（投放） | 第三人称画外音、快语速、参数轰炸、广告投放感强 | **非默认**；仅当用户显式要"抖音信息流投放/硬广"时才用，不属于种草的默认形态 |

> **国外种草要点（用户明确 2026-08-16）**：海外种草以 UGC 风为主——真实、原生、像普通用户在分享，而非 polished creator vlog。合规上仍须：目标市场语言+本地字幕、付费内容开 Paid partnership 披露、AIGC 标注、酒精类受管制需资质。

**子类型**（按小红书自拍自然风执行；已剔除的好物清单/直播切片不作为正式交付类型）：

| 子类型 | 特点 | 钩子 |
|--------|------|------|
| 产品种草 | 博主自然展示+真实体验，卖点轻带 | 场景代入 / 好奇揭秘 |
| 开箱测评 | 博主开箱过程 + 真实反应 | 好奇揭秘 / 悬念追问 |
| 探店打卡 | 博主到店真实体验种草 | 场景代入 / 好奇揭秘 |
| 对比测评 | 博主真实对比，凸显自家 | 反差反转 / 数字冲击 |
| 达人讲解带货 | 达人出镜 + 口语化讲解，商品时刻驱动，抖音 UGC 风 | 价格冲击 / 优惠泄露 / 痛点-商品直给 |

**分镜结构（小红书自拍自然风）**：
博主出场（自拍/对镜，自然打招呼 1-2s）→ 自然带出场景/产品（我在喝/用/探到 2-3s）→ 真实体验感受（自然说，卖点轻带 8-12s）→ 记忆点/金句（2-3s）→ CTA（关注/收藏/评论，自然收尾 2-3s）

> **必含商品时刻**：无论哪条路线，分镜里必须至少有一个商品时刻（开箱 / 首次使用 / 痛点→商品呈现 / 近景演示 / 自然推荐，见 `copywriting-library.md`）。钩子留人后立刻进商品时刻，不能接空镜。

**路线路由（种草转化下三条路线，按需选）**：

| 路线 | 形态 | 何时用 |
|------|------|--------|
| 纯商品展示 | 无人物，商品自身演示 | 标品、参数型、无达人预算 |
| 达人出镜讲解（抖音 UGC 带货） | 达人出镜 + 口语化口播讲解，商品时刻驱动，竖版 9:16 | 抖音带货、需要信任感转化 |
| 自拍自然风（种草/探店默认） | 小红书自拍，不像念稿 | 国内种草/探店标准形态 |

**达人出镜方向模板（抖音 UGC 带货用）**：
描述一个「人物 + 场景 + 一次商品互动 + 正对镜头 + 平稳手持/手机拍摄感」的画面。即：真人出镜，身处真实生活/店铺场景，手持或演示商品，目光看向镜头，运镜是手持平稳感而非棚拍推拉。商品排在画面第一位，达人讲解是辅助。

**口播驱动标注**：
达人出镜讲解 / 抖音信息流口播路线为口播驱动——整条由达人口语化讲解串联，8-12 秒口播写足（详见 `copywriting-library.md` 台词密度）。自拍自然风不是口播驱动，卖点自然带出即可。

**话术特点**：第一人称、口语化、有真实情绪波动（惊喜/安利欲）；闺蜜式词可用但别堆砌；**不像念稿**。详见 `references/copywriting-library.md` 的「小红书自拍自然风」。

**资产规范（小红书自拍种草）**：按模型分流：Seedance / H3 先交付黑白素描三视图；选定可灵则直接使用用户授权的真人照片/视频作 I2V 身份锚定，免产素描。视频是否使用写实真人第一人称风格，按用户单独确认；真实生活/店铺场景，不棚拍；产品自然出现在博主手中/桌上，不堆硬照。

**卖点密度**：核心参数+口感+价格要保留，但**自然带出**，不堆参数轰炸、不硬套进剧情。

**时长**：15-30s（自拍种草偏短，自然说完不拖）。

## ② 剧情内容

**定义**：用微故事/情景剧做产品植入，钩子→冲突→反转→植入。

| 子类型 | 特点 |
|--------|------|
| 微短剧 | 完整小故事，产品自然植入 |
| 情景剧 | 生活片段，产品作为道具/解决方案 |
| 剧情种草 | 钩子+冲突+反转，结尾落到产品 |

**分镜结构**：钩子 3s → 冲突建立 5s → 反转 7s → 产品植入 5s → 收尾 CTA

**关键**：产品是"解决问题"的关键，不是硬广；反转是灵魂。

**时长**：15-45s。

## ③ 品牌形象（含 TVC）

**定义**：塑造品牌形象与势能，重质感、重情绪，不直接逼单。

| 子类型 | 特点 |
|--------|------|
| **TVC 广告** | 商业广告大片，精致制作感，品牌调性 |
| 品牌故事/溯源 | 讲品牌起源、工厂、真材实料 |
| 品牌形象片 | 品牌价值观、社会价值 |

**分镜结构**：情绪钩子 → 品牌势能（门店/工厂/荣誉）→ 金句 → 品牌 Slogan

**质感**：精致制作感（专业布光、稳定运镜、电影级光影）。

**时长**：30-60s。

## ④ 人设 IP

**定义**：用具体"人"（老板/创始人/达人/虚拟IP）做品牌人格化，靠人设圈粉。

| 子类型 | 特点 |
|--------|------|
| 老板脱口秀 | 老板讲段子，自嘲+品牌，不硬套卖点 |
| 创始人 IP | 创始人故事、价值观输出 |
| 达人 KOC | 达人真实使用分享 |
| 虚拟 IP | 3D/动漫角色种草 |

**脱口秀段子套路**（关键）：抓一个具体意象**连续往死里挖梗**（如啤酒肚：工伤→肚子自己站住→守酒糗事→以身试酒），用反转、call-back、画面感。不硬塞产品卖点。

**时长**：15-60s。

---

## ⑤ 促销转化

**定义**：直接刺激下单，强 CTA、强紧迫感。

| 子类型 | 特点 |
|--------|------|
| 大促预热 | 造势、预告优惠 |
| 限时优惠 | 紧迫感逼单 |

**分镜结构**：利益钩子 → 优惠力度 → 数量/时间紧迫 → 立即下单 CTA

> 必含商品时刻（近景演示 / 价格展示特写），让优惠落到具体商品上，不空喊折扣。

**时长**：15-30s。

---

## ⑥ 知识热点

**定义**：用干货/科普/热点吸引流量，软性带出产品。

| 子类型 | 特点 |
|--------|------|
| 产品教程 | 教怎么用/怎么选 |
| 使用场景 | 场景化演示 |
| 品类科普 | 讲品类知识（如精酿 vs 工业啤酒） |
| 节日借势 | 节日热点营销 |
| 热点跟拍 | 跟热点/挑战 |

**分镜结构**：知识钩子 → 干货/科普 → 自然带出产品 → 关注 CTA

**时长**：30-60s。
