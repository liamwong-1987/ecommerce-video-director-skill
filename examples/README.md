## 关键教训沉淀（务必遵守）

1. **卖点不缩水**：参数/口感/价格一个不能丢，信息流可快语速。
2. **文案安全**：避免"上天台"（轻生联想）、"去山里喝酒"（危险联想）等负面场景。
3. **敏感词**：电话号码/二维码/微信号不进提示词；招商加盟改"开店"；收益承诺中性化。
4. **脱口秀**：连续挖梗 > 说教式自嘲；AI 硬编段子易尬，优先用真实素材或资料库套路。
5. **人物资产视觉**：人物形象图固定为黑白铅笔素描 / 黑白线稿；视频风格按用户单独确认，不反向改变人物资产。
6. **场景做资产时**：30s 单段不必做场景资产，写死在 PROMPT 里即可；多段拼接才需要资产锚定。
