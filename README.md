# 电商带货短视频导演

## 项目简介

这是一个面向电商内容创作者、品牌方、广告团队和 AI 视频制作者的短视频导演 Skill。

它会先调用独立的“头脑风暴”Skill，理解每个客户不同的想法、产品、受众、参考和限制，比较 2–3 条创意路线并确认《视频创意蓝图》，再把资料整理为可直接执行的：

- 短视频创意方案
- 纯文字剧本
- 分镜脚本
- 人物与场景设定
- 产品展示方案
- 视频生成提示词
- 平台发布与合规检查清单

针对 AI 视频中常见的产品外观变化、人物身份漂移、镜头衔接不稳定等问题，工作流会先进行视觉预演和关键资产确认，再进入视频生成，减少“画面好看但产品不对”的情况。

## 支持内容

### 视频类型

- 产品种草
- 剧情带货
- 品牌广告与 TVC
- 人设 IP
- 促销转化
- 知识与热点内容

这些是营销目的标签和案例入口，不是完整的视频类型边界。具体项目会动态规划钩子、叙事、产品角色、卖点证明、人物关系、视觉语法、声音和结尾。

### 发布平台

抖音、快手、视频号、小红书、B站、TikTok、YouTube、Instagram、Facebook、Snapchat 等。

### 视频模型

- Seedance 2.0
- Seedance 2.0 Mini
- Seedance 2.5
- MiniMax H3
- 可灵 Kling

不同模型根据人物表现、产品展示、声音、时长和镜头控制需求选择。

## 核心能力

### 从创意到成片方案

从产品卖点和用户的初步想法出发，先完成头脑风暴和创意蓝图确认，再逐步形成完整的短视频制作方案。

### 产品与人物稳定性

通过视觉预演、关键资产确认和镜头级生成策略，提升产品、人物、场景在视频中的连续性。

### 平台适配

根据发布平台、目标受众和地区要求，调整脚本语言、节奏、表达方式与合规提醒。

### 两种工作方式

#### 纯提示词模式

输出：

- 剧本
- 分镜
- 资产 SPEC
- 视频生成提示词
- 平台操作指引

#### 生成模式

配置视频生成接口后，可进一步接入资产生成、视频生成和批量出片流程。

## 项目结构

```text
SKILL.md                 核心工作流
references/              模型、资产、平台和创作参考
video_api.cjs            可选的视频生成接口客户端
examples/                示例资料
```

## 使用方式

将本 Skill 接入支持 WorkBuddy Skill 的工作环境，然后直接描述你的产品、平台、创意或视频需求即可。

如果需要生成模式，再配置对应的视频接口环境变量。

## 适用场景

- 电商产品短视频
- AI 产品广告
- 品牌宣传片
- 主播/达人口播
- 剧情种草
- 开箱测评
- 促销视频
- 批量内容测试

## 说明

AI 视频模型对包装文字、Logo 和复杂产品细节的还原能力存在边界。对于需要高度准确的产品展示，应结合真实产品素材或后期合成使用。

## 常见问题

### 1. 这是什么？
这是一个面向电商短视频创作的导演工作流 Skill，帮助把产品资料、卖点和创意整理为脚本、分镜、视觉资产方案及视频生成提示词。

### 2. 它是不是一个视频生成模型？
不是。它负责前期策划、镜头设计、资产规划、模型选择和发布检查，也可以在配置接口后进入生成流程。

### 3. 支持哪些视频模型？
目前适配 Seedance、Seedance 2.0 Mini、Seedance 2.5、MiniMax H3 和可灵 Kling。具体模型会按镜头类型和制作目标选择。

### 4. 能不能保证产品在视频里完全一致？
不能对所有模型承诺百分之百还原。对于 Logo、包装文字和复杂细节要求较高的产品，应使用真实产品素材、关键画面确认或后期合成提高准确度。

### 5. 使用前需要准备什么？
准备产品图片或视频、产品卖点、目标受众、发布平台、视频时长、风格方向和必要的品牌规范。资料越完整，输出越可执行。

### 6. 支持哪些发布平台？
支持抖音、快手、视频号、小红书、B站、TikTok、YouTube、Instagram、Facebook、Snapchat 等平台。

### 7. 能不能批量制作内容？
可以。纯提示词模式适合批量生成创作方案；配置接口后，可进一步接入资产生成、视频生成和批量出片流程。

### 8. 纯提示词模式和生成模式有什么区别？
纯提示词模式输出脚本、分镜、资产 SPEC、视频提示词和平台指引；生成模式在此基础上，通过已配置的视频接口执行资产生成和视频生成。
