# 电商短视频导演 · 一键 PROMPT 工厂

> 把"我想做个电商短视频"变成**可直接喂给即梦 / Seedance / MiniMax 等视频模型的完整 PROMPT 包**。
> 这是一个**通用提示词工作流（Skill 格式）**，**不绑定任何 AI 工具**——你可以把它加载到任何支持自定义指令 / Skill 的 AI 助手里使用（Claude Code、Cursor、CodeBuddy、ChatGPT 自定义 GPT、通义灵码、任意支持系统提示词的对话助手等）。

## 它能做什么

输入一个模糊需求（如"我要给小金罐做个抖音种草视频"），它走完 11 个阶段，产出**一整套可直接用于视频生成的 PROMPT 资产**：

- **纯文字剧本**：钩子 + 痛点共鸣 + 卖点 + 金句 + CTA，台词按风格写满
- **分镜表**：镜头 / 时间轴 / 画面描述 / 台词 / 声音，标关键帧
- **资产 SPEC**：角色锚点 / 场景 / 产品图 / 道具 / 首尾帧
- **视频模型专用 PROMPT**：Seedance 中文六板块 / MiniMax H3 英文，直接复制去生成
- **尾帧高清重绘方案**：长视频分段衔接用

你拿到 PROMPT 包，去即梦 / 自己的视频 API 一跑就出片。**没有生图生视频 API 也能用**——它只出 PROMPT，生成那步由你执行。

## 为什么用这套

- **国内外通吃**：国内 5 平台（抖音/快手/视频号/小红书/B站）+ 国外 5 平台（TikTok/YouTube/Instagram/Facebook/Snapchat），规则分开加载
- **合规先行**：每条红线标注来源（官方 / 源 Skill / 实测 / 导演经验），不合规自动改写但真实卖点不动
- **风格自由**：6 大类视频类型 × 20 种呈现风格任意组合
- **模型无关**：同一剧本可映射到 Seedance 2.0 / 2.5 或 MiniMax H3
- **纯提示词、零依赖**：不调用任何外部 API，可离线跑

## 11 阶段流程

| 阶段 | 做什么 | 产出 |
|------|--------|------|
| 1. 理解创意 | 对齐意图（带货/种草/品牌/IP/促销/知识），不急着问细节 | 方向复述 |
| 2. 摸需求 | 六维扫描：产品/受众/区域/平台/时长/类型/风格/素材 | 缺失项清单 |
| 3. 深度挖掘 | 最多 4 轮提问，必做 4 探测：发行区域 / 能力模式 / 批量 / 呈现风格 | 完整需求 |
| 4. 纯文字剧本 | 按类型+风格写，**唯一事实源**；出完**必停等用户确认** | 纯文字剧本 |
| 5. 合规检查 | 红线过滤，每条标来源 | 合规剧本 |
| 6. 自检清单 | 14 项打勾，不通过回阶段 4 | 自检通过 |
| 7. 提取分镜 | 从剧本提取，不新增内容；7 原则（景别禁忌/蒙太奇/一致性…） | 分镜表 |
| 8. 提取资产 | 角色/场景/产品/道具/首尾帧 SPEC | 资产清单 |
| 9. 模型选择 | Seedance 2.5(30s) / 2.0(15s) / H3(15s·2K) | 模型 ID |
| 10. 生成视频 PROMPT | 按模型转格式（中文六板块 / 英文三字段） | 模型专用 PROMPT |
| 11. 尾帧重绘衔接 | 仅 >15s 且 2.0/H3 时触发：拆段→生成→取尾帧→重绘→当首帧→拼接 | 长视频衔接方案 |

> **关键关卡**：阶段 4 出完剧本必须停住问用户"行不行"，没确认绝不进阶段 5。

## 支持的平台与区域

### 国内（走《广告法》口径：极限词 / 导流 / 医疗功效 / 招商资质）
| 平台 | 特别红线 |
|------|---------|
| 抖音 | 极限词、导流（微信/二维码/外链）、医疗功效、AI 标注 |
| 快手 | 类似抖音，社区规范严控虚假宣传 |
| 视频号 | 微信生态，导流管控严 |
| 小红书 | 交易导流细则（禁站外交易）、AI 内容须标"AI创作" |
| B站 | 年轻向，软广需声明 |

### 国外（走当地法规：商业披露 / 受管制商品 / AIGC 标注）
| 平台 | 特别红线 |
|------|---------|
| TikTok | 付费合作须开披露开关、受管制商品（烟酒药品）禁投 |
| YouTube | 付费宣传披露、"altered/synthetic content" 标注 |
| Instagram | Paid Partnership 标签 |
| Facebook | 商业披露 + 受管制商品限制 |
| Snapchat | 类似 Meta 政策 |

跨区发布（如同时发小红书 + TikTok）：主区域判定 + 次区域红线叠加。

## 视频类型 × 呈现风格

### 6 大类视频类型（营销目的）
① 种草转化（产品种草/开箱/好物清单/探店/对比）　② 剧情内容（微短剧/情景剧）　③ 品牌形象（TVC/品牌故事）　④ 人设IP（老板脱口秀/达人 KOC/虚拟 IP）　⑤ 促销转化（直播切片/大促预热）　⑥ 知识热点（教程/科普/热点）

### 20 种呈现风格（与类型正交，自由组合）
- **真人出镜 8 种**：口播直出 / 自拍手持（第一人称）/ UGC 原生随手拍 / 情景剧 / 老板脱口秀 / 街头访谈 / 开箱测评 / vlog 生活流
- **非真人低成本 6 种**：图文快闪 / 字幕卡点 / 素材混剪 / AI 数字人 / 动画 3D / ASMR 沉浸
- **叙事手法 6 种（可叠加）**：对比测评 / 好物合集 / 直播切片 / 悬念反转 / 效果见证 / 复古滤镜

> **种草 / 探店默认形态**：国内 = 小红书自拍自然风（第一人称、自然口语、生活场景）；国外 = UGC 原生风（普通用户随手拍、真实反应）。**都不是**抖音信息流口播风，除非用户显式要"信息流投放/硬广"。

## 视频模型

| 模型 | 单次时长 | 适用场景 |
|------|---------|---------|
| **Seedance 2.5** | 30s（可超长 180s） | 30s+、多素材、时间戳控制，**首选** |
| **Seedance 2.0** | 15s | 稳定成熟工作流 |
| **MiniMax H3** | 15s（2K） | 原生立体声 / 首尾帧（FL2VA）/ 2K / 性价比 |

> 30s 以内建议直接用 **Seedance 2.5 一次生成，无需分段拼接**——少一步少一个坑。

## 怎么用

### 方式 A：作为 Skill / 自定义指令加载
把整个仓库（或 `SKILL.md` + `references/`）作为指令上下文喂给你的 AI 助手：
- **Claude Code / CodeBuddy / Cursor 类**：放到对应 Skill 目录（如 `~/.claude/skills/`、项目 `.codebuddy/skills/`），工具会按 SKILL.md 自动调用
- **ChatGPT 自定义 GPT**：把 `SKILL.md` 内容贴进"指令"框
- **任意对话助手**：把 `SKILL.md` 作为系统提示词的一部分

### 方式 B：直接对话驱动（零配置）
即使不配置 Skill，也可以直接把 `SKILL.md` 全文贴给任意 AI 对话，说"**按这个流程帮我做一条 [产品] 的 [平台] [类型] 视频 PROMPT**"，它就会照 11 阶段走。

### 最小跑通示例
1. 准备真实产品信息（卖点必须真实，不编功效数据）
2. 告诉 AI：发抖音、30s、种草、小红书自拍风
3. AI 走完阶段 1–4 出剧本 → **你确认** → 阶段 5–10 出 PROMPT 包
4. 拿 PROMPT 去即梦 / 你的视频 API 生成视频

## 合规说明

所有红线标注四类来源，便于核查与追责：
- **【官方】**：平台公约 / 规范（抖音公约、小红书交易导流细则、TikTok / YouTube / IG 商业政策）
- **【源 Skill】**：三个源工作流（seedance-director / douyin-script-zh / create-product-microstory）
- **【实测】**：本项目在 AI 视频生成中踩过的坑（如"招商/加盟"触发生成报错）
- **【导演经验】**：行业经验性提示

**原则**：不合规处自动改写到合规，但**真实卖点不动**。
