# 抖音·TikTok 视频导演 Skill

电商短视频导演 Skill（WorkBuddy Skill 格式）。一键生成**国内外短视频 PROMPT 包**——你拿去即梦 / 平台 / 自己的 API 跑就能出片。

## 能力

- **11 阶段流程**：理解创意 → 摸需求 → 深度挖掘 → 纯文字剧本 → ⏸用户确认 → 合规检查 → 自检清单 → 提取分镜 → 提取资产 → 模型选择 → 生成视频 PROMPT → 尾帧重绘衔接
- **覆盖 11 个平台**：国内（抖音 / 快手 / 视频号 / 小红书 / B站）、国外（TikTok / YouTube / Instagram / Facebook / Snapchat）
- **6 大类视频类型 × 20 种呈现风格**（真人出镜 / 非真人低成本 / 叙事手法），自由组合
- **合规红线均标注来源**（官方 / 源 SKILL / 实测 / 导演经验），不合规处改写但不动真实卖点
- **当前定位：纯提示词工厂**——一键出剧本 / 分镜 / 资产 SPEC / 视频 PROMPT / 尾帧重绘 PROMPT

## 视频模型

- Seedance 2.5（30s）/ 2.0（15s）
- MiniMax H3（15s·2K，支持首尾帧）
