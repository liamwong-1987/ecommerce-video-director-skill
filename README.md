# 电商短视频制作流程说明

## 整体判断

一条电商短视频的产出，拆开看是两段。

前半段把一句需求加工成视频模型能执行的指令。后半段把指令交给视频模型，生成文件。

系统目前只做前半段。输入"给某款产品做一条抖音种草视频"这类需求，补全必要信息，写成剧本，拆成分镜，最后翻译成视频模型能接受的指令文本（PROMPT）。用户拿这段指令去即梦、Seedance、MiniMax 等平台生成视频。

后半段在外部平台完成，系统不参与。

## 客户需要提供什么

做视频前，客户至少要给两类东西：产品信息、产品图。除此之外，不同视频类型要的素材不一样。

### 所有视频都要的

产品信息（文字）：名称、核心卖点、参数、价格、认证、成分。这些必须真实，不能由系统编。

产品图（1-2 张）：正面外观或包装。有实拍图最好，直接使用；没有就由 AI 生成概念占位图，只作构图参考，不作为最终素材。

### 按视频类型追加

| 视频类型 | 额外素材 |
|---------|---------|
| 种草转化 | 产品实拍图（重点），可选博主真人参考 |
| 剧情内容 | 产品图，可选演员、场景参考 |
| 品牌形象 / TVC | 品牌 Logo、品牌色、门店或工厂实拍、产品高清图 |
| 人设 IP | 真人照片（老板 / 达人形象）或虚拟 IP 设定 |
| 促销转化 | 产品图，真实价格、优惠、库存数据 |
| 知识热点 | 产品图，可选品类知识资料 |

### 按呈现风格追加

真人出镜类需要真人照片参考，用于锁定人物形象。非真人低成本类（图文快闪、字幕卡点、素材混剪）只需要产品图和文案，不需要真人。对比测评类需要多个产品的图。

### 没有素材时怎么办

产品图缺失，由 AI 生成概念占位图，只用于构图参考。Logo、包装文字、型号、成分表、认证这类精确内容不靠 AI 重绘，有实拍图直接使用。

真人脸过审：即梦等平台禁止上传清晰真人脸素材，人物形象图用黑白素描铅笔风格过审，生成时再还原写实。

## 流程步骤

### 1. 需求确认

明确卖什么、发哪个平台、什么风格、时长多少。卖点必须真实，不能虚构功效、认证或价格。平台决定合规口径，国内和国外规则不同。

### 2. 剧本

把视频写成纯文字，包含开头钩子、中间卖点、结尾引导下单。台词要写足，不能只给几句。这一步是整个视频的依据，后续所有内容都从它展开。

### 3. 确认

剧本写完必须停下来给用户过目，确认无误再继续。这一步避免后面全部返工，不能跳过。

### 4. 合规检查

按发行平台查对应规则。系统内置国内外 10 个平台的规则：国内（抖音、快手、视频号、小红书、B站）、国外（TikTok、YouTube、Instagram、Facebook、Snapchat），每条规则标来源。排查禁用词（"最""第一""根治""加微信"等），改写到合规，真实卖点保留。

### 5. 分镜

把剧本切成一帧帧画面，标注每段的画面内容、台词、声音。相当于给生成环节一张逐秒的执行表。

### 6. 资产

描述视频里出现的角色、场景、产品图、道具，保证前后一致。比如人物不能上一秒一个长相、下一秒换一个。

### 7. 模型选择

按时长和需求选模型。Seedance 2.5 一次生成 30 秒，Seedance 2.0 和 MiniMax 系一次 15 秒。选哪个，影响后面要不要分段。

### 8. PROMPT

把分镜和资产按选定模型的格式拼成指令。Seedance 用中文六板块，MiniMax 用英文。

### 9. 生成

把指令提交给视频平台，等它生成。这一步是异步的，通常几十秒到几分钟，生成后拿到视频文件或下载链接。

## 术语

| 词 | 含义 |
|----|------|
| 剧本 | 视频的文字版，还没有画面 |
| 分镜 | 把剧本拆成逐秒的画面计划 |
| 资产 | 视频里人、场景、道具的文字描述，用于保证前后一致 |
| PROMPT | 交给视频模型的指令，描述得越具体，生成越准 |
| 尾帧 | 一段视频的最后一帧画面 |
| 合规红线 | 平台禁用词，出现会导致视频下架 |

## 两个注意点

系统只出指令，不出视频。之前做的样片，都是人拿指令去平台网页粘贴生成的。

视频生成是异步的，不是提交就出结果，要等。做界面时进度条、失败重试都要考虑。

长视频需要分段。超过单次生成上限时，切几段分别生成，上一段结尾当下段开头，最后拼成一条。

## 小结

做电商短视频，本质是把一句需求变成视频模型能读懂的指令，再交给模型生成文件。剧本、分镜、资产、合规这些步骤，都是在把需求逐步具体化、结构化，最终落到那段指令上。

这套流程里的规则（剧本怎么写、分镜怎么排、哪些词违规）有现成的规则库可以调用，不需要从零掌握。

## 安装

```
git clone https://github.com/liamwong-1987/ecommerce-video-director-skill
```

两种方式使用：

作为 Skill 加载：把整个目录放到 AI 编程助手的 skills 目录下（如 Codex 的 `~/.codex/skills/`、Claude Code 的 `~/.claude/skills/`、Cursor 的对应目录），工具会按 SKILL.md 自动调用。

零配置直接用：即使不配置 Skill，也可以把 `SKILL.md` 全文贴给任意 AI 对话，说"按这个流程帮我做一条 [产品] 的 [平台] [类型] 视频 PROMPT"，它就会照流程走。
